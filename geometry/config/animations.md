### `vector_addition` — 벡터 덧셈 단계 (평행사변형 법칙)

**계산 단계**:
```
Step 1: a⃗ 표시
  원점 O에서 a⃗ = (a₁, a₂) 방향으로 화살표 등장
  "먼저 a⃗를 표시합니다"

Step 2: b⃗ 표시
  a⃗의 끝점에서 b⃗ = (b₁, b₂) 방향으로 화살표 등장 (이어 붙이기)
  동시에 원점에서 b⃗ 화살표도 등장 (평행사변형 반대쪽 변)
  "a⃗의 끝에서 b⃗를 이어 붙입니다"

Step 3: a⃗ + b⃗ 합벡터 표시
  원점에서 평행사변형 대각선 방향으로 합벡터 등장
  "원점에서 대각선 방향이 합벡터 a⃗+b⃗ = (a₁+b₁, a₂+b₂)입니다"
  수식 박스: a⃗+b⃗ = ({{ax}}+{{bx}}, {{ay}}+{{by}}) = ({{rx}}, {{ry}})
```

**GSAP 요소 전환**:
```

- b⃗ 이어붙이기: translate 후 strokeDashoffset 200→0 (delay 0.8)
- 평행사변형 fill: opacity 0→0.2 (delay 1.2)
- 합벡터: strokeDashoffset 280→0, stroke:#f39c12 (delay 1.6)
- 수식 박스: opacity 0→1 (delay 2.2)
```

**강의 원고 키포인트**:

```
  "벡터는 크기와 방향만 있고 시작점은 어디든 상관없어요.
  그래서 a⃗의 끝에서 b⃗를 다시 그릴 수 있습니다.
  이게 삼각형 법칙이에요."

Step 3 narration:
  "평행사변형의 대각선이 합벡터입니다.
  두 방식(삼각형 법칙, 평행사변형 법칙) 모두 결과는 같아요.

```

### `dot_product_compute` — 내적 두 가지 계산법 비교

**계산 단계**:
```
Step 1: 수식 두 가지 제시
  방법 1 (기하):   a⃗·b⃗ = |a⃗||b⃗|cosθ
  방법 2 (성분):   a⃗·b⃗ = a₁b₁ + a₂b₂

Step 2: 기하 방법 대입
  a⃗ = ({{ax}}, {{ay}}), b⃗ = ({{bx}}, {{by}})
  |a⃗| = √({{ax}}²+{{ay}}²) = {{mag_a}}
  |b⃗| = √({{bx}}²+{{by}}²) = {{mag_b}}
  cosθ = {{cos_val}}
  → a⃗·b⃗ = {{mag_a}} × {{mag_b}} × {{cos_val}} = {{dot_val}}

Step 3: 성분 방법 대입 + 일치 확인
  a⃗·b⃗ = {{ax}}×{{bx}} + {{ay}}×{{by}}
        = {{a1b1}} + {{a2b2}}
        = {{dot_val}}
  → 두 방법 결과 일치 ✓
  (강조 박스: 두 공식은 같은 값을 다른 방식으로 계산한다)
```

**계산 추적 표**:
```
| 방법 | 계산식 | 결과 |
|------|--------|------|
| 기하  | |a⃗||b⃗|cosθ = {{mag_a}}×{{mag_b}}×{{cos_val}} | {{dot_val}} |
| 성분  | a₁b₁+a₂b₂ = {{a1b1}}+{{a2b2}} | {{dot_val}} |
```

**강의 원고 키포인트**:
```
Step 1 narration:
  "내적에는 공식이 두 개 있어요.
  기하 공식은 각도를 알 때 쓰고,
  성분 공식은 좌표를 알 때 씁니다.
  둘 다 같은 값이 나와야 해요 — 그게 바로 cosθ의 정의입니다."

Step 3 narration:
  "성분끼리 곱해서 더하면 됩니다.
  결과가 양수면 예각, 0이면 수직, 음수면 둔각이에요."
```

### `vector_projection` — 정사영 계산 단계

**계산 단계**:
```
Step 1: 정사영 정의
  a⃗를 b⃗ 방향으로 정사영하면
  b⃗ 방향 단위벡터: b̂ = b⃗/|b⃗|
  정사영 길이: |a⃗|cosθ

Step 2: 내적을 이용한 표현
  a⃗·b⃗ = |a⃗||b⃗|cosθ
  → |a⃗|cosθ = (a⃗·b⃗) / |b⃗|     (정사영 길이)

Step 3: 벡터 형태 (방향 포함)
  proj_b a⃗ = (정사영 길이) × b̂
            = (a⃗·b⃗)/|b⃗| × b⃗/|b⃗|
            = (a⃗·b⃗)/|b⃗|² × b⃗

Step 4: 숫자 대입
  a⃗ = ({{ax}}, {{ay}}), b⃗ = ({{bx}}, {{by}})
  a⃗·b⃗ = {{dot_val}}, |b⃗|² = {{mag_b_sq}}
  proj_b a⃗ = ({{dot_val}}/{{mag_b_sq}}) × ({{bx}}, {{by}})
           = {{scalar}} × ({{bx}}, {{by}})
           = ({{projx}}, {{projy}})
```

**계산 추적 표**:
```
| 단계 | 계산 | 결과 |
|------|------|------|
| a⃗·b⃗ | {{ax}}×{{bx}}+{{ay}}×{{by}} | {{dot_val}} |
| |b⃗|² | {{bx}}²+{{by}}²            | {{mag_b_sq}} |
| 스칼라 | {{dot_val}}/{{mag_b_sq}}   | {{scalar}} |
| proj_b a⃗ | {{scalar}}×({{bx}},{{by}}) | ({{projx}},{{projy}}) |
```

**강의 원고 키포인트**:
```
Step 2 narration:
  "정사영 길이는 |a⃗|cosθ인데,
  θ를 직접 구하기 어려울 때가 많아요.
  내적 공식을 이용하면 cosθ 없이도 계산할 수 있어요."

Step 3 narration:
  "벡터 형태로 만들려면 길이에 방향을 곱해야 하죠.
  b⃗ 방향의 단위벡터 b̂ = b⃗/|b⃗|를 곱하면
  공식이 (a⃗·b⃗)/|b⃗|² × b⃗가 됩니다.
  분모에 |b⃗|²이 나오는 이유예요."
```

### `parabola_derive` — 포물선 방정식 유도

**계산 단계**:
```
Step 1: 정의 제시 + 그림
  초점 F(p, 0), 준선 l: x = -p
  포물선 = 초점과 준선까지 거리가 같은 점의 자취
  점 P(x, y)에 대해: PF = PH  (H는 준선 위 발)

Step 2: 거리 조건 수식화
  PF = √((x-p)² + y²)
  PH = x + p  (x > -p인 경우)
  조건: √((x-p)² + y²) = x + p

Step 3: 양변 제곱 후 정리
  (x-p)² + y² = (x+p)²
  x²-2px+p² + y² = x²+2px+p²
  y² = 4px

Step 4: 결론 및 특징 정리
  y² = 4px  (p > 0이면 오른쪽으로 열림)
  초점: F(p, 0)
  준선: x = -p
  꼭짓점: O(0, 0)
  대칭축: x축
```

**계산 추적 표**:
```
| p 값 | 방정식 | 초점 | 준선 |
|------|--------|------|------|
| 1    | y²=4x  | F(1,0)  | x=-1 |
| 2    | y²=8x  | F(2,0)  | x=-2 |
| 3    | y²=12x | F(3,0)  | x=-3 |
```

**강의 원고 키포인트**:
```
Step 2 narration:
  "거리 조건을 수식으로 쓰면 두 개의 거리가 같아야 해요.
  준선까지 거리 PH는 그냥 x+p입니다.
  준선이 세로선이니까 x좌표 차이만 계산하면 되거든요."

Step 3 narration:
  "양변을 제곱해서 √를 없애요.
  좌변을 전개하면 x²-2px+p²+y²이고,
  우변은 x²+2px+p².
  x²와 p²이 공약소거되고 y²=4px가 나옵니다."

Step 4 narration:
  "p가 클수록 포물선이 넓게 벌어집니다.
  초점 거리가 멀수록 곡선이 완만해지는 거예요."
```

### `ellipse_derive` — 타원 방정식 유도

**계산 단계**:
```
Step 1: 정의 제시 + 그림
  두 초점 F₁(-c, 0), F₂(c, 0)  (c > 0)
  타원 = 두 초점까지 거리의 합이 일정한 점의 자취
  점 P(x, y)에 대해: |PF₁| + |PF₂| = 2a  (a > c)

Step 2: 거리 조건 수식화
  |PF₁| = √((x+c)² + y²)
  |PF₂| = √((x-c)² + y²)
  √((x+c)²+y²) + √((x-c)²+y²) = 2a

Step 3: 한쪽 이항 후 양변 제곱 (2회)
  1차 제곱: (x+c)²+y² = (2a - √((x-c)²+y²))²
  정리: a² - cx = a√((x-c)²+y²)
  2차 제곱: (a²-cx)² = a²((x-c)²+y²)
  전개·정리: a²x² - 2a²cx + a⁴ = a²x²-2a²cx+a²c²+a²y²
  → (a²-c²)x² + a²y² = a²(a²-c²)

Step 4: b² = a²-c² 치환 후 표준형
  b²x² + a²y² = a²b²
  양변을 a²b²로 나누면:
  x²/a² + y²/b² = 1
```

**계산 추적 표**:
```
| a | b (b²=a²-c²) | c | 방정식 | 초점 |
|---|--------------|---|--------|------|
| 5 | 4  (c=3)     | 3 | x²/25+y²/16=1 | F(±3,0) |
| 5 | 3  (c=4)     | 4 | x²/25+y²/9=1  | F(±4,0) |
| 3 | 2  (c=√5)    | √5| x²/9+y²/4=1   | F(±√5,0)|
```

**강의 원고 키포인트**:
```
Step 3 narration:
  "√가 두 개라 계산이 복잡해 보이지만, 요령이 있어요.
  한쪽 √를 이항해서 양변을 제곱하는 걸 두 번 반복합니다.
  결과적으로 a²-c²이 등장하는데, 이게 b²가 됩니다."

Step 4 narration:
  "b² = a²-c²는 타원에서 가장 중요한 관계식입니다.
  직각삼각형으로 기억하세요:
  a(장반축)가 빗변, b(단반축)와 c(초점거리)가 두 변."
```

### `hyperbola_derive` — 쌍곡선 방정식 유도

**계산 단계**:
```
Step 1: 정의 제시 + 그림
  두 초점 F₁(-c, 0), F₂(c, 0)  (c > 0)
  쌍곡선 = 두 초점까지 거리의 차의 절댓값이 일정한 점의 자취
  점 P(x, y)에 대해: ||PF₁| - |PF₂|| = 2a  (0 < a < c)

Step 2: 거리 조건 수식화 (차로 정의)
  |PF₁| - |PF₂| = ±2a
  (± 는 P가 어느 가지에 있느냐에 따라 결정)
  √((x+c)²+y²) - √((x-c)²+y²) = 2a  (오른쪽 가지)

Step 3: 타원 유도와 동일한 방법 적용
  이항 후 1차 제곱: cx - a² = a√((x-c)²+y²)
  2차 제곱 후 전개: (c²-a²)x² - a²y² = a²(c²-a²)
  → c²-a² = b²로 치환

Step 4: 표준형
  x²/a² - y²/b² = 1
  특징:
  - 꼭짓점: A(±a, 0)
  - 초점: F(±c, 0)  (c² = a²+b²)
  - 점근선: y = ±(b/a)x
```

**계산 추적 표**:
```
| a | b (b²=c²-a²) | c | 방정식 | 점근선 |
|---|--------------|---|--------|--------|
| 2 | 2  (c=2√2)   | 2√2 | x²/4-y²/4=1 | y=±x |
| 3 | 4  (c=5)     | 5   | x²/9-y²/16=1 | y=±4x/3 |
| 2 | √2 (c=√6)    | √6  | x²/4-y²/2=1  | y=±x/√2 |
```

**강의 원고 키포인트**:
```
Step 1 narration:
  "타원은 두 거리의 합이 일정, 쌍곡선은 두 거리의 차가 일정합니다.
  공식 하나 차이인데 모양이 완전히 달라져요."

Step 3 narration:
  "유도 방법은 타원과 같아요. 이항하고 제곱을 두 번.
  차이는 c²-a²이 등장한다는 점입니다.
  타원의 b²=a²-c²와 부호가 반대예요.
  쌍곡선에서는 c > a이므로 c²-a²이 양수입니다."

Step 4 narration:
  "점근선 y=±(b/a)x은 쌍곡선이 무한히 가까워지지만 닿지 않는 직선입니다.
  x/a 비율이 기울기를 결정해요."
```

### `space_distance` — 공간에서 두 점 거리

**계산 단계**:
```
Step 1: 평면 두 점 거리 복습
  A(x₁, y₁), B(x₂, y₂)
  AB = √((x₂-x₁)² + (y₂-y₁)²)  (2D 피타고라스)
  "이것을 공간으로 확장합니다"

Step 2: 보조점 설정 (피타고라스 2회 적용)
  A(x₁,y₁,z₁), B(x₂,y₂,z₂)
  보조점 C(x₂,y₂,z₁) 설정
  AC = √((x₂-x₁)²+(y₂-y₁)²)  (xy평면에서 거리)
  CB = |z₂-z₁|                 (z방향 거리)
  AC⊥CB이므로 피타고라스 적용

Step 3: 최종 공식
  AB² = AC² + CB²
       = (x₂-x₁)²+(y₂-y₁)² + (z₂-z₁)²
  AB  = √((x₂-x₁)²+(y₂-y₁)²+(z₂-z₁)²)

  숫자 예시 — A(1,2,3), B(4,6,3+4):
  AB = √((4-1)²+(6-2)²+(7-3)²)
     = √(9+16+16)
     = √41
```

**계산 추적 표**:
```
| 항목 | 계산 | 결과 |
|------|------|------|
| Δx² | ({{x2}}-{{x1}})² | {{dx2}} |
| Δy² | ({{y2}}-{{y1}})² | {{dy2}} |
| Δz² | ({{z2}}-{{z1}})² | {{dz2}} |
| AB  | √({{dx2}}+{{dy2}}+{{dz2}}) | {{dist}} |
```

**강의 원고 키포인트**:
```
Step 2 narration:
  "2D 피타고라스를 3D로 확장하려면 보조점을 하나 잡아요.
  같은 z높이에서 먼저 xy평면 거리를 구하고,
  그 다음 수직으로 z방향 거리를 더하는 겁니다.
  피타고라스 정리를 두 번 쓰는 거예요."

Step 3 narration:
  "공식이 x, y, z 세 방향을 그냥 더하는 형태죠.
  4D, 5D로도 똑같이 확장됩니다.
  머신러닝에서 고차원 거리 계산도 이 원리 그대로예요."
```

### `plane_equation` — 평면의 방정식 유도

**계산 단계**:
```
Step 1: 법선벡터 개념 제시
  평면에 수직인 벡터를 법선벡터라 한다: n⃗ = (a, b, c)
  평면 위의 한 점 P₀(x₀, y₀, z₀)이 주어졌을 때

Step 2: 평면 위 임의의 점 P(x,y,z) 조건
  벡터 P₀P⃗ = (x-x₀, y-y₀, z-z₀)는 평면 위에 있음
  법선벡터 n⃗ ⊥ P₀P⃗  →  내적 = 0
  n⃗ · P₀P⃗ = 0

Step 3: 내적 전개
  (a, b, c) · (x-x₀, y-y₀, z-z₀) = 0
  a(x-x₀) + b(y-y₀) + c(z-z₀) = 0

Step 4: 전개 후 표준형
  ax + by + cz - (ax₀+by₀+cz₀) = 0
  ax + by + cz + d = 0  (d = -(ax₀+by₀+cz₀))

  숫자 예시 — n⃗=(1,2,3), P₀(1,0,-1):
  1(x-1) + 2(y-0) + 3(z+1) = 0
  x + 2y + 3z + 2 = 0
```

**계산 추적 표**:
```
| 법선벡터 n⃗ | 점 P₀ | 평면의 방정식 |
|-----------|-------|-------------|
| (1,0,0) | (2,0,0) | x=2 (yz평면 평행) |
| (0,1,0) | (0,3,0) | y=3 (xz평면 평행) |
| (1,2,3) | (1,0,-1) | x+2y+3z+2=0 |
| (2,-1,1) | (0,1,2) | 2x-y+z-1=0 |
```

**강의 원고 키포인트**:
```
Step 2 narration:
  "평면의 방정식을 구하는 핵심 아이디어는 이것입니다.
  평면 위의 어떤 벡터도 법선벡터와 수직이에요.
  수직 = 내적이 0이라는 조건을 이용합니다."

Step 3 narration:
  "내적을 전개하면 바로 평면의 방정식이 나옵니다.
  a(x-x₀)+b(y-y₀)+c(z-z₀)=0이요.
  법선벡터의 성분 (a,b,c)이 그대로 x,y,z의 계수가 됩니다."
```

### `volume_revolution` — 회전체 부피 개념

**계산 단계**:
```
Step 1: 회전 과정 시각화
  x축을 기준으로 곡선 y=f(x) (a≤x≤b) 회전
  각 x 위치에서 y=f(x)가 반지름인 원이 생긴다
  "곡선이 회전하면 입체가 됩니다"

Step 2: 얇은 원기둥 슬라이스 (미분 발상)
  x 위치에서 두께 dx인 원기둥 단면
  반지름 r = f(x)
  단면 원의 넓이: S(x) = π·[f(x)]²
  두께 dx인 원기둥 부피: dV = S(x)·dx = π[f(x)]²dx

Step 3: 무한히 얇게 쌓아 적분
  V = ∫_a^b π[f(x)]² dx
  "얇은 원기둥을 무한히 쌓는 것 = 적분"

Step 4: 숫자 예시 — y=x (0≤x≤2) 회전
  V = ∫₀² π·x² dx
    = π [x³/3]₀²
    = π × (8/3 - 0)
    = 8π/3
  (원뿔 부피 공식 (1/3)πr²h = (1/3)π×4×2 = 8π/3 와 일치 ✓)
```

**계산 추적 표**:
```
| 곡선 y=f(x) | 구간 | 피적분함수 π[f(x)]² | 부피 V |
|------------|------|---------------------|--------|
| y = x      | [0,2] | πx² | 8π/3 |
| y = √x     | [0,4] | πx  | 8π  |
| y = x²     | [0,1] | πx⁴ | π/5 |
| y = r (상수) | [0,h] | πr² | πr²h (원기둥) |
```

**강의 원고 키포인트**:
```
Step 2 narration:
  "부피를 구하기 어려운 이유는 입체가 복잡하기 때문이에요.
  그래서 아주 얇게 자르는 거예요.
  얇은 원기둥은 넓이 × 두께로 계산하기 쉽거든요."

Step 3 narration:
  "무한히 얇게 자른 것을 무한히 많이 더하는 것이 바로 적분입니다.
  dx가 두께, π[f(x)]²가 단면 넓이예요.
  이 구조를 이해하면 구, 원뿔, 어떤 회전체도 같은 방식으로 풀 수 있어요."

Step 4 narration:
  "y=x를 회전하면 원뿔이에요.
  적분으로 구한 8π/3이 원뿔 공식과 일치하는 걸 보여주면
  공식 암기가 아니라 원리를 이해했다는 걸 확인할 수 있어요."
```

```javascript
function flowVector(lineId, delay = 0, color = '#f39c12') {
  gsap.set('#' + lineId, { strokeDashoffset: 300 });
  gsap.to('#' + lineId, {

  });
```

```javascript
function fillShape(shapeId, delay = 0, fillColor = 'rgba(243,156,18,0.2)') {
  gsap.to('#' + shapeId, {
    opacity: 1,
    duration: 0.6,
    delay,
    ease: 'power1.inOut',
    onStart: function() {
      document.getElementById(shapeId).style.fill = fillColor;
    }
  });
}
```

### 계산 셀 채우기 (기하 전용)
```javascript
function fillGeoCell(id, val, color = '#f39c12') {
  const el = document.getElementById(id);
  if (!el) return;
  gsap.to(el, {
    backgroundColor: 'rgba(52,152,219,0.3)', duration: 0.3,
    onComplete: () => {
      el.textContent = val;
      el.style.color = color;
      el.classList.add('filled');
      gsap.to(el, { backgroundColor: 'transparent', duration: 0.5 });
    }
  });
}
```
