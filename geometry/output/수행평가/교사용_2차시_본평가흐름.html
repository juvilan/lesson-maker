기하 · 수행평가

이차곡선의 광학적 성질 탐구하기

교사용 · 2차시 본평가 흐름
● 평가 시간 · 채점 진행
평가 과제 (학생에게 제시할 발문)
선택한 이차곡선의 수학적 정의와 성질로부터 반사법칙과 맞아떨어지는 광학적 성질을 추론하고, 그 이유를 시뮬레이션으로 설명하시오.
⚠ 평가 환경 — 1차시와 본질적으로 다른 점
2차시는 본평가가 진행되는 시험 시간입니다. 학생 단독 수행, 모둠 협력·공유 발표 없음, 교사는 답을 주지 않습니다. 50분 안에 학생이 처음부터 끝까지 자기 작품을 완성하고 제출해야 합니다.

1 1차시와의 결정적 차이 교사·학생 모두 인지해야 함

1차시 (지난 시간)
워크숍. 모둠 협력 가능, 의도적 오류 예시 함께 분석, 1~2 모둠 발표·공유. 교사는 함께 발견하는 진행자.
2차시 (오늘 · 본평가)
시험. 개인 단독 수행, 학생 간 공유 금지, 발표 없음. 교사는 환경 관리·시간 안내·공정성 유지. 채점 시작.

2 수업 전 준비 시작 5분 전까지 점검

  • 학생 디벗 태블릿 충전 상태 + 크롬 브라우저 정상 작동
  • Gemini 로그인 상태 — 학생 본인 계정으로 로그인했는지
  • 제출 채널 (구글 드라이브 폴더 / 클래스룸 / 패들렛 등) 활성화 + 학생 접근 권한 확인
  • 학생용 프롬프트 가이드를 태블릿에서 다시 열 수 있도록 안내 준비 (1차시 때 본 것)
  • 채점 시트(루브릭 문서의 6번 양식) 학생 수만큼 출력 또는 디지털 양식 준비
  • 1차시 예시 HTML은 학생에게 더 이상 배포하지 않음 — 1차시 때 받은 사본도 복사·재활용 금지임을 알릴 예정

3 2차시 흐름 총 50분 · 본평가

0~5분 도입 — 평가 안내와 곡선 선택 확정 5분

교사 안내

  • 발문 다시 한 번 (강조 박스 그대로 낭독).
  • "오늘은 평가 시간이다. 모둠 활동·발표 없이 각자 작업한다." 명시.
  • 곡선 선택 안내: "1차시는 포물선으로 고정이었지만, 오늘은 세 곡선(포물선·타원·쌍곡선) 중 자유 선택이다. 지금 이 자리에서 최종 확정하고, 시작 후에는 변경 불가."
  • 제출 방법 3가지 환기: ① HTML 파일 / ② 첫 메시지 인적사항 / ③ 대화 공유 URL.
  • 시간 관리: "40분에 제출 안내, 50분에 일괄 마감".
금지 사항 (시작 전 학생에게 분명히)
  • 1차시 예시 HTML을 그대로 또는 일부 복사해서 제출 금지 — 본인 프롬프트로 처음부터 만들어야 함.
  • 다른 학생의 화면·결과물·프롬프트를 보거나 공유 금지.
  • 외부 인터넷 검색을 통한 기존 시뮬레이션 복제 금지 — Gemini 대화만 허용.
  • 친구나 외부에 도움 요청 금지 (메시지·통화 포함).
허용되는 것
  • 학생용 프롬프트 가이드(1차시 때 본 그 문서) 다시 열어보기.
  • 교과서·자신의 노트 참조 (수학적 정의·성질 확인용).
  • Gemini와의 여러 차례 수정 대화 — 완벽한 첫 시도보다 다듬는 과정이 중요.
"오늘은 채점이 시작되는 시간입니다. 1차시처럼 모둠으로 얘기하지 않고, 각자의 작품을 만듭니다. 곡선은 지금 이 순간에 최종 결정하세요."
5~12분 개인 추론 정리 — Gemini를 열기 전 단계 7분

학생 활동 (각자 노트 또는 디지털 메모)

  • 선택한 곡선의 수학적 정의를 수식과 언어로 적기.
  • 접선의 이등분 성질을 떠올리기 (포물선: ∠FPH 이등분 / 타원: 외각 / 쌍곡선: 내각).
  • 예상되는 광학적 성질을 추론 — 어떤 빛이 어디로 가는가.
  • 시뮬에 들어가야 할 표시 요소 목록화 (접선·법선·각도·정의 보조선 등).

교사 행동

  • 조용히 순회. 설명·지도 금지. 학생이 멍하니 있으면 학생용 가이드의 "직접 써야 할 4가지" 항목을 손으로 짚어주는 정도까지만.
  • "답을 알려달라"는 요청은 정중히 거절: "그건 평가의 핵심이라 알려줄 수 없어요. 가이드 다시 한 번 보세요."
  • 학생들 사이의 대화가 발생하면 즉시 분리.
이 단계의 의미
Gemini를 켜자마자 막연하게 "타원의 광학적 성질을 보여줘"라고 적는 학생을 막기 위함. 추론을 먼저 정리한 학생은 프롬프트의 질이 다르다. 차원 D(프롬프트·대화)와 차원 B(추론)에 직접 영향.
12~40분 프롬프트 작성 · 시뮬 생성 · 다듬기 28분

학생 활동

  1. Gemini 새 대화 시작 — 첫 메시지에 인적사항(학년·반·번호·이름) 기재.
  2. 준비한 추론을 바탕으로 첫 프롬프트 작성 (고정 문구 + 4가지 직접 쓸 부분).
  3. 결과 HTML 확인 → 다운로드하여 브라우저에서 직접 작동 점검.
  4. 오류·부족함 발견 → 수정 프롬프트로 다시 요청 (반복 가능).
  5. 30분 시점에 "이쯤이면 제출해도 될까" 자기 점검.

교사 행동

  • 순회 + 시간 안내가 주 역할. 25분 / 35분 시점에 남은 시간 공지.
  • 기술적 문제(태블릿 멈춤, 로그인 오류, Gemini 응답 지연 등)만 직접 해결.
  • 수학적 내용·추론·프롬프트 작성에 대한 직접 지도는 하지 않음. "가이드 다시 보세요" 정도까지만.
  • 1차시 예시를 화면에 띄워놓고 그대로 베끼는 학생 발견 시 주의 + 채점 시 차원 D 감점 명시.
  • 학생 간 화면 엿보기·대화 발견 시 즉시 분리·기록.
"막힌다고 손 들지 마세요. 가이드가 답을 알려주는 게 아니라 방향을 잡아줍니다. 한 번 더 읽어보세요."
시간 관리 팁
12~25분: 첫 프롬프트와 1차 결과. 25~35분: 수정·다듬기. 35~40분: 최종 점검과 제출 준비. 15분 안에 완벽한 결과가 나온 학생은 의심해볼 만함 — 1차시 예시 복사 가능성, 또는 너무 단순한 결과물.
40~50분 제출 — 마지막 점검과 마감 10분

학생 활동

  1. HTML 파일 다운로드 (파일명에 본인 정보 포함 권장: 2-3-15_홍길동_타원.html 등 — 학교 양식 따름).
  2. Gemini 대화의 공유 링크 생성 → URL 복사.
  3. 제출 채널에 HTML 파일 + 공유 URL 함께 업로드.
  4. 제출 완료 확인 → 자리 정리.

교사 행동

  • 40분 시점에 "이제 제출 단계입니다" 공지.
  • 제출 채널에 파일이 들어오는지 실시간 확인.
  • 45분 / 48분 시점에 잔여 시간 카운트다운.
  • 50분: 일괄 마감. 미제출 학생 별도 메모.
"파일 이름에 본인 정보가 들어가 있는지 한 번만 더 확인하세요. 대화 공유 URL도 빠뜨리지 마세요."

4 교사 역할 vs 학생 활동 한눈에 정리

교사가 할 일

  • 평가 환경 유지 (조용함·집중·공정성)
  • 시간 안내 (25분·35분·40분·45분 시점)
  • 기술적 문제 즉각 해결 (태블릿·네트워크·Gemini)
  • 금지 행위 발견 시 주의·분리·기록
  • 제출 채널 실시간 모니터링
  • 가이드 위치 안내 (열어볼 수 있도록만)

교사가 하지 않을 일

  • 수학적 내용·정의·성질에 대한 설명
  • 프롬프트 어떻게 쓸지 직접 지도
  • 시뮬에 무엇을 넣을지 알려주기
  • Gemini 결과의 오류 지적해주기
  • 학생끼리 의논하도록 유도
  • 특정 학생에게만 시간 연장

5 예상 상황과 대응

"막혀서 못 하겠어요"

"답을 알려줄 수는 없어요. 가이드의 4가지 항목 중 어디서 막혔는지만 말해보세요." → 학생이 "정의를 모르겠어요"라고 답하면 교과서 페이지만 안내. 추론 자체는 본인이 해야 함을 명확히.

"Gemini가 자꾸 이상한 걸 만들어요"

"1차시에서 했던 것처럼 어디가 잘못됐는지 적어서 다시 요청해보세요." → 수정 능력은 차원 D 평가의 일부.

"시간이 부족해요"

원칙적으로 시간 연장 없음. 학생에게 "지금까지 작업한 것을 제출하세요. 미완성도 평가 대상이며 점수가 차등 적용됩니다." 안내. 형평성 유지가 우선.

"태블릿 문제 / Gemini 응답 지연"

실제 기술적 문제로 확인되면 해당 학생만큼의 시간을 별도 기록하고, 수업 후 보충 시간 부여 검토. 전반적 네트워크 장애 시 일괄 연장.

"1차시 예시를 그대로 복사한 흔적 발견"

대화 URL을 채점 시 확인. 학생 본인의 추론·프롬프트가 보이지 않으면 차원 D 미흡 처리. 명백한 복사는 별도 조치.

"옆 학생과 얘기하거나 화면 들여다봄"

1회: 구두 주의. 2회: 자리 분리. 반복: 평가 부정행위로 기록·별도 조치.

6 평가 종료 후

  • 미제출·미완성 학생 명단 별도 정리 → 보충 시간 또는 사후 처리 검토.
  • 모든 제출물(HTML + 대화 URL) 1주일 내 채점 완료를 학생들에게 약속.
  • 채점은 별도 시간에 교사용 채점 기준 루브릭 문서를 기준으로 진행 (학생 1명당 채점 시트 1장).
  • 피드백은 학생용 한 줄 코멘트 + 차원별 점수 형태로 돌려줌. 모범 결과물은 차후 수업에 예시로 활용 가능 (학생 동의 시).
루브릭 연결
채점은 4차원 × 3단계 = 총 12점 루브릭 기준. 자세한 채점 가이드는 별도 문서 "교사용 채점 기준(루브릭)" 참조. 본 문서와 분리되어 있는 이유는 채점 기준이 학생에게 공개되지 않기 때문.
