이차곡선의 접선

포물선 · 타원 · 쌍곡선의 접선 방정식

🔵

포물선

\(y^2 = 4px\)
🟢

타원

\(\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1\)
🔴

쌍곡선

\(\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1\)

학습 목표

  • 포물선 \(y^2=4px\)의 위의 점 및 기울기를 이용한 접선 방정식을 구할 수 있다.
  • 타원 \(\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1\)의 위의 점 및 기울기를 이용한 접선 방정식을 구할 수 있다.
  • 쌍곡선 \(\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1\)의 위의 점 및 기울기를 이용한 접선 방정식을 구할 수 있다.
  • 이차곡선 밖의 점에서 그은 접선의 방정식을 구하는 방법을 이해한다.
  • 판별식 \(D=0\) 조건이 접선 공식 유도에서 어떻게 쓰이는지 설명할 수 있다.
핵심 원리: 이차곡선과 직선을 연립한 이차방정식의 판별식 \(D=0\)이면 직선이 곡선에 접한다.

포물선 반사판

위성 안테나·전파망원경의 반사면은 포물선. 신호는 접선 방향으로 반사된다.
🛸

위성 궤도 이탈

타원 궤도를 도는 위성이 점화 후 이탈하는 방향 = 그 순간 궤도의 접선 방향.
🔊

음파 렌즈 (타원방)

타원의 한 초점에서 나온 소리가 반사되어 다른 초점에 모인다 — 접선과 법선의 원리.
접선(Tangent)이란? 곡선 위의 한 점에서 그 점에만 닿는(한 점에서 만나는) 직선. 미분의 언어로는 그 점에서의 순간 기울기를 가진 직선.

할선 → 접선: 극한으로서의 접선

← 0으로 줄이면 접선
할선(Secant): 곡선 위 두 점을 지나는 직선
두 점이 가까워질수록 → 접선
포물선 \(y^2=4x\) 위의 점 \(P(t^2, 2t)\)
접선 기울기 \(= \dfrac{1}{t}\) (t→2일 때 \(\frac{1}{2}\))
Δt를 0으로 줄이면 두 점이 합쳐져 접선이 됩니다.

포물선 위의 점에서의 접선 유도

포물선 \(y^2 = 4px\), 위의 점 \(\mathrm{P}(x_1, y_1)\)에서의 접선
Step 1 — 접선 가정
포물선 위 점 \(P(x_1, y_1)\)을 지나는 접선: \(y - y_1 = m(x - x_1)\)
Step 2 — 판별식 D = 0 조건
접선식을 \(y^2=4px\)에 대입하면 이차방정식이 나온다.
접선 조건 \(D = 0\) 적용 → \(m = \dfrac{2p}{y_1}\)
Step 3 — 공식 도출
\(m = \dfrac{2p}{y_1}\) 을 접선식에 대입하여 정리하면:
\[\boxed{y_1 y = 2p(x + x_1)}\] 단, \(y_1^2 = 4px_1\) (점이 포물선 위에 있음)

예제: 포물선 위의 점에서 접선 계산

포물선 \(y^2 = 8x\) 위의 점 \((2, 4)\)에서의 접선 방정식을 구하시오.
Step 1 — 조건 확인
\(y^2 = 8x\)이면 \(4p = 8\), 즉 \(p = 2\)
점 확인: \(4^2 = 16 = 8 \times 2\) ✓ (포물선 위의 점)
Step 2 — 공식 대입
\(y_1 = 4,\ x_1 = 2,\ p = 2\)
\(y_1 y = 2p(x + x_1)\) 에 대입:
\(4y = 2 \times 2 \times (x + 2) = 4(x+2)\)
Step 3 — 결론
접선의 방정식: \[\boxed{y = x + 2}\] 기울기 \(m = 1\), y절편 \(= 2\)

타원 위의 점에서의 접선 유도

타원 \(\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1\), 위의 점 \(\mathrm{P}(x_1, y_1)\)에서의 접선
Step 1 — 접선 가정
점 \(P(x_1, y_1)\)을 지나는 접선: \(y - y_1 = m(x - x_1)\)
Step 2 — D = 0 조건 적용
접선식을 타원에 대입하면 \(x\)에 대한 이차방정식.
\(D = 0\)에서 \(m = -\dfrac{b^2 x_1}{a^2 y_1}\) 을 얻는다.
Step 3 — 공식 도출
대입 후 \(\dfrac{x_1^2}{a^2}+\dfrac{y_1^2}{b^2}=1\) 이용하여 정리:
\[\boxed{\dfrac{x_1 x}{a^2}+\dfrac{y_1 y}{b^2}=1}\] 기울기형: \(y = mx \pm \sqrt{a^2m^2+b^2}\)
0 / 3

예제: 타원 위의 점에서 접선 계산

타원 \(\dfrac{x^2}{16}+\dfrac{y^2}{9}=1\) 위의 점 \(\left(2,\ \dfrac{3\sqrt{3}}{2}\right)\)에서의 접선
풀이
\(a^2 = 16,\ b^2 = 9\)
\(x_1 = 2,\ y_1 = \dfrac{3\sqrt{3}}{2}\)
공식 적용:
\(\dfrac{2x}{16} + \dfrac{\frac{3\sqrt{3}}{2} \cdot y}{9} = 1\)
\(\dfrac{x}{8} + \dfrac{\sqrt{3}}{6}y = 1\)
\[ \boxed{\dfrac{x}{8} + \dfrac{\sqrt{3}\,y}{6} = 1} \]
점이 타원 위에 있는지 먼저 확인! \(\dfrac{4}{16}+\dfrac{27/4}{9}=\dfrac{1}{4}+\dfrac{3}{4}=1\) ✓

쌍곡선 위의 점에서의 접선 유도

쌍곡선 \(\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1\), 위의 점 \(\mathrm{P}(x_1, y_1)\)에서의 접선
Step 1 — 접선 가정
점 \(P(x_1, y_1)\)을 지나는 접선: \(y - y_1 = m(x - x_1)\)
Step 2 — D = 0 조건 적용
접선식을 쌍곡선에 대입 → \(x\)에 대한 이차방정식.
타원과 달리 \(y^2\) 부호가 음 → \(D = 0\)에서
\(m = \dfrac{b^2 x_1}{a^2 y_1}\) 을 얻는다.
Step 3 — 공식 도출
\(\dfrac{x_1^2}{a^2}-\dfrac{y_1^2}{b^2}=1\) 이용하여 정리:
\[\boxed{\dfrac{x_1 x}{a^2}-\dfrac{y_1 y}{b^2}=1}\] 기울기형: \(y = mx \pm \sqrt{a^2m^2-b^2}\) (단, \(a^2m^2 > b^2\))
0 / 3

예제: 쌍곡선 위의 점에서 접선 계산

쌍곡선 \(\dfrac{x^2}{4}-\dfrac{y^2}{3}=1\) 위의 점 \((2, 0)\)에서의 접선
풀이
\(a^2 = 4,\ b^2 = 3\)
\(x_1 = 2,\ y_1 = 0\)
\(y_1 = 0\)이면 점 P가 x축 위에 있으므로
접선: \(x = a\) 또는 \(x = -a\)
점 \((2, 0)\)이 꼭짓점이므로 접선: \(x = 2\)
\[ \boxed{x = 2} \]
공식 대입: \(\dfrac{2 \cdot x}{4} - \dfrac{0 \cdot y}{3} = 1\)
\(\Rightarrow \dfrac{x}{2} = 1 \Rightarrow x = 2\)
꼭짓점에서의 접선은 수직선! 기울기형 공식 사용 불가.

기울기가 주어진 포물선의 접선

포물선 \(y^2=8x\)에서 기울기 \(m=2\)인 접선의 방정식을 구하시오.
Step 1 — 공식 확인
\(y^2 = 8x\)에서 \(p = 2\)
기울기형 공식: \(y = mx + \dfrac{p}{m}\) (단, \(m \neq 0\))
Step 2 — 대입 계산
\(m = 2,\ p = 2\):
\(y = 2x + \dfrac{2}{2} = 2x + 1\)
Step 3 — 접점 확인
접점: \(\left(\dfrac{p}{m^2},\ \dfrac{2p}{m}\right) = \left(\dfrac{2}{4},\ \dfrac{4}{2}\right) = \left(\dfrac{1}{2},\ 2\right)\)
검증: \(2^2 = 4 = 8 \times \dfrac{1}{2}\) ✓
\[\boxed{y = 2x + 1}\]

기울기가 주어진 타원의 접선

타원 \(\dfrac{x^2}{4}+\dfrac{y^2}{3}=1\)에서 기울기가 1인 접선의 방정식을 구하시오.
풀이
\(a^2 = 4,\ b^2 = 3,\ m = 1\)
기울기형 공식:
\(y = mx \pm \sqrt{a^2m^2 + b^2}\)
대입:
\(y = x \pm \sqrt{4 \cdot 1 + 3}\)
\(y = x \pm \sqrt{7}\)
\[\boxed{y = x + \sqrt{7} \quad \text{또는} \quad y = x - \sqrt{7}}\]
구분수식결과
\(a^2m^2\)\(4 \times 1^2\)4
\(+\ b^2\)\(+\ 3\)7
\(\sqrt{\cdots}\)\(\sqrt{7}\)\(\approx 2.65\)

이차곡선 밖의 점에서의 접선

포물선 \(y^2 = 4x\) 밖의 점 \((2, 4)\)에서 그은 접선의 방정식을 모두 구하시오.
풀이 전략
접점을 \(P(x_1, y_1)\)으로 놓으면 접선 방정식:
\(y_1 y = 2(x + x_1)\)   … ①
이 직선이 점 \((2, 4)\)를 지나므로:
\(4y_1 = 2(2 + x_1)\)
\(2y_1 = 2 + x_1\)   … ②
점 \(P\)가 포물선 위에 있으므로:
\(y_1^2 = 4x_1\)   … ③
연립 풀기
②에서 \(x_1 = 2y_1 - 2\), ③에 대입:
\(y_1^2 = 4(2y_1 - 2) = 8y_1 - 8\)
\(y_1^2 - 8y_1 + 8 = 0\)
\(y_1 = 4 \pm 2\sqrt{2}\)
접선: \(y = (2+\sqrt{2})x - 4\sqrt{2} + 4\)
   \(y = (2-\sqrt{2})x + 4\sqrt{2} + 4\)
곡선 밖 점 → 접선이 2개 존재하는 경우가 일반적!

이차곡선 접선 공식 총정리

이차곡선 방정식 위의 점 P(x₁,y₁)에서의 접선 기울기 m인 접선
포물선 \(y^2 = 4px\) \(y_1 y = 2p(x + x_1)\) \(y = mx + \dfrac{p}{m}\)
타원 \(\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1\) \(\dfrac{x_1 x}{a^2}+\dfrac{y_1 y}{b^2}=1\) \(y = mx \pm \sqrt{a^2m^2+b^2}\)
쌍곡선 \(\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1\) \(\dfrac{x_1 x}{a^2}-\dfrac{y_1 y}{b^2}=1\) \(y = mx \pm \sqrt{a^2m^2-b^2}\)
(단, \(a^2m^2>b^2\))
공통 패턴: 위의 점 공식에서 \(x^2 \to x_1 x\), \(y^2 \to y_1 y\)로 교체하면 접선 공식이 된다.

연습 문제

Q. 포물선 \(y^2 = 12x\) 위의 점 \((3, 6)\)에서의 접선 방정식을 구하시오.
힌트: \(y^2 = 12x\)이면 \(4p = 12\), 즉 \(p = ?\)
풀이:
\(y^2 = 12x\)이면 \(p = 3\)
점 확인: \(6^2 = 36 = 12 \times 3\) ✓
공식 \(y_1 y = 2p(x+x_1)\)에 대입:
\(6y = 6(x+3)\)
\[\boxed{y = x + 3}\]
