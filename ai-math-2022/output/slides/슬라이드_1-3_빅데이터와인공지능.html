AI 파이프라인 — 1~2단계

수집 → 가공

📥 1단계: 수집
  • 🌡️ IoT 센서 (온도, 습도, 위치)
  • 📱 소셜미디어 게시글/댓글
  • 🏥 의료 기기 측정값
  • 🛰️ 위성 이미지 데이터
🔧 2단계: 가공
  • ❓ 결측값(NaN) 처리
  • 📉 이상치(outlier) 제거
  • 📏 정규화(normalization)
  • 🏷️ 레이블(정답) 부여
💡 AI 프로젝트의 80% 시간이 데이터 가공
🍳 비유: 요리 재료 손질 — 좋은 재료 없이는 맛있는 음식을 만들 수 없다
"AI 개발자의 대부분 시간이 데이터 가공에 쏠립니다. 학생들이 놀라는 포인트예요."
AI 파이프라인 — 3단계

분석과 모델 제작

🧠 무엇을 하나?
  • 📊 탐색적 데이터 분석(EDA) — 패턴 탐색
  • 🎯 학습 알고리즘 선택
    (지도학습 / 비지도학습 / 강화학습)
  • ⚙️ 모델 학습 (가중치 최적화)
"모델 = 데이터에서 패턴을 학습한 함수"
신경망 모델 구조 예시
신경망은 이미 배웠으니 간략히 리마인드. "모델 = 함수"라는 개념 강조.
AI 파이프라인 — 4~5단계

예측 → 평가 / 의사결정

🔮 4단계: 예측
  • 새 데이터에 학습된 모델 적용
  • 분류: 스팸인가 아닌가?
  • 수치 예측: 내일 주가는?
  • 생성: 이 이미지에 맞는 문장은?
📊 5단계: 평가 / 의사결정
  • 정확도(Accuracy) 검증
  • 실제 환경(현장) 테스트
  • 전문가 검토
⚠️ AI가 예측해도 최종 결정은 사람이!
AI는 의사결정 도구이지, 의사결정 주체가 아님
"특히 의료·법률·금융 분야에서 AI의 판단을 그대로 따르면 위험할 수 있습니다."
실생활 사례 ①

신약 개발 — AI로 10년을 단축

😰 기존 방식
신약 개발 기간: 10~15년
개발 비용: 1조 원 이상
성공률: 0.02% 미만
🤖 AI 활용 후
단백질 구조 예측 → 후보 물질 탐색
DeepMind의 AlphaFold
2억 개 이상 단백질 구조 예측 성공
🔬 파이프라인 연결
📥 수집: 수백만 개 단백질 데이터
🔧 가공: 아미노산 서열 정제
🧠 분석: 딥러닝 구조 예측 모델
🔮 예측: 신약 후보 물질 효과
📊 평가: 임상 시험 검증
"AlphaFold는 과학계에서 50년 넘게 못 풀던 단백질 구조 예측 문제를 AI로 해결했습니다."
실생활 사례 ②

AI 번역기 — 규칙에서 데이터로

📚 기존 번역기
문법 규칙을 사람이 직접 작성
→ 어색하고 문맥 이해 못 함
예: "It's raining cats and dogs"
→ "고양이와 개가 비처럼 내린다" ❌
🤖 AI 번역기
수억 개 번역 쌍 학습 → 문맥 이해
Transformer (2017) → GPT, DeepL, 파파고
→ "비가 엄청 쏟아진다" ✓
📊 데이터의 힘
수억 개 번역 쌍 데이터
↓
패턴 학습 (Transformer)
↓
문맥 이해 번역
한계: 문화적 뉘앙스, 고유어 번역 오류 여전히 존재
"파파고, 구글 번역기 다 이 원리입니다. 학생들이 매일 쓰는 도구를 예시로 들면 좋아해요."

→ 여성 지원자 점수 자동 감점

→ 해당 그룹 진단 정확도 ↓

AI 공정성

AI 편향의 원인과 해결

⚠️ 편향의 원인
① 학습 데이터 편향

③ 피드백 편향
편향된 결과 → 더 많은 편향 데이터 생성
✅ 해결 방향
🌍 다양한 데이터 수집
다양한 성별·인종·연령 데이터 포함
🔍 편향 탐지 알고리즘
AI 공정성 지표 자동 검사
👥 인간 검토 프로세스
전문가·시민 패널 검토
📋 AI 윤리 가이드라인
EU AI Act 등 규제 마련
