1-1 인공지능의 의미 — 강의 대본

인공지능수학 | 고2 | 총 45분 | 슬라이드 15장

S1 표지 ~1분
"자, 오늘부터 인공지능수학 1단원을 시작하겠습니다.
단원 제목이 '인공지능의 의미'인데요.
여러분 스마트폰 잠금 해제할 때 얼굴 인식 쓰는 분 있죠? 그게 바로 AI예요.
오늘은 그 AI가 뭔지, 어떻게 작동하는지 수학적으로 이해해보겠습니다."
수업 시작 분위기 만들기. 가벼운 질문으로 시작해 긴장 풀어주세요.
S2 학습 목표 ~2분
"오늘 수업이 끝나면 세 가지를 할 수 있어야 해요.
첫 번째, AI가 기존 프로그래밍과 어떻게 다른지 설명할 수 있고,
두 번째, 데이터를 종류별로 분류할 수 있고,
세 번째, 퍼셉트론이라는 인공 뉴런에서 가중합 계산을 직접 할 수 있어야 합니다.
마지막 거 계산 시험에 나올 수 있으니까 꼭 잡아가세요."
S3 생각열기 — 일상 속 AI ~4분
"여러분, 오늘 아침에 유튜브나 넷플릭스 뭔가 추천받은 분 있어요?
그거 어떻게 추천하는 거 같아요?"
학생 반응 유도 — 10~15초 기다리기
"맞아요. 내가 본 영상 기록을 분석해서 추천해주죠.
그럼 챗봇은요? 챗GPT한테 질문하면 답이 나오잖아요.
이걸 어떻게 만들었을까요?
이 기계들은 어떻게 우리 말을 이해하고 학습할까요?
오늘 수업에서 그 원리의 출발점을 배웁니다."
슬라이드의 두 예시(챗봇, 추천 시스템)를 가리키며 설명하세요.
S4 AI 정의 ~6분
"AI의 공식 정의를 먼저 보겠습니다.
1956년 존 매카시라는 분이 이렇게 정의했어요.
'인간의 지능적 행동을 컴퓨터로 구현하는 기술'
그 해에 다트머스 회의에서 AI라는 용어 자체가 처음 만들어졌습니다."
"그런데 AI가 기존 프로그래밍과 뭐가 다르냐고요?
보세요. 기존 프로그래밍은: 입력 + 규칙 → 결과예요.
예를 들어 스팸 필터를 만든다고 하면,
프로그래머가 직접 '광고', '무료' 이런 단어 있으면 스팸이라고 규칙을 써요.
그런데 스팸이 매일 바뀌잖아요. 규칙을 계속 업데이트해야 하죠."
"기계학습은 반대입니다.
스팸 메일 100만 건을 줘요. 그러면 AI가 패턴을 스스로 찾아요.
이게 패러다임의 차이입니다.
핵심: AI는 데이터에서 규칙을 스스로 학습한다."
S5 데이터 분류 트리 ~9분
"AI는 데이터로 학습한다고 했죠. 그럼 데이터가 뭔지부터 알아야겠죠?
데이터를 크게 두 종류로 나눕니다. 정형 데이터와 비정형 데이터."
"정형 데이터는 쉽게 말해 표에 담을 수 있는 데이터예요.
학생 성적표 있죠? 이름, 국어점수, 수학점수 이런 식으로 표로 정리되잖아요.
그게 정형 데이터입니다.
반면에 비정형 데이터는 표에 담을 수 없어요.
여러분 찍은 사진, SNS에 쓴 글, 음성 파일 — 이건 표 한 칸에 못 넣잖아요."
"정형 데이터 안에서도 또 나뉩니다.
수치형은 숫자로 연산이 되는 것 — 키, 나이, 점수.
범주형은 이름만 있는 것 — 성별, 혈액형, 지역.
이 분류 트리를 머릿속에 그려두세요. 시험에 나옵니다."
S6 정형/비정형 데이터 예시 ~11분
"실제 예시를 볼게요.
왼쪽 성적표 보이죠? 이름, 점수 — 전형적인 정형 데이터입니다.
기상 관측 데이터도 마찬가지예요. 기온 24.5도, 습도 67% — 표에 딱 들어가죠."
"오른쪽 비정형 보세요.
SNS 글 '오늘 너무 맛있었어~' — 이걸 표 한 칸에 넣기가 어렵죠.
X-ray 이미지는 수백만 픽셀 데이터인데, 이걸 표로 정리하면 의미가 없어요.
음성 파일도 마찬가지입니다."
학생들이 SNS 쓴다는 걸 활용해서 친근하게 접근하세요.
S7 수치형 / 범주형 ~13분
"수치형과 범주형, 구분법이 뭐냐고요?
딱 하나만 기억하세요: 연산이 의미가 있냐 없냐."
"키 173cm와 165cm의 평균은 169cm. 의미 있죠? → 수치형.
그런데 혈액형 A형과 B형의 평균은요? A+B 나누기 2 = ?
의미가 없잖아요. → 범주형."
잠깐, 주소(서울, 부산)는 수치형일까요 범주형일까요?
범주형. 서울+부산÷2 는 의미 없음.
"주의할 점이 있어요.
범주형을 숫자로 코딩하는 경우가 있어요. A=1, B=2, O=3, AB=4 이렇게요.
하지만 코딩했다고 수치형이 되는 게 아닙니다.
A(1)이 B(2)보다 반이다? — 이 말이 의미 없잖아요."
S8 기계학습 — 패러다임 전환 ~17분
"다시 기계학습 이야기로 넘어갈게요.
기존 프로그래밍은 규칙을 우리가 직접 써요.
'이런 단어가 있으면 스팸' 이런 식으로요.
그런데 스팸 종류가 매일 바뀌면? 규칙을 계속 고쳐야 하죠. 힘들어요."
"머신러닝은 반대입니다.
스팸 메일 100만 건을 주면, AI가 규칙을 스스로 찾아요.
우리는 데이터와 정답(스팸이냐 아니냐)만 주면 됩니다."
"아래 훈련 루프를 보세요.
데이터 입력 → 예측 → 오차 계산 → 가중치 조정 → 반복.
이 루프가 학습의 본질입니다.
예측하고, 틀리면, 가중치를 조금 고치고, 다시 예측하고.
이걸 수만 번 반복하면 점점 정확해지는 거예요."
S9 3가지 학습 방식 ~19분
"기계학습을 학습 방식에 따라 세 가지로 나눕니다.
지도학습, 비지도학습, 강화학습."
"지도학습은 선생님이 있는 공부예요.
정답이 있는 데이터로 학습합니다.
스팸이면 1, 아니면 0 — 이런 레이블이 붙은 데이터로 배우는 거예요.
이미지 분류, 집값 예측 모두 지도학습이에요."
"비지도학습은 혼자 공부하는 거예요.
정답 레이블 없이 데이터 자체에서 패턴을 찾아요.
고객 100만 명의 구매 패턴을 넣어주면, AI가 스스로 비슷한 고객끼리 묶어요.
이게 군집화(클러스터링)입니다."
"강화학습은 게임을 잘하는 법을 터득하는 것과 같아요.
시도해보고, 좋은 결과가 나오면 보상, 나쁜 결과면 패널티.
알파고가 이 방식으로 바둑을 배웠습니다."
학생들에게 스마트폰의 어떤 기능이 각 학습 방식인지 물어보세요. 참여도 상승.
S10 딥러닝과 퍼셉트론 ~23분
"이제 딥러닝의 기본 단위인 퍼셉트론을 배울 거예요.
퍼셉트론은 우리 뇌의 뉴런을 모델로 만든 거예요."
"생물학적 뉴런을 보세요.
수상돌기로 신호를 받고, 세포체에서 통합해서, 축삭을 통해 다음 뉴런으로 전달해요.
임계값 이상이면 발화, 미만이면 침묵."
"인공 뉴런, 즉 퍼셉트론도 똑같은 구조예요.
오른쪽 다이어그램을 보세요.
x₁, x₂가 입력이고, w₁, w₂가 가중치, b가 편향이에요.
Σ 노드에서 가중합을 구하고, 활성화 함수 f(z)를 거쳐 출력 y가 나옵니다.
다음 슬라이드에서 직접 계산해볼 거예요."
S11 가중합 계산 (단계별) ~27분
"자, 이제 직접 계산해봅시다.
w₁=0.5, w₂=0.5, 편향 b=−0.7로 고정하겠습니다."
클릭 1 (또는 N 키)
"Step 1: 입력값을 x₁=1, x₂=1로 설정합니다.
AND 게이트에서 '둘 다 1'인 경우라고 생각해도 돼요."
클릭 2
"Step 2: 가중합을 계산합니다.
z = w₁×x₁ + w₂×x₂ + b
= 0.5×1 + 0.5×1 + (−0.7)
= 0.5 + 0.5 − 0.7
= 0.3"
클릭 3
"Step 3: 계단함수를 적용합니다.
z = 0.3, 0보다 크거나 같죠? → y = 1. 발화!"
"여기서 잠깐. x₁=1, x₂=0이면 어떻게 될까요?
z = 0.5×1 + 0.5×0 + (−0.7) = −0.2
0보다 작으니까 y = 0. 침묵.
이렇게 이 퍼셉트론은 둘 다 1일 때만 1을 출력해요. AND 게이트예요."
학습지 6번 문제와 연결하여 설명하세요. "이게 바로 학습지 6번 문제입니다."
S12 계단함수 ~30분
"방금 쓴 계단함수, 정확히 정의해볼게요.
z가 0 이상이면 y=1, 0 미만이면 y=0.
오른쪽 그래프처럼 딱 떨어지는 함수입니다."
"계단함수는 직관적이에요.
임계값 이상이면 켜지고, 미만이면 꺼지는 스위치 같은 거죠.
그런데 결정적인 단점이 있어요."
"z=0에서 불연속이에요.
미분이 안 된다는 말이에요.
왜 미분이 중요하냐고요?
AI를 학습시키는 '역전파'라는 방법이 미분에 기반하거든요.
미분 안 되면 학습 못 해요. 이게 계단함수의 한계입니다."
S13 다양한 활성화 함수 비교 ~33분
"그래서 계단함수 대신 다른 함수들을 씁니다.
그래프에서 네 함수를 비교해보세요."
"시그모이드 함수는 계단함수를 부드럽게 만든 거예요.
0과 1 사이 값을 출력하고, 어디서든 미분이 돼요.
한동안 많이 쓰였는데, 층이 깊어지면 기울기가 0에 가까워지는 '기울기 소실' 문제가 있어요."
"ReLU는 요즘 가장 많이 쓰는 활성화 함수예요.
z가 0보다 크면 그냥 통과, 0 이하면 0.
계산이 단순하고 빠르고, 기울기 소실 문제도 적어요.
현재 딥러닝의 기본 선택지입니다."
"오른쪽 세 가지 역할 박스가 핵심이에요.
비선형성, 미분 가능성, 계산 효율 — 이 세 가지를 기억하세요."
S14 확인 문제 ~41분
"자, 오늘 내용 확인 문제 두 개 풀어봅시다.
2~3분 주겠습니다. 혼자 먼저 해보세요."
학생에게 2분 개별 풀이 시간 주기
"문제 1 — AI의 정의.
'인간의 지능적 행동을 컴퓨터로 구현하는 기술'이 핵심이에요.
자기 말로 쓰는 거라서 정확한 단어보다 개념을 이해했냐가 중요해요."
"문제 2 — 데이터 분류.
키(175cm): 정형 / 수치형.
음성 파일: 비정형 — 수치형/범주형 구분 없음.
혈액형(B형): 정형 / 범주형.
SNS 게시글: 비정형 — 수치형/범주형 없음.
이 네 가지 확인하세요."
S15 단원 정리 ~45분
"오늘 배운 핵심을 네 가지로 정리합니다."
"첫째, AI: 데이터로부터 규칙을 스스로 학습하는 기술.
둘째, 데이터: 정형(수치형, 범주형) vs 비정형(텍스트, 이미지, 영상).
셋째, 학습 방식: 지도(정답 있음) / 비지도(정답 없음) / 강화(보상).
넷째, 퍼셉트론 수식: z = Σwᵢxᵢ + b, 활성화 함수 거쳐 y 출력."
"특히 퍼셉트론 계산은 다음 시간에도 계속 써요.
슬라이드 11에서 한 것처럼 w, x, b 넣어서 z 구하고, 계단함수나 시그모이드로 y 구하는 거 — 연습해 오세요.
학습지 6번 꼭 혼자 풀어보고, 다음 시간에 확인하겠습니다.
오늘 수업 마치겠습니다."
