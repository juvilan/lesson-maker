### ✅ 정정 (2026-08-25) — step-box 는 고장 나 있지 않았다

2026-08-24에 "공유 CSS 의 step-box 전이가 Reveal 의 display 토글과 겹쳐 펼쳐지지 않는다"고
진단해 커밋(`0dad0db`)했는데 **이 진단은 틀렸습니다.**

진짜 원인은 검증에 쓰던 **브라우저 창이 `document.visibilityState === "hidden"`** 이었던 것입니다.
크롬은 숨겨진 문서에서 CSS 전이를 시작하지 않아, 클래스는 붙었는데 계산 스타일이
시작 값에 머물렀습니다. 같은 문서에서 시험한 결과:

```
전이 없음  opacity 0.1 → 1      바뀜
전이 있음  opacity 0.1 → 0.1    안 바뀜      (visibilityState: hidden)
```

**형제 덱들(1-1-3, 1-2-2, 1-2-3, 1-2-4, 1-3-1, 1-3-2)은 멀쩡합니다.** 손볼 것 없습니다.

그래도 유효한 것 둘:

1. **명시도 함정은 진짜입니다.** `section.tight .step-box`(0,2,1)는 공유 CSS 의
   `.reveal .step-box.visible`(0,3,0)에 집니다. **여백은 `.visible` 쪽에 둬야 이깁니다.**
   이걸 몰라 8장이 1023px 로 넘쳤습니다.
2. **전이·애니메이션이 걸린 것을 재기 전에 `document.visibilityState` 를 먼저 확인하세요.**
   `hidden` 이면 전이 기반 상태 측정은 전부 무효입니다. 높이만 재는 건 영향 없습니다.

유사도 덱의 step-box 는 오진 과정에서 `display` 토글로 바꿨고 그대로 두었습니다 —
전이가 없어 확실히 동작하고 이미 검증을 마쳤기 때문입니다. 표시 조건은 규약대로 `.visible` 하나입니다.

**로컬 사람 눈 검토에서 남은 확인 사항** (수업 전 실제로 열어 볼 것)
- 11장에서 **유클리드를 마지막에** 눌러야 반례의 충격이 삽니다. 노트에 적어 두었습니다.

- 13장 "주의할 점" 행이 "유클리드가 틀렸다"로 읽히지 않는지 — 프레이밍이 12장과 이어져야 합니다.

### 측정 실패 두 건 — 같은 실수 반복하지 말 것

   → **`textContent`를 쓰세요** (`script`·`style`·`mjx-container` 제거 후).
2. **모든 section에 `display:block; height:auto`를 강제해 놓고 재면 안 됩니다.**
   레이아웃 맥락이 바뀌어 값이 부풀려집니다. 이 방식으로 3장이 994px 초과로 나왔지만,

#### `foreignObject` 함정 (실수하기 쉬움)

- **`text-anchor`가 없습니다.** `<text text-anchor="end" x="70">`을 같은 x로 옮기면
  라벨이 상자 폭만큼 통째로 밀립니다. 오류도 경고도 안 납니다.
  → `end`는 `x-width`, `middle`은 `x-width/2`로 x를 다시 계산하고 정렬은 flex로.
- **`y`는 baseline이 아니라 상자 위쪽**입니다. 글자 시각 중심 ≈ `baseline - 0.35×글자크기`이므로
  `y = 그 값 - height/2`로 두고 `align-items:center`를 씁니다.
- 검증은 `getScreenCTM().inverse()`로 렌더 좌표를 SVG 단위로 되돌려 **의도한 앵커와 대조**하세요.
  높이(`scrollHeight`) 측정으로는 라벨 어긋남이 절대 안 잡힙니다.

#### 기존 점검 항목 하나가 뒤집혔습니다

`svg mjx-container === 0`은 그동안 **통과 조건**이었습니다(Ⅲ-2-03의 SVG `<text>` 미조판 버그 때문).
이제 2-3-3은 설계상 13건이 정상입니다. 판정을 **`svg text mjx-container === 0`**으로 바꾸세요 —
원래 버그를 잡아내던 검사는 그대로 살고, 정상 `foreignObject`만 통과합니다.

#### 표기 규칙 — 사용자 확정 (2026-08-26)

**`TF`·`IDF`·`DF`는 수식이 아니라 이름입니다.** 따라서 수식 안에서도 **정체**로 세웁니다.
`\(TF\)`가 아니라 **`\(\mathrm{TF}\)`**. 산문의 정체와 서체가 맞아떨어집니다.
2-2-2의 10곳을 고쳤고, 이 세 약어는 2-2-2 외의 덱에는 수식으로 등장하지 않습니다
(다른 덱의 `TF-IDF`는 전부 산문이라 그대로 두는 것이 맞습니다).

**`P`·`Q`·`R`는 기본 수학 기호이므로 조판합니다.** 표 머리·결론 문장·정답까지
`\(P\)와 \(Q\)` 형태로 통일했습니다(2-3-3 10곳, 2-3-4 1곳).

**구분 기준** — 실물을 가리키면 정체, 수학 대상이면 조판:

| 정체(그대로 둘 것) | 조판할 것 |
|---|---|
| 댓글 A, 학생 B, 소비자 A~E, 표어 A, 상품 A, 제목 C | 점·벡터·집합 `P` `Q` `R`, 문장 `T₁`→`\(T_1\)` |
| 약어 이름 `TF` `IDF` `DF` (수식 안에서는 `\mathrm{}`) | 좌표축 `x` `y`, 원점 `O`, 각 `\(45^\circ\)` |
| 단위 `m`, `m/s`, `°C` | 좌표 `\(P(5,\ 1)\)`, 길이 값 |

부수 수정 1건 — 2-3-4 4장이 "두 텍스트 P와 Q의 단어집합이 \(P\)와 \(Q\)일 때"로
**같은 문자를 텍스트와 집합에 겹쳐 쓰고** 있었습니다. "두 텍스트의 단어집합이 각각

### ⚠️ 슬라이드 작성 시 함정 — 수식 안의 `<`

MathJax 수식 안에서 **`<` 바로 뒤에 알파벳이 오면 브라우저가 HTML 태그 시작으로 파싱해
그 줄의 나머지를 통째로 삼킵니다.** 콘솔 에러도, MathJax 에러도 나지 않아 눈으로만 발견됩니다.

```
\(x<h\)        → <h ... 가 태그로 먹힘 (깨짐)
\(0<h\le 2\)  → 깨짐
\(x &lt; h\)   → 정상
\(x < 1\)      → 정상 (뒤가 숫자·공백이면 태그가 아님)
```

**규칙: 수식 안의 `<`는 항상 `&lt;`로 쓴다.** 2026-08-20 1-2-3차시 덱에서 실제로 겪었습니다.
검출: `grep -nE '<[a-zA-Z]' 파일 | grep -v '</\?\(div\|span\|b\|td\|tr\)'`

### ⚠️ 함정 2 — LaTeX 명령이 문자열 이스케이프로 먹힘 (`\times` → 탭)

`\t` `\b` `\f` `\v` `\a` `\0`으로 시작하는 LaTeX 명령을 **JS/Python 문자열 안에서** 만들면
이스케이프로 해석돼 제어문자 + 나머지 글자만 남습니다. 콘솔 에러가 안 납니다.

```
\times → [TAB]imes      \begin → [\b]egin     \frac → [\f]rac
\text  → [TAB]ext       \beta  → [\b]eta      \vee  → [\v]ee
\theta → [TAB]heta      \bullet→ [\b]ullet    \vec  → [\v]ec
```

2026-08-25 1-1-3차시 10쪽에서 실제로 겪었습니다(`5c32471`).
**버튼을 눌러야 나오는 `.step-box` 안이라 로드 시점 검사로는 안 잡혔습니다.**

검출 — 저장소 전체를 한 번에 (2026-08-25 실행 결과 0건):

```bash
python3 - <<'PY'
import glob, io, re
CTRL={'\t':'\\t','\x08':'\\b','\x0c':'\\f','\x0b':'\\v','\x07':'\\a','\x00':'\\0'}
TAILS=['imes','ext{','ext ','heta','ilde','op ','o ','an ','eq','abla','u ','ot ',
       'ho','ight','egin','eta','ullet','ar{','mod','rac','orall','ee','ec{',
       'arphi','ert','arepsilon','lpha','pprox']
for f in sorted(glob.glob('**/*.html',recursive=True)):
    s=io.open(f,encoding='utf-8').read()
    for ch,name in CTRL.items():
        for m in re.finditer(re.escape(ch),s):
            if any(s[m.end():m.end()+12].startswith(t) for t in TAILS):
                print(f'{f} L{s[:m.start()].count(chr(10))+1} {name}')
PY
```

**예방: 생성 코드에서 TeX는 raw 문자열(`r'\times'`)이나 이스케이프(`'\\times'`)로 쓰세요.**
