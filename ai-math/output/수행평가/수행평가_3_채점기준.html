인공지능 수학 — 수행평가 3 채점 기준표

분류와 예측 (III단원)

평가 시기: 2026년 4~5월 총 배점: 28점 (기본 8점 + 분류 8점 + 확률 8점 + 경향성 4점)
① 분류 원리 이해 총 8점
수준기대 수행배점
매우 우수 좌표평면상의 데이터를 직선으로 구분하는 원리를 이해하고, 분류 기준선 y=−x+10을 정확히 그으며, 새로운 데이터(독서량 5, 어휘력 4)에 대해 f(5)=5 계산 후 y=4 < f(5)=5임을 근거로 일반 그룹(○)으로 분류 과정을 논리적으로 설명함 8점
우수 기준선을 그렸으나 새 데이터 분류 시 f(x) 계산은 정확하나 비교 방향 설명이 다소 부족하거나, 분류 결과는 맞으나 이유 서술이 충분하지 않음 6점
보통 분류 원리를 이해했으나 기준선 작도 오류가 있거나, 새 데이터 분류 과정 설명이 불명확함 (분류 결과만 쓰고 이유 미서술) 4점
노력 필요 활동지 작성을 성실히 시도함 (기준선 미완성 또는 분류 과정 서술 없음) 3점
채점 포인트
· 기준선 작도 (①): y절편 10, 기울기 −1인 직선 [2점]
· 분류 원리 서술 (②): "y값이 기준선 값보다 크면 ●그룹, 작으면 ○그룹" 명시 [3점]
· 새 데이터 분류 (③): f(5)=5 계산 후 y=4<5 비교, 결론(○그룹) 서술 [3점]
② 확률과 예측 총 8점
수준기대 수행배점
매우 우수 자료로부터 확률을 올바르게 계산하고(P(과학)=45/100), 조건부확률을 적용하여 2학년 조건에서도 예측하며(P(과학|2학년)=20/40=1/2), 예측 오차의 원인(표본 제한성, 개인차, 미반영 변수)을 두 가지 이상 논리적으로 설명함 8점
우수 확률 계산과 예측값 도출은 정확하나 오차 원인 설명이 한 가지만 제시되거나 부족함 6점
보통 확률 계산이나 예측 과정 중 하나만 정확하거나, 조건부확률 적용에 오류가 있음. 오차 원인 서술 시도는 있으나 내용이 단순함 4점
노력 필요 활동지 작성을 성실히 시도함 3점
채점 포인트
· ① 전체 확률: P(수학)=27/100, P(영어)=28/100, P(과학)=45/100 → 과학 예측 [3점]
· ② 조건부확률: P(수학|2학년)=12/40=3/10, P(영어|2학년)=8/40=1/5, P(과학|2학년)=20/40=1/2 → 과학 예측 [3점]
· ③ 오차 원인: 표본 수 제한 / 개인차 / 반영되지 않은 변수 등 중 2가지 이상 [2점]
③ 경향성 분석 총 4점
수준기대 수행배점
매우 우수 추세선 f(x)=0.5x−6을 산점도에 정확히 그리고, f(38)=13 예측값을 바르게 계산하며, "기온이 높을수록 판매량이 증가하는 양의 상관관계" 등 경향성 해석이 논리적임 4점
우수 추세선을 그렸으나 방향이 다소 부정확하거나, 예측값은 맞으나 경향성 해석이 단순함("증가한다" 수준) 3점
노력 필요 시도했으나 추세선 작도와 경향성 설명 모두 미흡함 2점
채점 포인트
· ④ 추세선 작도: f(20)=4, f(40)=14 등 두 점으로 직선 [1점]
· ⑤ 예측값: f(38)=0.5×38−6=19−6=13(백 개) [1점]
· ⑥ 경향성 서술: 양의 상관관계 + 기온↑→판매량↑ 내용 포함 [2점]
