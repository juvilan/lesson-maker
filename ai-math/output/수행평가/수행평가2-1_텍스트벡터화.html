문제 상황
한 음식점의 손님 후기 3개를 수학적으로 분석하려고 합니다.
아래 단계를 따라 텍스트 자료를 처리하시오.
  • 후기 A : 맛있는 파스타. 파스타 맛이 정말 좋아요.
  • 후기 B : 분위기가 좋아요. 서비스도 좋습니다.
  • 후기 C : 파스타와 분위기 모두 좋은 맛집.
Step 1 · 불용어 제거와 단어 사전 만들기
불용어(Stopword): 조사(이, 가, 도, 와, 은, 는), 어미(요, 습니다, 아요), 기타 의미 없는 말 → 제거
기본형 변환: 맛있는→맛있다 / 좋아요·좋습니다·좋은→좋다 / 맛이→맛

불용어를 제거하고 기본형으로 바꾼 뒤, 세 후기에 등장하는 모든 단어를 모아 단어 사전 U를 만드시오.

TF (Term Frequency): 각 단어가 해당 후기에서 등장한 횟수

Step 3 · DF 와 IDF 계산하기
DF (Document Frequency): 해당 단어가 등장하는 후기의 수
IDF (Inverse Document Frequency): IDF = n ÷ DF   (n = 전체 후기 수 = 3)
DF가 작을수록(희귀 단어) IDF가 크고 → 그 후기만의 핵심 정보!
