③ 핵심 개념 정리
1943 · 1958
퍼셉트론 (Perceptron)
입력값에 가중치(w)를 곱하여 더한 뒤,
결과가 기준값 이상이면 1, 미만이면 0을 출력.
가중합 → 0 또는 1
→ 최초의 학습하는 인공 뉴런 모델
1969 · AI 겨울
XOR 문제 (단층의 한계)
XOR은 직선 하나로 0과 1을 분리할 수 없음.
(선형 분리 불가)
단층 퍼셉트론으로는 XOR을 풀 수 없다는 것이 밝혀짐.
→ AI 연구 침체기 (AI 겨울) 시작
1986
역전파 알고리즘
(다층 신경망)
다층 신경망을 학습시키는 방법이 개발됨.
층을 여러 개 쌓으면 XOR도 해결 가능.
→ AI 연구 부활의 계기
2012
딥러닝 (AlexNet)
층을 깊이 쌓은 심층 신경망.
AlexNet이 이미지 분류 대회(ImageNet)에서
압도적 성능으로 우승.
→ 딥러닝 시대 개막

이유 예시 답안
· (가)→(나): 퍼셉트론은 직선 하나로만 분류하므로 XOR처럼 선형으로 분리할 수 없는 문제를 풀지 못했기 때문이다.
· (나)→(다): XOR처럼 단층으로 풀 수 없는 문제를 해결하기 위해, 층을 여러 개 쌓는 다층 신경망과 이를 학습시키는 방법(역전파 알고리즘)이 개발되었기 때문이다.
· (다)→(라): 역전파로 다층 신경망 학습이 가능해지자, 층을 더 깊이 쌓아 복잡한 패턴을 인식하는 딥러닝이 등장했기 때문이다.

⑤ 인공지능 · 기계학습 · 딥러닝의 포함관계
포함관계: 인공지능 ⊃ 기계학습 ⊃ 딥러닝
큰 원이 작은 원을 포함합니다. 딥러닝은 기계학습의 일종이고, 기계학습은 인공지능의 일종입니다.
O/X 문항정답
딥러닝은 기계학습의 한 종류이다.○
기계학습을 사용하면 반드시 딥러닝을 사용하는 것이다.✕
모든 인공지능이 기계학습을 사용하는 것은 아니다.○
딥러닝을 사용하면 인공지능을 사용한 것이다.○
⑥ 데이터 유형과 수학적 표현
📝 텍스트 (문장, 단어) → ① 벡터 (vector) 단어를 숫자로 된 목록(벡터)으로 표현 → BoW, TF·IDF
🖼 이미지 (사진, 픽셀) → ② 행렬 (matrix) 픽셀을 숫자 배열(행렬)로 표현 → 검은색=0, 흰색=1
🤖 판단·예측 결과 → ③ 함수 (function) 입력(x)을 받아 판단(y)을 출력하는 수학적 관계
이유 예시 답안: 컴퓨터는 글자나 그림을 직접 이해할 수 없으므로, 모든 데이터를 숫자로 변환해야 수학 연산을 통해 패턴을 학습하고 결과를 예측할 수 있기 때문이다.
