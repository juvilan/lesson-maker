텍스트 벡터화 연습

TF · IDF · TF-IDF

★ 모범 답안 ★
상황 영화 후기 3개를 수학적으로 분석해 봅시다.
아래 영화 후기에서 각 단어의 중요도를 TF-IDF로 계산하시오.
  • 후기 A : 재미있는 영화. 영화 스토리가 정말 재미있고 좋아요.
  • 후기 B : 연기가 좋아요. 음악도 좋습니다.
  • 후기 C : 영화와 연기 모두 좋은 작품.
STEP 1 불용어 제거 + 단어 사전 U 만들기
불용어 제거: 조사(가, 도, 와), 어미(요, 습니다, 는, 은, 이) 등 제거
기본형 변환: 재미있는·재미있고·재미있어요 → 재미있다  /  좋아요·좋습니다·좋은 → 좋다
후기 A 처리 결과 (예시) : { 재미있다, 영화, 스토리, 좋다 }
후기 B 처리 결과 : {  연기, 좋다, 음악  }
후기 C 처리 결과 : {  영화, 연기, 좋다, 작품  }
단어 사전 U = {  영화, 재미있다, 스토리, 연기, 좋다, 음악, 작품  }   (총 7개, n = 3)
STEP 2 TF 표 작성  (각 후기에서 단어가 등장한 횟수)
후기 영화 재미있다 스토리 연기 좋다 음악 작품
A 2 2 1 0 1 0 0
B 0 0 0 1 2 1 0
C 1 0 0 1 1 0 1
STEP 3 DF와 IDF 계산  (IDF = n ÷ DF,  n = 3)
DF : 해당 단어가 등장하는 후기의 수  |  IDF : 전체 후기 수 ÷ DF — 희귀한 단어일수록 IDF가 큽니다.
단어 영화 재미있다 스토리 연기 좋다 음악 작품
DF 2 1 1 2 3 1 1
IDF
(3÷DF)		 1.5 3 3 1.5 1 3 3
✎  "좋다"의 IDF = 1    "재미있다"의 IDF = 3    더 희귀한(특정 후기만의) 단어는?  재미있다
STEP 4 TF·IDF 계산 (후기 A)  (= TF × IDF)
단어 영화 재미있다 스토리 연기 좋다 음악 작품
TF(A) 2 2 1 0 1 0 0
IDF 1.5 3 3 1.5 1 3 3
TF·IDF 3 6 3 0 1 0 0
✎  후기 A의 핵심어(TF·IDF 최대) : 재미있다  → 후기 A의 주제는 "재미있는 스토리"이다.
STEP 5 생각 정리
Q1. "좋다"는 세 후기 모두에 등장한다. TF·IDF 관점에서 "좋다"가 특정 후기의 핵심어가 되기 어려운 이유를 설명하시오.
"좋다"는 세 후기 모두에 등장하므로 DF = 3, IDF = 3÷3 = 1이다. IDF가 1로 가장 낮기 때문에, 후기 A에서 TF가 1이더라도 TF·IDF = 1×1 = 1에 불과하다. 즉, 여러 후기에 공통으로 나타나는 단어는 IDF가 낮아져 TF·IDF 값도 작아지므로, 특정 후기만의 고유한 핵심어로 선택되기 어렵다.
Q2. TF만 사용했을 때의 한계는 무엇이고, TF·IDF가 이를 어떻게 보완하는가?
TF만 사용하면 "좋다"처럼 모든 후기에 자주 등장하는 단어도 높은 중요도를 가지게 된다. 이 단어는 특정 후기의 핵심 내용을 나타내지 않으므로 분석의 정확도가 떨어진다.
TF·IDF는 여기에 IDF를 곱함으로써, 많은 후기에 공통으로 나오는 단어(DF가 큰 단어)의 가중치를 자동으로 낮추고, 특정 후기에만 등장하는 희귀한 단어(DF가 작은 단어)에 더 높은 중요도를 부여한다. 이를 통해 각 후기의 고유한 내용을 더 잘 반영할 수 있다.
