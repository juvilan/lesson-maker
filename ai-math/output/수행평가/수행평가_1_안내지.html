③ AI 발전 타임라인
연도사건 · 개념핵심 내용
1943 맥컬록-피츠 뉴런 최초의 인공 뉴런 모델 — 수학적으로 뇌의 신경세포를 흉내 냄
1958 퍼셉트론 입력값에 가중치를 곱하여 합산 → 기준값 이상이면 1, 미만이면 0 출력
1969 XOR 문제 발견
(AI 겨울 시작)		 단층 퍼셉트론은 XOR처럼 직선 하나로 나눌 수 없는 문제를 풀지 못함
1986 역전파 알고리즘 다층 신경망을 학습시키는 방법 개발 → XOR 해결 가능, AI 연구 부활
2012 딥러닝 (AlexNet) 층을 깊이 쌓은 심층 신경망이 이미지 분류 대회에서 압도적 성능 → 딥러닝 시대 개막

AlexNet · 깊은 층
퍼셉트론 → XOR 문제 퍼셉트론은 직선 하나로만 분류하므로, XOR처럼 선형으로 나눌 수 없는 문제를 풀지 못했기 때문
XOR 문제 → 다층 신경망 단층의 한계를 극복하기 위해 층을 여러 개 쌓고, 이를 학습시키는 역전파 알고리즘이 개발되었기 때문
다층 신경망 → 딥러닝 다층 구조 학습이 가능해지자, 층을 더욱 깊이 쌓아 복잡한 패턴을 인식하는 딥러닝이 등장했기 때문

⑥ 인공지능 · 기계학습 · 딥러닝의 포함관계
인공지능(AI) ⊃ 기계학습(ML) ⊃ 딥러닝(DL)
· 딥러닝은 기계학습의 한 종류  · 기계학습이라고 모두 딥러닝은 아님
· 모든 인공지능이 기계학습을 쓰는 것은 아님  · 딥러닝 사용 = 인공지능 사용
⑦ 데이터 유형과 수학적 표현
텍스트 (문장·단어) → 벡터 (vector) 단어를 숫자 목록으로 표현 — BoW, TF·IDF
이미지 (사진·픽셀) → 행렬 (matrix) 픽셀 값을 숫자 배열로 표현 — 검은색=0, 흰색=1
판단·예측 결과 → 함수 (function) 입력(x)을 받아 결과(y)를 출력하는 수학적 관계
