문제

이미지를 수학적으로 표현하는 세 가지 방법을 단계별로 학습합니다.

① 흑백 이미지 → 0과 1의 행렬  (Step 1~3)
② 명암 이미지 → 0~255 수치 행렬  (Step 4)
③ 컬러 이미지 → R · G · B 세 행렬  (Step 5)

■ = 검정(0)   □ = 흰색(1)   숫자가 클수록 밝다(0→검정, 255→흰색)

Step 3 · 차이 행렬 계산
계산 방법: 두 행렬에서 같은 위치(i행, j열)의 값을 빼고 절댓값을 취합니다.
각 위치의 값 = |A의 (i,j) 값 − B의 (i,j) 값|
  → 값이 0이면 두 이미지에서 같은 픽셀, 1이면 다른 픽셀
예: A의 (1,1) = 0, B의 (1,1) = 0 이면 |0−0| = 0 (같음)

차이 행렬 |A − B| 를 계산하여 빈칸을 채우시오.
