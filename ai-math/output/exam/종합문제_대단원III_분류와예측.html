핵심 해설 요약

1번감성 점수가 높을수록 긍정, 낮을수록(음수일수록) 부정 감성이 강하다. ④는 반대로 서술되어 틀림.
2번좋다(+1) + 싫다(−2) + 좋다(+1) = 0
3번해밍 거리는 같은 길이의 두 이진 문자열에서 서로 다른 위치의 개수를 의미한다.
4번위치별 비교: (1=같음, 0≠1=다름, 1=같음, 1≠0=다름, 0=같음) → 다른 위치 2개
5번유클리드 거리는 두 점 사이의 직선 거리를 측정한다. \(d = \sqrt{\sum(a_i - b_i)^2}\)
6번\(\sqrt{(3-0)^2+(4-0)^2} = \sqrt{9+16} = \sqrt{25} = \mathbf{5}\)
7번같은 방향이면 각도 = 0°, cos 0° = 1. "코사인 유사도가 0"이라는 ④가 틀림.
8번\(|A \cap B| = |\{\text{바나나},\ \text{포도}\}| = 2\), \(|A \cup B| = 4\), \(J = \dfrac{2}{4} = \dfrac{1}{2}\)
9번퍼셉트론의 가중합: \(y = w_1 x_1 + w_2 x_2 + b\) (가중치 × 입력의 합 + 편향)
10번맛있다(+2) + 좋다(+1) + 싫다(−3) + 맛있다(+2) = +2
11번산점도는 두 변수의 관계를 좌표 평면 위의 점으로 나타낸 그래프이다.
12번\(f(3) = 2 \times 3 + 1 = \mathbf{7}\)
13번오차 = 관측값 − 예측값 = \(10 - 8 = \mathbf{2}\)
14번기울기 \(a > 0\)이면 \(x\) 증가 시 \(f(x)\)도 증가 → 증가 추세
15번\(f(x) = 10x + 40\) 검증: \(f(1)=50,\ f(2)=60,\ f(3)=70,\ f(4)=80,\ f(5)=90\) ✓
16번\(f(6) = 10 \times 6 + 40 = \mathbf{100}\)
17번코사인 유사도가 1에 가까울수록 유사. A-B=0.85가 세 쌍 중 최대 → A와 B가 가장 유사.
18번\(f(x)=3x-1\)의 각 오차: P1=|3−2|=1, P2=|6−5|=1, P3=|9−8|=1, P4=|11−11|=0, P5=|12−14|=2 → P5 최대
19번유클리드: \(\sqrt{(0-4)^2+(3-0)^2}=\sqrt{16+9}=5\) / 자카드: \(|A \cap B|=2,\ |A \cup B|=5 \Rightarrow \dfrac{2}{5}\)
20번ㄱ 참. ㄴ 참(해밍 거리=0이면 모든 위치 동일). ㄷ 거짓(기울기 음수 → 감소 추세). 따라서 ㄱ, ㄴ이 옳음.
