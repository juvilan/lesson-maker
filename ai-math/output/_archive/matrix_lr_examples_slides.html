왼쪽 곱 vs 오른쪽 곱
실전 예제 모음

행렬 A = [1,2,3; 4,5,6; 7,8,9] 에
다양한 행렬을 왼쪽(P·A)과 오른쪽(A·Q)에서 곱해보며
행 조작과 열 조작의 차이를 확인합니다

P · A → 행(가로줄) 조작 예제 4개
A · Q → 열(세로줄) 조작 예제 4개
비정방 행렬 예제 3개
복습

지난 시간 핵심: 왼쪽 곱 = 행, 오른쪽 곱 = 열

P · A → 행 조작
결과의 i행 = P의 i행이 A의 행들을 선형결합
= p₁·(A행1) + p₂·(A행2) + p₃·(A행3)
P의 각 행이 "A의 행들을 어떻게 섞을까?" 결정
→ 가로줄 단위로 교환, 복사, 이동, 블렌딩
A · Q → 열 조작
결과의 j열 = Q의 j열이 A의 열들을 선형결합
= q₁·(A열1) + q₂·(A열2) + q₃·(A열3)
Q의 각 열이 "A의 열들을 어떻게 섞을까?" 결정
→ 세로줄 단위로 교환, 복사, 이동, 블렌딩
오늘 사용할 원본 이미지 행렬: A = [1, 2, 3; 4, 5, 6; 7, 8, 9] — 각 행을 색으로 구분하여 변화를 추적합니다.

최종 정리

행렬 곱의 위치가 조작 방향을 결정한다

왼쪽 곱 P · A → 행(가로줄) 조작
① 행 교환: P = 순열행렬 → 상하 반전
② 행 복사: 같은 행벡터 반복 → 줄무늬
③ 행 이동: 대각 아래 shift → 위로 스크롤
④ 행 블렌딩: 가중합 → 세로 블러
오른쪽 곱 A · Q → 열(세로줄) 조작
① 열 교환: Q = 순열행렬 → 좌우 반전
② 열 복사: 같은 열벡터 반복 → 세로 줄무늬
③ 열 이동: 대각 위 shift → 오른쪽 스크롤
④ 열 스케일링: 대각행렬 → 열별 밝기 조절
비정방 행렬 → 크기 변환
m×n × n×n: m < n → 행 줄이기 (자르기), m > n → 행 늘리기 (보간)
n×n × n×p: p < n → 열 줄이기 (자르기), p > n → 열 늘리기 (복제)
핵심 공식
(P·A)의 i행 = P의 i행이 A의 행들을 선형결합
(A·Q)의 j열 = Q의 j열이 A의 열들을 선형결합
→ 조작 행렬의 각 행/열이 "레시피"이고, 원본의 행/열이 "재료"입니다.
