— 역사의 흐름

일상 속 AI 사례부터 시작해 AI/ML/DL의 관계와 역사의 흐름을 이해합니다.

도입 — 일상 속 AI
우리 주변의 AI를 찾아볼까요?
· 챗봇 (ChatGPT, 클로버) — 질문에 자연스럽게 답변
· AI 스피커 (시리, 빅스비) — 목소리를 알아듣고 명령 수행

이것들이 모두 수학으로 만들어졌습니다. 그 수학의 핵심이 바로 이 단원에서 배울 퍼셉트론과 신경망입니다.

1950년대
튜링 테스트 — "기계가 생각할 수 있는가?"
앨런 튜링이 "기계가 생각할 수 있는가?"라는 질문을 던지며 튜링 테스트를 제안합니다. 기계가 인간처럼 대화할 수 있으면 '생각한다'고 볼 수 있다는 개념입니다.
1956년
다트머스 회의 — '인공지능' 용어 첫 등장
미국 다트머스 대학에서 열린 학술 회의에서 'Artificial Intelligence(인공지능)'이라는 용어가 공식적으로 처음 사용됩니다. AI 연구의 공식적인 시작점입니다.
1957년 — 1960년대
퍼셉트론 탄생 (로젠블랫)
프랭크 로젠블랫이 뇌의 뉴런을 모방한 퍼셉트론을 발표합니다. 최초의 학습 가능한 인공 신경망으로, 데이터로부터 스스로 가중치를 조정할 수 있었습니다.
1969년
XOR 한계 발견 → 1차 AI 암흑기
민스키와 패퍼트가 단층 퍼셉트론은 XOR 문제를 풀 수 없다는 것을 수학적으로 증명합니다. 이 발표로 AI 연구비가 삭감되고 첫 번째 'AI 겨울'이 찾아옵니다.
1980년대
전문가 시스템 등장
인간 전문가의 지식을 규칙으로 직접 입력한 전문가 시스템이 의료·법률 분야에서 활용됩니다. 그러나 규칙 기반의 한계로 결국 두 번째 AI 겨울을 맞이합니다.
1986년
역전파 알고리즘 (루멜하트) — 학습이 가능해짐
힌튼·루멜하트 등이 역전파(Backpropagation) 알고리즘을 다층 신경망에 성공적으로 적용합니다. 이제 여러 층을 쌓고도 학습이 가능해졌습니다.
2006년
GPU 활용 딥러닝 실용화 (힌튼)
NVIDIA CUDA 출시로 GPU를 범용 연산에 활용할 수 있게 되고, 제프리 힌튼의 심층 신뢰 신경망(DBN) 발표로 '딥러닝'이라는 용어가 본격 등장합니다.
2012년
AlexNet — 이미지 인식 대회 압도적 우승
AlexNet이 이미지 인식 대회(ImageNet)에서 오류율을 26%에서 15%로 낮추며 압도적 우승합니다. 딥러닝이 세상의 주목을 받게 된 역사적 사건입니다.
2016년
AlphaGo vs 이세돌
구글 딥마인드의 AlphaGo가 세계 최고의 바둑 기사 이세돌을 4:1로 꺾습니다. AI가 인간의 직관이 필요하다고 여겨진 게임에서도 압도적 실력을 보임으로써 전 세계에 AI의 위력을 알렸습니다.
2017년~현재
트랜스포머 → ChatGPT 시대
"Attention Is All You Need" 논문으로 트랜스포머 구조가 등장합니다. GPT, BERT, ChatGPT 등 대형 언어 모델의 시대가 열리며 AI가 일상에 깊이 들어옵니다.

진리표와
논리 게이트

일상 속 논리 예시에서 출발해 AND/OR/XOR 진리표를 이해하고, 선형 분리 가능성 개념을 시각적으로 파악합니다.

AND 게이트
🔐
도어락 시스템
카드 인식 AND 비밀번호 → 문 열림

둘 다 1이어야 결과가 1이 된다.
하나라도 틀리면 → 출입 불가 (0)
x₁ AND x₂ = 1
← x₁=1 이고 x₂=1 일 때만
OR 게이트
🚨
화재 경보 시스템
화재감지 OR 연기감지 → 경보 울림

하나라도 1이면 결과가 1이 된다.
둘 다 0일 때만 → 경보 없음 (0)
x₁ OR x₂ = 1
← x₁=1 또는 x₂=1 일 때
XOR 게이트
💡
계단 스위치
위스위치 XOR 아래스위치 → 불 켜짐
둘 다 올리면 꺼짐 (서로 다를 때만 1)

출결 XOR 예시: 명부 있는데 결석 = 이상 감지!
x₁ XOR x₂ = 1
← x₁ ≠ x₂ 일 때만

선형 분리 가능 / 불가 시각화

퍼셉트론은 직선 하나로 두 그룹을 나눕니다. 어떤 게이트는 가능하고 어떤 게이트는 불가능할까요?

AND ✓
직선 하나로 분리 가능
OR ✓
직선 하나로 분리 가능
XOR ✗
직선으로 분리 불가!
집합으로 이해하기 — 벤다이어그램

논리 게이트를 집합의 언어로 표현하면 각 연산의 의미가 명확해집니다.

OR = A∪B (합집합)
A 또는 B에 속하는 원소 전체
AND = A∩B (교집합)
A와 B 모두에 속하는 원소만
XOR = A△B (대칭차집합)
A 또는 B 중 하나에만 속하는 원소
핵심: XOR = (A∪B) − (A∩B). 합집합에서 교집합을 뺀 것 — 둘 중 하나에만 속하는 원소들의 집합입니다.
계단 스위치가 XOR인 이유: 위 스위치 또는 아래 스위치 중 정확히 하나만 올라가 있을 때 불이 켜집니다.
다음 시간 예고: 퍼셉트론이 어떻게 이 진리표를 수학적으로 구현하는지 배웁니다. 가중치(w)와 편향(b)이 어떻게 결정 경계선을 만드는지 직접 계산해봅니다.

퍼셉트론의
수학적 구조

뉴런에서 퍼셉트론으로의 대응 관계를 파악하고, 수식과 경계선 유도를 단계별로 학습합니다.

뉴런 → 퍼셉트론 대응
뇌를 모방한 것은 맞지만, 작동 원리는 순수 수학입니다.
수상돌기가 입력이 되고, 시냅스 강도가 가중치가 되고, 세포체의 합산이 수식이 됩니다.
생물학적 뉴런→퍼셉트론역할
수상돌기 (입력) → 입력값 x₁, x₂, ... 다른 뉴런으로부터 신호를 받음
시냅스 강도 → 가중치 w₁, w₂, ... 각 신호의 중요도 (학습으로 조정)
세포체 (합산) → 가중합 Σ(xᵢ · wᵢ) + b 입력 신호들을 가중 합산
임계값 → 편향(Bias) b = -θ 발화 기준점 조정
발화 여부 → 활성화 함수 f(z) 최종 출력값 결정 (0 또는 1)
퍼셉트론 구조 다이어그램
퍼셉트론 수식

퍼셉트론의 계산은 두 단계로 이루어집니다:

① 가중합 계산:
z = w₁x₁ + w₂x₂ + b
② 활성화 함수 (계단 함수):
y = f(z) = 1   (z ≥ 0 일 때)
y = f(z) = 0   (z < 0 일 때)
  • x₁, x₂ : 입력값
  • w₁, w₂ : 가중치 (학습으로 조정)
  • b : 편향 (bias), b = -θ
  • y : 출력값 (0 또는 1)
AND 게이트 인터랙티브 계산

w₁=0.5, w₂=0.5, b=-0.7 로 설정하면:

버튼을 눌러 계산해보세요
w₁ 0.5
w₂ 0.5
bias b -0.7
경계선 수식 유도 ★ — 단계별 이해

퍼셉트론의 결정 경계선이 어떻게 나오는지 4단계로 유도합니다.

Step 1 — 경계선 조건

결정 경계선이란 출력이 0과 1의 경계, 즉 z = 0인 선입니다.

w₁x₁ + w₂x₂ + b = 0
⟺  w₁x₁ + w₂x₂ = θ   (b = -θ)
Step 2 — x₂에 대해 정리

경계선 방정식을 x₂ = … 형태로 정리합니다:

x₂ = -(w₁/w₂) · x₁ + θ/w₂

· 기울기: -w₁/w₂
· y절편: θ/w₂
Step 3 — AND 게이트 숫자 대입

w₁=0.5, w₂=0.5, θ=0.7 (b=-0.7)을 대입합니다:

기울기 = -(0.5/0.5) = -1
y절편 = 0.7/0.5 = 1.4

→  경계선: x₂ = -x₁ + 1.4

교과서가 w₁=w₂로 맞춘 이유: 기울기를 -1로 고정해서 임계값 θ의 효과만 깔끔하게 보여주기 위한 교육적 단순화입니다.

Step 4 — θ 슬라이더로 경계선 변화 관찰

θ(임계값)를 바꾸면 경계선의 y절편이 변합니다. θ 낮추면 OR처럼, 높이면 AND처럼 작동합니다.

θ (임계값) 0.7

4차시

XOR 문제와
다층 퍼셉트론

XOR가 왜 직선 하나로 풀리지 않는지 확인하고, 층을 쌓으면 해결된다는 것을 직관적으로 이해합니다.

복습 — XOR 선형 분리 불가
계단 스위치 예시: 위 스위치(x₁) XOR 아래 스위치(x₂)
→ 둘이 다를 때만 전등이 켜진다.
→ (0,1)과 (1,0)만 1 → 두 덩어리 → 직선 하나로 분리 불가!
0(0,0)
1(0,1)
1(1,0)
0(1,1)
1969년 민스키와 패퍼트: 단층 퍼셉트론은 XOR처럼 선형 분리 불가능한 문제를 절대 풀 수 없다. → 1차 AI 겨울.
해결의 실마리 — 층을 쌓자!

복잡한 판단을 단순한 판단들의 조합으로 만들면 됩니다.

일상 비유: 복잡한 레시피는 단순한 조리법의 조합
· "볶기" + "끓이기" + "조리기" = 복잡한 요리
→ AND + OR + NAND = XOR
핵심 아이디어:
XOR = (OR 판단) AND (NAND 판단)
→ 두 개의 단순 판단을 조합하면 복잡한 XOR 가능!
XOR = OR AND NAND 분해 ★
h₁ = OR(x₁, x₂) — "최소 하나는 켜졌다"
h₂ = NAND(x₁, x₂) — "전부 다 켜진 건 아니다"
y = AND(h₁, h₂) — "정확히 하나만 켜졌다" = XOR

NAND = NOT AND → (1,1)은 0, 나머지는 모두 1
