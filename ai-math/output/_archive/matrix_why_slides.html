핵심 정리

하나의 격자, 두 가지 읽기

왼쪽 곱 P · A
결과의 i행 = P의 i행 [p₁, p₂, p₃] 이
A의 행들을 선형결합
= p₁·(A행1) + p₂·(A행2) + p₃·(A행3)
✓ 행 교환 (순열)
✓ 행 이동 (아래/위로 shift)
✓ 행 소거 (0행 → 검정 줄)
✓ 행 수 변경 (m×n 행렬 → m행 결과)

A의 열들을 선형결합
= q₁·(A열1) + q₂·(A열2) + q₃·(A열3)
✓ 열 교환 (순열)
✓ 열 이동 (오른쪽/왼쪽으로 shift)
✓ 열 소거 (0열 → 검정 줄)
✓ 열 수 변경 (n×p 행렬 → p열 결과)
왜 다른가? — 격자를 어느 방향으로 읽느냐의 차이
격자의 (i,j) 성분 = rᵢ · cⱼ

세로(↓) 묶음 → j열 전체 = 오른쪽 열 cⱼ의 역할
