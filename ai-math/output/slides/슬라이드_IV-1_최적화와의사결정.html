손실함수란?

손실함수 (Loss Function)
추세선의 오차의 제곱의 평균을 나타내는 함수.
값이 작을수록 예측이 정확하다.
\[ L(w) = (w - 3)^2 \]
예시: 최솟값을 w=3에서 갖는 손실함수
• w = 0: L = 9 (오차 큼)
• w = 2: L = 1 (오차 줄어듦)
• w = 3: L = 0 (완벽한 예측)

포물선의 꼭짓점 = 손실 최솟값

손실함수를 (w-3)² 이차함수로 단순화해서 설명합니다. 실제 교과서에서는 L(a) = (880a²-1672a+830)/5 형태이지만, 원리 이해를 위해 단순 형태부터 시작합니다.

경사하강법 — 기울기로 내려가기

갱신식: \[ w \leftarrow w - \eta \cdot \frac{\partial L}{\partial w} \]
η (에타): 학습률
Step 1: 현재 위치
w₀ = 0,   L(0) = (0−3)² = 9
Step 2: 기울기 계산
\(\frac{\partial L}{\partial w} = 2(w-3)\)  →  w₀=0 대입: 2×(0−3) = −6
Step 3: 갱신 (η=0.1)
w₁ = 0 − 0.1 × (−6) = 0.6
Step 4: 확인
L(0.6) = (0.6−3)² = 5.76 < 9  ✓ 손실 감소!

기울기 반대 방향으로 이동

0 / 4
N키로 단계 진행. 기울기가 음수이면 w를 증가시켜야 손실이 줄어든다는 것을 강조. η=0.1 × (-6) = -0.6이므로 w가 0.6 증가합니다.

학습률 선택이 경사하강법에서 가장 중요한 하이퍼파라미터입니다. η=1.5이면 w가 0 → 7.5 → -8.25...처럼 발산합니다.

경사하강법의 종류

📦 Batch GD
전체 데이터로 기울기 계산
• 안정적이지만 느림
• 대용량 데이터에 비적합
⚡ Stochastic GD
1개 데이터씩 기울기 계산
• 빠르지만 불안정
• 지역 최솟값 탈출 가능
🔥 Mini-Batch GD
소규모 묶음으로 계산
• Batch + Stochastic 절충
• 딥러닝에서 표준적 방법
지역 최솟값 vs 전역 최솟값
이차함수처럼 단순한 경우: 지역 = 전역 최솟값 (같음)
복잡한 손실 함수: 여러 개의 지역 최솟값 존재 → 전역 최솟값 탐색이 어려움
실제 딥러닝에서는 Mini-Batch SGD (배치 크기 32~256)를 주로 사용합니다. 지역 최솟값 문제는 다음 슬라이드의 의사결정 트리와 비교할 때 다시 언급합니다.

손실함수 최솟값 찾기 — 미분 활용

교과서 핵심 방법
손실함수 L(a)가 a의 이차함수일 때, L'(a) = 0을 풀어 최솟값을 구한다.
추세선 f(x) = ax에 대한 손실함수
\[ L(a) = \frac{880a^2 - 1672a + 830}{5} \]
미분으로 최솟값 구하기
\[ L'(a) = \frac{1760a - 1672}{5} = 0 \] \[ a = \frac{1672}{1760} = \frac{19}{20} = 0.95 \]
💡 미분계수 = 기울기 = 0인 지점이 최솟값
미분 = 0 → 최솟값 a = 0.95 → 이 추세선이 데이터 예측에 가장 적합
교과서 104-105쪽 내용. 실제로는 손실함수를 미분하여 L'(a)=0을 풀면 최적의 추세선 기울기를 얻을 수 있습니다. 경사하강법은 이 과정을 수치적으로 반복합니다.

정보의 불확실성 — 엔트로피

\[ H = -\sum_{i} p_i \cdot \log_2 p_i \]
• H가 클수록 → 불확실성↑ (섞여있음)
• H가 작을수록 → 불확실성↓ (깔끔히 분류됨)
• 의사결정 트리는 H를 최소화하는 방향으로 분기
균등 (50:50)
H = −(0.5·log₂0.5 + 0.5·log₂0.5) = 1.0 bit
불균등 (80:20)
H = −(0.8·log₂0.8 + 0.2·log₂0.2) ≈ 0.72 bit
순수 (100:0)
H = −(1·log₂1) = 0 bit (완전히 분류됨)
의사결정 트리에서 분기 기준을 선택할 때 엔트로피를 사용합니다. 분기 후 엔트로피가 가장 많이 감소하는 특징(속성)을 선택합니다. 이것이 정보 이득(Information Gain)입니다.

정보이득 — 최선의 분류 기준 찾기

정보이득 (Information Gain) = 분기 전 H − 분기 후 평균 H
정보이득이 클수록 더 좋은 분류 기준
예시: 스팸 메일 분류
전체 H = 1.0 bit (스팸:정상 = 5:5)

기준 A: "광고" 단어 포함 여부
→ 포함: 스팸 4, 정상 1 → H ≈ 0.72
→ 미포함: 스팸 1, 정상 4 → H ≈ 0.72
→ 평균 H = 0.72
→ 정보이득 = 1.0 − 0.72 = 0.28
의사결정 트리 구조
의사결정 트리는 각 분기점에서 정보이득이 가장 큰 특징을 선택합니다. 이것이 이산적 최적화입니다. 경사하강법(연속 최적화)과 비교됩니다.

최적화 방법 비교

📉
경사하강법 (연속 최적화)
  • 손실함수 L(w)를 미분하여 최솟값 탐색
  • 가중치(w)가 연속적인 수
  • 적합 문제: 회귀, 신경망 학습
  • 목적: 오차 최소화
🌳
의사결정 트리 (이산 최적화)
  • 엔트로피/정보이득으로 최적 분기 선택
  • 선택지가 이산적 (예/아니오)
  • 적합 문제: 분류, 규칙 생성
  • 목적: 불확실성 최소화
공통점: 둘 다 어떤 기준값을 최소화하여 최적의 의사 결정을 내린다
교과서는 손실함수를 중심으로 연속 최적화를 가르칩니다. 의사결정 트리는 고등 AI 수학에서 이산 최적화의 대표 예시로 사용됩니다.

2변수 경사하강법 — 종합 예제

L(w₁,w₂) = w₁² + w₂²,   η = 0.1,   초기: (w₁,w₂) = (2, 3)

초기
w₁=2, w₂=3  →  L = 2² + 3² = 13,   η = 0.1
1회 갱신
∂L/∂w₁ = 2w₁ = 4,   ∂L/∂w₂ = 2w₂ = 6
w₁ = 2 − 0.1×4 = 1.6,   w₂ = 3 − 0.1×6 = 2.4   L = 8.32
2회 갱신
w₁ = 1.6−0.1×3.2 = 1.28,   w₂ = 2.4−0.1×4.8 = 1.92   L = 5.32
3회 갱신
w₁ = 1.024,   w₂ = 1.536  →  L ≈ 3.41
수렴
반복할수록 (0, 0)으로 수렴  →  L(w₁,w₂) = w₁²+w₂²의 최솟값은 w₁=w₂=0에서 L=0
0 / 5
2변수로 확장된 경사하강법. 각 변수에 대해 편미분을 구하고 독립적으로 갱신합니다. L=w₁²+w₂²는 원점이 최솟값인 그릇 모양 함수입니다.

확인 문제

Q. L(w) = w² − 4w + 5에서 경사하강법 1회 적용 후 w₁은?
(η = 0.1, w₀ = 0)
① w₁ = 0.2     ② w₁ = 0.4     ③ w₁ = 0.6     ④ w₁ = 0.8
풀이:
L'(w) = 2w − 4  →  w₀=0 대입: L'(0) = −4
w₁ = 0 − 0.1 × (−4) = 0.4  →  정답 ②
검증: L(0.4) = 0.16 − 1.6 + 5 = 3.56 < L(0) = 5 ✓
다음 차시: 다항함수의 미분 심화 | 최적화 탐구 주제 선정
학생들이 먼저 풀어보게 한 후 정답을 공개합니다. L'(w)=2w-4이고 w=0에서 기울기=-4, 갱신식 적용하면 w₁=0+0.4=0.4입니다.
