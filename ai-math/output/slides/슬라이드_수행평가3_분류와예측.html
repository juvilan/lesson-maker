Part A — 좌표평면 분류

데이터를 좌표평면에 나타내면?

핵심 아이디어

두 변량 \(x, y\)를 좌표평면에 찍으면
같은 그룹끼리 뭉쳐서 나타난다.
→ 직선 하나로 두 그룹을 구분!

분류 기준선

\(y = ax + b\)

직선 위쪽 → A그룹
직선 아래쪽 → B그룹

I단원 퍼셉트론과 같은 원리!
가중합으로 직선을 만들어 분류

● A그룹   ● B그룹   — 분류 기준선

Part A — 분류 기준선으로 분류하기

새 데이터를 분류하는 방법

분류 기준선 \(f(x) = ax + b\)에서
새 데이터 \((x_0,\, y_0)\)에 대해 \(f(x_0)\)를 계산한다.

\(y_0 > f(x_0)\)
직선 위쪽 → A그룹
\(y_0 < f(x_0)\)
직선 아래쪽 → B그룹

예시. 분류 기준선: \(f(x) = -x + 10\)

A그룹(●): 가(2,9), 나(3,8), 다(4,8)   /   B그룹(○): 라(7,2), 마(8,1), 바(6,2)

새 학생 '사': 수학 5점, 과학 4점 → \((x_0, y_0) = (5, 4)\)

\(f(5) = -5 + 10 = 5\)     \(y_0 = 4 < 5 = f(5)\)   →   B그룹으로 분류

✏ 서술 예시: "사의 과학 점수 4점은 분류선에서의 값 5보다 낮으므로, 직선 아래에 위치하여 B그룹으로 분류된다."

Part B — 확률과 예측

확률로 예측하기

자료에서 각 사건의 확률을 계산하면,
확률이 가장 높은 사건을 예측값으로 선택한다.

\[P(\text{사건}) = \dfrac{\text{빈도수}}{\text{전체}}\]

조건부 확률

\(P(A \mid B)\): 사건 B가 주어졌을 때
사건 A가 일어날 확률
→ 조건에 따라 예측 결과가 달라진다!

예) 60명 학생의 좋아하는 계절

봄여름가을합계
남814830
여681630
합계14222460
전체 예측: P(봄)=14/60, P(여름)=22/60, P(가을)=24/60 최대
→ 가을을 좋아한다고 예측
여학생 조건: P(봄|여)=6/30, P(여름|여)=8/30, P(가을|여)=16/30 최대
→ 조건을 줘도 가을 예측 (하지만 비율은 달라짐!)
Part B — 예측 오차의 원인

왜 예측이 빗나갈 수 있는가?

① 표본의 제한성

조사한 사람 수가 적으면 실제 모집단의 비율과 차이가 날 수 있다.
예) 60명의 계절 선호도가 전교 1,000명의 선호도와 다를 수 있음

② 개인차

확률은 집단 전체의 경향성을 나타낼 뿐,
특정 개인이 어떤 선택을 할지는 보장하지 않는다.

③ 반영되지 않은 조건

실제 선택에는 성별·학년 외에도 가족, 경험, 환경 등
다양한 변수가 작용하지만, 표에 모두 담을 수 없다.

서술 포인트: 표본 수 제한 + 개인차 + 고려하지 못한 변수 → 오차 발생
Part C — 경향성과 추세선

산점도와 상관관계

산점도: 두 변량 \(x,y\)의 데이터를 좌표평면에 나타낸 그래프

양의 상관관계

\(x\uparrow\) → \(y\uparrow\)
우상향 분포

음의 상관관계

\(x\uparrow\) → \(y\downarrow\)
우하향 분포

추세선 (Trend Line)

\(f(x) = ax + b\)

공학적 도구로 구함
\(a > 0\): 양의 상관, \(a < 0\): 음의 상관

독서량(x권/월)과 어휘력(y점) — 양의 상관관계

추세선: \(f(x) = 5x + 50\) (공학적 도구)
Part C — 예측값과 오차

추세선으로 예측하고 오차 구하기

예측값

새 \(x\) 값을 추세선에 대입

\(\text{예측값} = f(x_0) = ax_0 + b\)

오차 (잔차)

\[(\text{오차}) = y - f(x)\] \[(\text{오차의 크기}) = |y - f(x)|\]

※ 오차가 음수면 실측값 < 예측값

추세선: f(x) = 5x + 50

예측: 월 독서량 6권인 학생의 어휘력은?

Part C — 확인 문제

확인 문제

문제. 어느 도시의 최고 기온(x℃)과 아이스크림 판매량(y백 개)을 조사한 자료에서 공학적 도구로 구한 추세선이 \(f(x) = 0.5x - 6\)이다.

기온(x℃)2428303236
판매량(y)6891113

(1) 기온이 높을수록 판매량이 어떻게 변하는가?

→ 양의 상관관계 (함께 증가)

(2) 기온 38℃인 날의 판매량을 예측하시오.

\(f(38) = 0.5 \times 38 - 6 = 13\text{(백 개)}\)

(3) 기온 32℃인 날의 오차와 오차의 크기를 구하시오.

\(f(32) = 0.5\times32 - 6 = 10\)
오차 \(= 11 - 10 = 1\)
오차의 크기 \(= |1| = 1\)
