자료(data)란?

관찰이나 측정 등을 통해 얻게 되는 가공되지 않은 정보

예: 키와 성적, 각종 설문을 통해 얻는 값이나 의견

정형 Structured

일정한 형식을 갖춘 자료

예: 회계 자료, 학생 명단, 성적표

비정형 Unstructured

일정한 형식을 갖추지 않은 자료

예: 댓글, 음성, 사진, 동영상

왜 중요한가?  컴퓨터(AI)는 수(숫자)만 처리할 수 있습니다. 자료를 목적에 맞게 수로 변환하는 것이 인공지능 수학의 출발점입니다.

자료의 종류 비교

정형(Structured) 자료

일정한 형식 O

📋 학생 성적표
📋 출석부
📋 회계 장부
📋 주소록

행과 열이 명확하고, 규칙적 구조

비정형(Unstructured) 자료

일정한 형식 X

💬 SNS 댓글 / 게시물
🎵 음성 파일
🖼️ 사진 / 이미지
🎬 동영상

구조가 없고, 자유로운 형태

전 세계 데이터의 약 80~90%가 비정형 자료 — AI가 처리할 수 있도록 변환하는 방법을 배웁니다!

불용어 제거 후 집합 표현

3개의 영화 댓글을 각각 집합으로 나타냅니다.

댓글 A "이 영화는 긴장감과 감동이 있는 영화예요."
A = { 영화, 긴장감, 감동 }
댓글 B "이 영화는 감동은 있지만 지루해서 실망이에요."
B = { 영화, 감동, 지루하다, 실망 }
댓글 C "추천! 눈물 없이는 볼 수 없는 감동적인 영화입니다."
C = { 추천, 눈물, 보다, 감동, 영화 }

불용어는 목적에 따라 다르게 설정

예시:  영화 감상 감성 분석이 목적이라면, '영화'와 '보다'는 모든 댓글에 공통으로 나타나므로 불용어로 추가 처리 가능

추가 불용어 영화, 보다

A' = { 긴장감, 감동 }
B' = { 감동, 지루하다, 실망 }
C' = { 추천, 눈물, 감동 }

새로운 단어 사전

U' = { 긴장감, 감동, 지루하다, 실망, 추천, 눈물 }
8개 → 6개로 줄어들어 더 핵심적인 특징만 남음
핵심: 불용어 설정은 분석 목적에 따라 유동적으로 결정합니다.

집합을 벡터로 표현하기

단어 사전 U의 각 단어가 해당 집합에 속하면 1, 속하지 않으면 0으로 표현

집합 영화 긴장감 감동 지루하다 실망 추천 눈물 보다
A 1 1 1 0 0 0 0 0
B 1 0 1 1 1 0 0 0
C 1 0 1 0 0 1 1 1
각 행이 하나의 벡터가 됩니다. 이제 컴퓨터가 처리할 수 있는 형태로 변환 완료!

벡터 표현 결과

단어 사전 U = {영화, 긴장감, 감동, 지루하다, 실망, 추천, 눈물, 보다} 순서에 따름

\(\vec{A}\) =  (1,  1,  1,  0,  0,  0,  0,  0)
\(\vec{B}\) =  (1,  0,  1,  1,  1,  0,  0,  0)
\(\vec{C}\) =  (1,  0,  1,  0,  0,  1,  1,  1)
정리:  비정형 텍스트 댓글 3개가 각각 8차원 벡터로 변환되었습니다.
이제 AI 알고리즘이 수학적으로 처리할 수 있습니다!

벡터(vector)란?

\(n\)개의 수 \(x_1, x_2, \ldots, x_n\)을 괄호 속에 순서대로 나열하여 나타낸

\[ \vec{X} = (x_1,\; x_2,\; \ldots,\; x_n) \]

을 벡터라 한다.

첫째 성분

\(x_1\)

\(n\)째 성분

\(x_n\)

예시:  댓글 A의 벡터 \(\vec{A} = (1, 1, 1, 0, 0, 0, 0, 0)\) 에서
첫째 성분 = 1 (영화 ∈ A),  넷째 성분 = 0 (지루하다 ∉ A)
주의:  벡터는 순서가 중요합니다. 단어 사전의 순서를 반드시 지켜야 합니다.

확인 문제

벡터 \(\vec{X} = (1,\; 0,\; 2,\; 3,\; 1)\) 에서 다음을 구하시오.

(1)  벡터 \(\vec{X}\) 의 둘째 성분은?

→  0 (x₂ = 0)

(2)  벡터 \(\vec{X}\) 의 넷째 성분은?

→  3 (x₄ = 3)
확인:  \(\vec{X} = (\underbrace{1}_{x_1},\; \underbrace{0}_{x_2},\; \underbrace{2}_{x_3},\; \underbrace{3}_{x_4},\; \underbrace{1}_{x_5})\) — 성분 번호와 위치를 꼭 확인하세요!

활동: 돈가스 음식점 후기 분석

후기 A 수제 돈가스가 맛있고, 양도 많았어요~!
후기 B 돈가스에 치즈가 많아요, 치즈 돈가스 추천!
후기 C 역시 수제 돈가스! 치즈 돈가스와 카레 돈가스도 맛있어요!
A = {수제, 맛있다, 양, 많다}
B = {치즈, 많다, 추천}
C = {수제, 치즈, 카레, 맛있다}
U = {수제, 맛있다, 양, 많다, 치즈, 추천, 카레} (7개)
\(\vec{A}\) =  (1,1,1,1,0,0,0) 수제·맛있다·양·많다 ∈ A
\(\vec{B}\) =  (0,0,0,1,1,1,0) 많다·치즈·추천 ∈ B
\(\vec{C}\) =  (1,1,0,0,1,0,1) 수제·맛있다·치즈·카레 ∈ C

개념 정리하기

관찰이나 측정 등을 통해 얻게 되는 가공되지 않은 정보를  자료  라고 한다.
정형  자료는 일정한 형식을 갖춘 자료이고,  비정형  자료는 일정한 형식을 갖추지 않은 자료이다.
텍스트 자료는 집합이나  벡터  로 나타낼 수 있다.
\(n\)개의 수를 괄호 속에 순서대로 나열한 것을  벡터  라 한다.

핵심 흐름 정리

텍스트 자료  →  낱말 분리 + 불용어 제거  →  집합  →  벡터  →  AI 처리
