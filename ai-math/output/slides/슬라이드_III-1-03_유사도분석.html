유사도(Similarity)란?

두 텍스트 사이의 유사한 정도를 수학적으로 수치화한 것
→ '유사한 정도'는 주관적이므로 정량화가 필요

유클리드 유사도

두 벡터 사이의 거리
값이 작을수록 유사

코사인 유사도

두 벡터가 이루는 각도의 코사인
1에 가까울수록 유사

자카드 유사도

두 집합의 공통 원소 비율
1에 가까울수록 유사

① 유클리드 유사도(Euclid Similarity)

두 텍스트 P, Q의 벡터가 \(\vec{P}=(p_1,p_2,\ldots,p_n)\), \(\vec{Q}=(q_1,q_2,\ldots,q_n)\)일 때,

\[L(\vec{P},\vec{Q}) = \sqrt{(p_1-q_1)^2+(p_2-q_2)^2+\cdots+(p_n-q_n)^2}\]

※ 두 벡터의 끝점 사이의 좌표평면 거리와 같다. 값이 작을수록 유사.

예제

세 텍스트 P, Q, R의 벡터: \(\vec{P}=(1,0,1)\), \(\vec{Q}=(0,1,2)\), \(\vec{R}=(1,1,0)\)일 때, 가장 유사한 두 텍스트를 구하시오.

\(L(P,Q)=\sqrt{(1-0)^2+(0-1)^2+(1-2)^2}=\sqrt{3}\)
\(L(Q,R)=\sqrt{(0-1)^2+(1-1)^2+(2-0)^2}=\sqrt{5}\)
\(L(R,P)=\sqrt{(1-1)^2+(1-0)^2+(0-1)^2}=\sqrt{2}\)

∴ \(L(R,P)=\sqrt{2}\)가 가장 작으므로 P와 R이 가장 유사

② 코사인 유사도(Cosine Similarity)

두 텍스트 P, Q의 벡터가 \(\vec{P}=(p_1,\ldots,p_n)\), \(\vec{Q}=(q_1,\ldots,q_n)\)일 때,

\[C(\vec{P},\vec{Q}) = \dfrac{p_1 q_1 + p_2 q_2 + \cdots + p_n q_n}{\sqrt{p_1^2+\cdots+p_n^2}\ \cdot\ \sqrt{q_1^2+\cdots+q_n^2}}\]

※ \(C(\vec{P},\vec{Q}) = \cos\theta\) (두 벡터가 이루는 각의 코사인)   \(0 \le C \le 1\), 값이 클수록 유사

예제

\(\vec{P}=(1,1,0)\), \(\vec{Q}=(2,0,0)\), \(\vec{R}=(1,0,2)\)일 때, 가장 유사한 두 텍스트를 구하시오.

\(C(P,Q)=\dfrac{1\cdot2+1\cdot0+0\cdot0}{\sqrt{2}\cdot2}=\dfrac{2}{2\sqrt{2}}=\dfrac{1}{\sqrt{2}}\approx 0.71\)
\(C(Q,R)=\dfrac{2}{\sqrt{5}\cdot2}\approx 0.45\),  \(C(R,P)=\dfrac{1}{\sqrt{5}\cdot\sqrt{2}}\approx 0.32\)

∴ \(C(P,Q)\)가 가장 크므로 P와 Q가 가장 유사

③ 자카드 유사도(Jaccard Similarity)

두 텍스트 P, Q를 구성하는 단어의 집합이 \(P=\{p_1,\ldots,p_k\}\), \(Q=\{q_1,\ldots,q_m\}\)일 때,

\[J(P,Q) = \dfrac{n(P \cap Q)}{n(P \cup Q)} = \dfrac{n(P \cap Q)}{n(P)+n(Q)-n(P \cap Q)}\]

※ 두 집합에 공통으로 포함되는 원소가 많을수록 유사  ·  \(0 \le J(P,Q) \le 1\)

예제

\(P=\{\text{빨강, 노랑, 파랑}\}\), \(Q=\{\text{빨강, 초록, 보라}\}\), \(R=\{\text{초록, 파랑, 보라}\}\)일 때, 가장 유사한 두 텍스트를 구하시오.

\(J(P,Q)=\dfrac{1}{5}\),  \(J(Q,R)=\dfrac{2}{4}=\dfrac{1}{2}\),  \(J(R,P)=\dfrac{1}{5}\)

∴ \(J(Q,R)\)가 가장 크므로 Q와 R이 가장 유사

유사도 분석으로 텍스트 자동 분류 완성

확인 문제

문제 1. 세 텍스트 P, Q, R를 나타내는 벡터가 다음과 같을 때, 유클리드 유사도를 이용하여 가장 유사한 두 텍스트를 고르시오.

\[\vec{P}=(2,0,1,1),\quad \vec{Q}=(0,1,0,2),\quad \vec{R}=(1,3,1,0)\]

\(L(P,Q)=\sqrt{4+1+1+1}=\sqrt{7}\),  \(L(Q,R)=\sqrt{1+4+1+4}=\sqrt{10}\),  \(L(R,P)=\sqrt{1+9+0+1}=\sqrt{11}\)

∴ P와 Q가 가장 유사

문제 2. 두 텍스트 P, Q를 구성하는 단어의 집합이 \(P=\{\text{쥐, 호랑이, 용}\}\), \(Q=\{\text{소, 호랑이, 용, 뱀}\}\)일 때, 자카드 유사도 \(J(P,Q)\)를 구하시오.

\(P\cap Q=\{\text{호랑이, 용}\}\), \(P\cup Q=\{\text{쥐, 소, 호랑이, 용, 뱀}\}\)

\(J(P,Q)=\dfrac{2}{5}\)

핵심 정리

유클리드 유사도

\(L = \sqrt{\sum(p_i - q_i)^2}\)

작을수록 유사 (범위: \(L \ge 0\))

코사인 유사도

\(C = \dfrac{\vec{P}\cdot\vec{Q}}{|\vec{P}||\vec{Q}|}\)

클수록 유사 (범위: \(0 \le C \le 1\))

자카드 유사도

\(J = \dfrac{n(P \cap Q)}{n(P \cup Q)}\)

클수록 유사 (범위: \(0 \le J \le 1\))

유사도 분석 → 텍스트를 의미 있는 그룹으로 자동 분류
