07

해밍 거리 정의와 계산

4분
도입
이제 두 이미지가 얼마나 다른지 측정하는 방법 — 해밍 거리를 배웁니다.
단계별 설명
H(A, B) = 두 행렬에서 값이 서로 다른 성분의 개수. → [클릭: Step 1] 행렬 P = [[1,0],[1,1]], Q = [[1,1],[0,1]]입니다. → [클릭: Step 2] 위치별 비교: (1,1): 1과 1 → 같음. (1,2): 0과 1 → 다름! (2,1): 1과 0 → 다름! (2,2): 1과 1 → 같음. → [클릭: Step 3] 다른 위치 2곳 → H(P,Q) = 2입니다.
시각화 활동
→ [시각화 버튼 클릭] 빨간색으로 표시된 성분 확인.
질문 포인트
Q: H(A,B) = 0이면 무슨 의미일까요? [학생 응답: 두 이미지가 완전히 같다]
오개념 예방
주의! 해밍 거리는 유클리드 거리와 다릅니다. 유클리드는 차이의 크기를 보지만, 해밍은 다른 위치의 개수만 셉니다. 0/1 이진 이미지에 특화된 측정법이에요.
마무리
H가 작을수록 두 이미지가 유사합니다.
08

해밍 거리로 이미지 분류

3분
도입
교과서 예시 — 전광판 이미지 분류입니다.
단계별 설명
A = 숫자 0 (성분합 19), B = 숫자 8 (성분합 17), C = 불완전한 이미지. → [클릭: Step 1] H(C, A) = 5. C와 A에서 다른 성분이 5곳. → [클릭: Step 2] H(C, B) = 3. C와 B에서 다른 성분이 3곳. → [클릭: Step 3] H(C,B) < H(C,A) → C는 B(숫자 8)에 더 가깝다! 따라서 C를 숫자 8로 분류합니다.
비유
이걸 사람으로 치면, '8과는 3곳만 다르고, 0과는 5곳이나 다르니까 8이겠구나' 판단하는 겁니다.
질문 포인트
Q: H(C,A)와 H(C,B)가 같으면 어떻게 해야 할까요? [학생 생각 시간 20초] → 다른 방법으로 판단하거나, 추가 이미지가 필요합니다.
마무리
이제 두 번째 방법 — 퍼셉트론으로 분류해봅시다.

두 가지 분류 방법 비교

도입
해밍 거리와 퍼셉트론, 두 방법의 차이를 잠깐 짚어보겠습니다.
비교
→ 해밍 거리: 다른 성분의 개수, 작을수록 유사. 계산 간단. → 퍼셉트론: 가중치 W = (1/합) × 템플릿, 분류 점수가 클수록 유사. → [클릭] 공통점: 두 방법 모두 유사한 픽셀이 많을수록 같은 종류로 판단한다는 원리.

주의! 퍼셉트론이 '왜 성분합으로 나누나요?' — 이미지마다 밝은 픽셀(1) 수가 다르니까, 공평하게 비교하기 위해 정규화합니다.

퍼셉트론으로 이미지 분류

3분

전개
→ [클릭] 가중치 행렬 만들기: W_A = (1/A의 성분 합) × A. 정규화된 가중치입니다. → [클릭] 분류 점수: 입력 이미지 C의 벡터에 W_A를 적용하여 가중합 x를 계산합니다. 점수가 클수록 C가 A에 가깝습니다. → 오른쪽 다이어그램: 35개 픽셀값 → 가중치 내적 → 분류 점수 0.82 출력.
비유
이미지의 픽셀들이 주어진 템플릿과 얼마나 겹치는지 점수를 냅니다. 겹치는 픽셀이 많을수록 점수가 높아요.
마무리

가중치 행렬 W 계산

4분
도입
교과서 7×5 전광판 예시로 계산해봅시다.
단계별 계산
→ [클릭: Step 1] W_A = (1/19) × A. 숫자 0 이미지 A의 성분 합이 19이므로 각 원소를 19로 나눕니다. → [클릭: Step 2] W_B = (1/17) × B. 숫자 8 이미지 B의 성분 합이 17이므로 17로 나눕니다. → [클릭: Step 3] 이미지 C를 두 퍼셉트론에 입력: P_A 점수 = 0.74, P_B 점수 = 0.82. 0.82 > 0.74이므로 B(숫자 8)로 분류!
📋 판서 (칠판)
W_A = (1/19) × A W_B = (1/17) × B
질문 포인트
Q: 왜 1/19이 아니라 1/19 × A 전체인가요? [학생 응답 대기] → 행렬 A의 각 성분이 그대로 가중치 역할을 합니다. 템플릿과 같은 위치에 1이 있으면 그 위치의 가중치가 1/19이 됩니다.
오개념 예방
주의! W_A와 W_B의 분모가 다릅니다(19 vs 17). 왜일까요? 이미지마다 켜진 픽셀 수가 달라서 공평하게 비교하기 위해 각자의 합으로 나눕니다.
마무리
해밍 거리(3 < 5)와 퍼셉트론(0.82 > 0.74) 두 방법 모두 C를 숫자 8로 분류했습니다!
