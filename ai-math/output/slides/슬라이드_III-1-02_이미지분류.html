해밍 거리(Hamming Distance)

두 이미지 A, B를 나타내는 행렬이 모든 성분이 0 또는 1일 때,

\[H(A,B) = (\text{두 행렬 A와 B에서 값이 서로 다른 성분의 개수})\]

※ 해밍 거리가 작을수록 두 이미지가 유사 → 같은 숫자로 분류

보기

세 이미지 P, Q, R를 나타내는 행렬: \(P=\begin{pmatrix}1&0\\1&1\end{pmatrix}\), \(Q=\begin{pmatrix}1&1\\0&1\end{pmatrix}\), \(R=\begin{pmatrix}1&0\\1&0\end{pmatrix}\)

\(p_{11}=r_{11}\), \(p_{12}=r_{12}\), \(p_{21}=r_{21}\), \(p_{22}\neq r_{22}\)

\(H(P,Q)=2\),  \(H(P,R)=1\)  → P는 R과 더 유사

H(C, A) 계산

값이 다른 성분 수

H(C, A) = 5

H(C, B) 계산

값이 다른 성분 수

H(C, B) = 3

\(H(C,B) < H(C,A)\) → 인공지능은 이미지 C를 숫자 8로 분류

인공신경망과 퍼셉트론

인간의 신경 세포

가지 돌기로 자극을 받아들이고, 자극의 세기가 임갯값보다 크면 축삭 돌기를 통해 다음 세포로 신호 전달

퍼셉트론(Perceptron)

신경 세포를 수학적으로 모델링한 것
입력값에 가중치를 곱하여 더한 합이 임갯값 이상이면 출력값 전달

퍼셉트론 수식

\[x = x_1 w_1 + x_2 w_2 + \cdots + x_n w_n\]
\[\sigma(x) = \begin{cases} 0 & (x < \theta) \\ c & (x \ge \theta) \end{cases}\]

※ \(w_i\): 가중치, \(\theta\): 임갯값, \(c\): 출력 상수

퍼셉트론으로 이미지 분류하기

행렬 → 입력값 변환

이미지를 나타내는 \(m \times n\) 행렬의 성분을 일렬로 나열하면 \(r = m \times n\)개의 입력값 \(x_1, x_2, \ldots, x_r\)

\[x = x_1 w_1 + x_2 w_2 + \cdots + x_r w_r \quad (r = m \times n)\]

가중치 행렬 W

각 픽셀이 출력에 미치는 영향을 나타내는 가중치를 행렬로 정리

\(W = \begin{pmatrix}w_{11}&\cdots&w_{1n}\\\vdots&&\vdots\\w_{m1}&\cdots&w_{mn}\end{pmatrix}\)

분류 결과

\(x\) 계산 후 활성화함수 \(\sigma(x)\) 적용

이미지 C → 일렬 나열 → x 계산 → σ(x) → 숫자 분류

출력값이 0 또는 c인지에 따라 분류 결정

확인 문제

문제. 세 이미지 P, Q, R를 나타내는 행렬이 다음과 같을 때, \(H(P,Q)\)와 \(H(Q,R)\)을 구하시오.

\[P=\begin{pmatrix}0&1&0\\1&0&1\\0&1&0\end{pmatrix},\quad Q=\begin{pmatrix}1&0&0\\1&1&0\\1&1&1\end{pmatrix},\quad R=\begin{pmatrix}0&1&0\\1&0&1\\1&1&1\end{pmatrix}\]

P와 Q 비교:
다른 성분: (1,1), (1,2), (2,2), (3,1), (3,2)

\(H(P,Q)=6\)

Q와 R 비교:
다른 성분: (1,1), (1,2), (2,2)

\(H(Q,R)=4\)

∴ \(H(Q,R) < H(P,Q)\) → Q와 R이 더 유사

핵심 정리

해밍 거리

\(H(A,B) = \text{(다른 성분의 개수)}\)

작을수록 유사 → 같은 이미지로 분류

퍼셉트론

\(x = \sum x_i w_i\),  \(\sigma(x) = \begin{cases}0&(x<\theta)\\c&(x\ge\theta)\end{cases}\)

이미지 → 일렬 나열 → 가중합 → 분류
