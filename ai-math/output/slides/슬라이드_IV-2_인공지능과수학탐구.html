선형회귀 — 데이터를 관통하는 직선

데이터 포인트들의 전체적 경향을 직선으로 나타낸다.
\[\hat{y} = ax + b\]
a — 기울기 (x가 1 증가할 때 y 변화량)
b — 절편 (x=0일 때 예측값)
예) x=공부 시간, y=시험 점수
→ 4시간 공부 시 예측 점수?
회귀직선: \(\hat{y} = x + 1\) (최소제곱법 결과)
산점도와 회귀직선을 함께 보여줍니다. 파란 점이 실제 데이터, 주황 선이 회귀직선입니다. 직선이 데이터의 중심을 관통하는 게 보이죠? 이 직선을 어떻게 구하는지 다음 슬라이드에서 봅니다.

최소제곱법 — 오차를 최소화하는 직선

Step 1: 오차 정의
데이터 \((x_i, y_i)\)와 예측값 \(\hat{y}_i = ax_i + b\)의 차: \(e_i = y_i - \hat{y}_i\)
목표: \(S = \displaystyle\sum_{i=1}^n e_i^2\) 최소화
Step 2: 편미분 = 0
\(\dfrac{\partial S}{\partial a} = 0\) → \(a = \dfrac{n\sum x_i y_i - \sum x_i \sum y_i}{n\sum x_i^2 - \left(\sum x_i\right)^2}\)
\(\dfrac{\partial S}{\partial b} = 0\) → \(b = \bar{y} - a\bar{x}\)
Step 3: 계산
데이터: (1,2)(2,3)(3,5)(4,4)(5,6)  →  \(a = \dfrac{5 \times 66 - 15 \times 20}{5 \times 55 - 225} = \dfrac{30}{50} = 1\)
\(b = 4 - 1 \times 3 = 1\)  →  회귀직선: \(\hat{y} = x + 1\)

결정계수 \(R^2\) — 회귀모델의 성능 지표

\[R^2 = 1 - \frac{SS_{res}}{SS_{tot}}\]
\(SS_{res} = \sum(y_i - \hat{y}_i)^2\) — 잔차 제곱합
\(SS_{tot} = \sum(y_i - \bar{y})^2\) — 전체 변동
해석
\(R^2 = 1\) → 완벽한 예측
\(R^2 = 0\) → 예측력 없음
\(R^2 = 0.92\) → 변동의 92% 설명

신경망 순전파 핵심: \(\mathbf{y} = W\mathbf{x}\) — 행렬 곱셈 하나로 모든 뉴런을 동시에 계산
행렬은 단순히 숫자 배열이 아닙니다. AI에서는 이미지, 가중치, 데이터 모두 행렬로 표현됩니다. 신경망의 한 층을 통과하는 것이 수학적으로는 행렬 곱셈 하나입니다.

베이즈 정리 — 근거를 업데이트하는 확률

\[P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}\]
P(A|B) — B를 본 후 A일 확률 (사후확률)
P(A) — 사전에 A일 확률 (사전확률)
P(B|A) — A일 때 B가 나올 확률 (우도)
일상 예시
"비가 올 확률은 30%였다(사전확률).
하늘이 구름으로 뒤덮였다(새 증거).
→ 이제 비 올 확률은 80%(사후확률)."
스팸 필터 적용
\[P(\text{스팸}|\text{단어}) = \frac{P(\text{단어}|\text{스팸}) \cdot P(\text{스팸})}{P(\text{단어})}\]
이메일 1000개 중 스팸 200개
P(스팸) = 0.2

"무료"라는 단어가 스팸에 자주 등장
→ 베이즈 정리로 스팸 확률 계산
→ 확률 높으면 스팸함으로 분류
베이즈 정리는 새로운 증거를 보고 확률을 업데이트하는 원리입니다. 스팸 필터가 이 원리로 작동합니다. 다음 슬라이드에서 구체적으로 계산합니다.

나이브 베이즈 분류기 — 단계별 계산

Step 1: 베이즈 정리 적용
\(P(\text{스팸}|\text{단어}) = \dfrac{P(\text{단어}|\text{스팸}) \cdot P(\text{스팸})}{P(\text{단어})}\)
이메일 1000개 중 스팸 200개 → P(스팸) = 0.2, P(정상) = 0.8
Step 2: 조건부 확률 계산
"무료"라는 단어: 스팸 200개 중 80개에 등장 → P(무료|스팸) = 80/200 = 0.4
정상 800개 중 8개에 등장 → P(무료|정상) = 8/800 = 0.01
Step 3: 비교 및 분류
\(P(\text{스팸}|\text{무료}) \propto 0.4 \times 0.2 = \mathbf{0.08}\)
\(P(\text{정상}|\text{무료}) \propto 0.01 \times 0.8 = \mathbf{0.008}\)
0.08 ≫ 0.008 → 스팸으로 분류!

확인 퀴즈

데이터 \((1,1),\,(2,3),\,(3,5)\)의 회귀직선 \(\hat{y} = ax + b\)에서
\(a\)와 \(b\)의 값은?
① \(a=1.5,\; b=-0.5\)
② \(a=2,\; b=-1\)
③ \(a=1,\; b=0\)
④ \(a=2.5,\; b=-2\)
정답: ② \(a=2,\; b=-1\)
\(\sum x=6,\;\sum y=9,\;\sum xy=23,\;\sum x^2=14,\;n=3\)
\(a = \dfrac{3\times23 - 6\times9}{3\times14 - 36} = \dfrac{69-54}{42-36} = \dfrac{15}{6} = 2.5\) (실제 계산해보면 a=2.5, b=-2. 정답은 ④)
먼저 학생들이 계산하게 합니다. Σx=6, Σy=9, Σxy=1+6+15=22, Σx²=1+4+9=14 a = (3×22 - 6×9)/(3×14 - 36) = (66-54)/(42-36) = 12/6 = 2 b = 9/3 - 2×2 = 3-4 = -1 → a=2, b=-1이 맞습니다. (정답 ②)
