02 텍스트 자료의 처리

TF (단어 빈도수) DF (문서 빈도수) IDF (역문서 빈도수) TF·IDF
성취기준 12인수02-02

수와 수학 기호로 표현된 텍스트 자료를 처리하는 수학 원리를 이해하고
자료를 시각화할 수 있다.

고등 인공지능 수학  |  미래엔 pp.33–38

학습목표

1
단어 빈도수(TF)로 주제어를 찾을 수 있다.
각 문서에서 단어의 등장 횟수를 세어 가장 자주 등장하는 단어를 주제어로 파악한다.
2
TF·IDF 4단계 계산 방법을 이해하고 적용할 수 있다.
TF → DF → IDF → TF·IDF 순서로 계산하여 특정 문서만의 핵심 정보를 추출한다.
3
TF·IDF 값을 해석하여 유용한 정보를 도출할 수 있다.
값이 클수록 특정 문서에서 중요한 단어임을 이해하고, 실제 텍스트에서 의미를 읽어낸다.
핵심 질문:  "청바지 후기가 수백 개일 때, 어떤 후기가 진짜 유용한 정보를 담고 있을까?"

다가서기

비정형 텍스트에서 주제어와 유용한 정보를 어떻게 찾을 수 있을까?
후기 A

"청바지 추천! 예쁘고 저렴해서 청바지를 추천해요."

후기 B

"청바지의 가격, 디자인 다 좋아요. 특히 디자인 추천!^^"

후기 C

"신축성과 디자인이 좋고, 가격도 좋아서 이 청바지를 추천해요."

세 후기 모두 "청바지", "추천"이라는 단어를 공통으로 포함합니다.
하지만 각 후기가 전달하는 핵심 정보(추천 이유)는 서로 다릅니다.

문제

단순히 자주 나오는 단어만 보면 모든 후기의 핵심이 "청바지, 추천"으로 동일해 보인다.

→
해결

해당 문서에서만 자주 나오는 단어에 높은 가중치를 부여하면 각 후기의 핵심 정보를 추출할 수 있다.

TF의 원리:  같은 문서 안에서 반복되는 단어는 그 문서의 주제와 관련이 깊다. 마치 연설에서 자주 반복되는 단어가 핵심 주제인 것처럼.

단어 빈도수(TF) 표

각 행 = 하나의 후기, 각 열 = 단어 빈도  |  표는 순서대로 나타납니다.
후기 청바지 추천 예쁘다 저렴하다 가격 디자인 좋다 신축성
후기 A 2 2 1 1 0 0 0 0
후기 B 1 1 0 0 1 2 1 0
후기 C 1 1 0 0 1 1 2 1
말뭉치 합계 4 4 1 1 2 3 3 1
TF 최댓값으로 주제어 파악:
후기 A: 청바지, 추천 (TF=2)  |  후기 B: 디자인 (TF=2)  |  후기 C: 좋다 (TF=2)

벡터(Vector) 표현

TF 표의 각 행을 수의 나열(벡터)로 표현하면 수학적으로 다룰 수 있습니다.
순서: (청바지, 추천, 예쁘다, 저렴하다, 가격, 디자인, 좋다, 신축성)
\(\vec{A}\) = 2 2 1 1 0 0 0 0
\(\vec{B}\) = 1 1 0 0 1 2 1 0
\(\vec{C}\) = 1 1 0 0 1 1 2 1
벡터란?

크기와 방향을 가진 수학적 객체. 여기서는 단어들의 빈도를 순서대로 나열한 것.

활용:

두 문서의 벡터가 비슷하면 → 비슷한 내용
코사인 유사도 등으로 문서 분류에 활용

TF의 한계

문제점

"청바지"는 세 후기 모두에서 등장합니다.

의류 쇼핑몰 후기라면 모든 후기에 "청바지"가 등장하는 것은 당연합니다.

TF만 보면 "청바지"가 항상 주제어로 나오지만, 이는 당연한 정보일 뿐 각 후기의 특별한 정보가 아닙니다.

예시 1 — 영화 리뷰 사이트

"영화", "감독" 같은 단어는 모든 리뷰에 등장 → TF 높지만 정보 가치 낮음

예시 2 — 뉴스 기사

"기자", "보도" 등은 뉴스 전반에 공통 → TF 높지만 특정 기사의 핵심이 아님

결론:  많은 문서에 공통으로 자주 등장하는 단어는 TF가 높더라도 특정 문서의 유용한 정보를 나타내지 못합니다.
→ 각 문서에서만 특별히 자주 나오는 단어를 찾는 새로운 방법이 필요합니다.

TF·IDF 공식
TF·IDF = TF × IDF

IDF는 "많이 퍼진 단어는 점수 DOWN, 희귀한 단어는 점수 UP"

단계 1 — TF (단어 빈도수)

TF — 복습

정의

각 단어가 해당 문서(후기)에서 등장한 횟수

역할

TF·IDF 계산의 첫 번째 인수(因數). 문서 내 중요도 측정.

후기 청바지 추천 예쁘다 저렴하다 가격 디자인 좋다 신축성
후기 A 2211 0000
후기 B 1100 1210
후기 C 1100 1121
다음 단계: TF만으로는 "모든 문서에 공통으로 등장하는 단어"와 "특정 문서에만 등장하는 단어"를 구별하지 못합니다.
→ DF(문서 빈도수)로 각 단어가 몇 개 문서에 등장하는지 파악합니다.
단계 2 — DF (문서 빈도수) & 상대도수

DF — 단어가 등장하는 문서의 수

DF 정의

단어가 등장하는 문서의 개수
(전체 문서 수 n = 3)

상대도수 DF/n

DF를 전체 문서 수로 나눈 값
0과 1 사이의 값

구분 청바지 추천 예쁘다 저렴하다 가격 디자인 좋다 신축성
DF 3 3 1 1 2 2 2 1
DF/n 1 1 1/3 1/3 2/3 2/3 2/3 1/3
해석:
청바지, 추천: DF = 3 (전체 3개 후기 모두에 등장) → 상대도수 = 1 (최대)
예쁘다, 저렴하다, 신축성: DF = 1 (1개 후기에만 등장) → 상대도수 = 1/3 (최소)
단계 3 — IDF (역문서 빈도수)

IDF — 상대도수의 역수

\[ \text{IDF} = \frac{n}{\text{DF}} = \frac{1}{\text{DF}/n} \]
상대도수(DF/n)가 크면(많은 문서에 등장) → IDF 작음  |  상대도수가 작으면(희귀한 단어) → IDF 큼
구분 청바지 추천 예쁘다 저렴하다 가격 디자인 좋다 신축성
DF/n 111/31/32/32/32/31/3
IDF = n/DF 1 1 3 3 3/2 3/2 3/2 3
청바지, 추천 — IDF = 1
3개 문서 모두에 등장 → 역수 = 1 (낮은 정보 가치)
예쁘다, 저렴하다, 신축성 — IDF = 3
1개 문서에만 등장 → 역수 = 3 (높은 정보 가치)
참고 (실제 AI/검색엔진):  실제로는 IDF = \(\log\!\left(\dfrac{n}{\text{DF}}\right)\)을 사용하여 큰 값을 압축합니다.
예: n = 10,000,000, DF = 100이면 n/DF = 100,000이지만 log(100,000) ≈ 5로 관리 가능한 크기로 변환.
단계 4 — TF·IDF = TF × IDF

TF·IDF 계산

IDF 참고값: 청바지=1, 추천=1, 예쁘다=3, 저렴하다=3, 가격=3/2, 디자인=3/2, 좋다=3/2, 신축성=3
후기 청바지 추천 예쁘다 저렴하다 가격 디자인 좋다 신축성
후기 A 2×1=2 2×1=2 1×3=3 1×3=3 0 0 0 0
후기 B 1×1=1 1×1=1 0 0 1×3/2=3/2 2×3/2=3 1×3/2=3/2 0
후기 C 1×1=1 1×1=1 0 0 1×3/2=3/2 1×3/2=3/2 2×3/2=3 1×3=3
최고값(★): TF·IDF = 3인 단어들이 각 후기의 핵심 정보!
후기 A: 예쁘다, 저렴하다  |  후기 B: 디자인  |  후기 C: 좋다, 신축성

TF·IDF의 의미

TF·IDF 작으면 (→ 0에 가까울수록)
중요도 낮음
  • 여러 문서에 공통으로 자주 등장
  • 특정 문서에 특별한 정보를 제공하지 않음
  • 예: 청바지(1), 추천(1)
TF·IDF 크면 (→ 값이 클수록)
중요도 높음
  • 특정 문서에서만 자주 등장
  • 해당 문서만의 고유한 핵심 정보
  • 예: 예쁘다(3), 신축성(3)
\[ \text{TF·IDF}(t, d) = \underbrace{\text{TF}(t, d)}_{\text{문서 } d \text{에서 단어 } t \text{의 빈도}} \times \underbrace{\frac{n}{\text{DF}(t)}}_{\text{단어 } t \text{가 특정 문서에만 있을수록 } \uparrow} \]
실생활 활용
  • 인터넷 검색 엔진의 문서 순위 결정
  • 추천 시스템 (Netflix, 쇼핑몰 등)
  • 뉴스 기사 자동 분류
  • 챗봇 대화 의도 파악
발전 방향
  • IDF에 로그(log) 적용 → 값 안정화
  • Word2Vec: 의미 기반 벡터
  • BERT, GPT: 문맥 이해까지 확장

개념 정리하기

단어 빈도수 (TF, Term Frequency)
단어가 해당 문서에서 등장한 횟수.
TF가 가장 큰 단어 = 주제어
문서 빈도수 (DF, Document Frequency)
단어가 등장하는 문서의 개수.
상대도수 = DF ÷ 전체 문서 수 (n)
역문서 빈도수 (IDF, Inverse Document Frequency)
상대도수(DF/n)의 역수 = n/DF
희귀 단어일수록 IDF 큼
TF·IDF
TF × IDF
작으면 중요도 낮음  |  크면 중요도 높음
빈칸 채우기 — 핵심 정리
① 단어가 해당 문서에서 출현한 횟수를 구하면 TF (단어 빈도수)를 알 수 있다.
② DF를 전체 문서 수로 나눈 값을 상대도수라 한다.
③ IDF는 상대도수 DF/n의 역수이다.
④ TF·IDF가 작을수록 중요도가 낮은 단어, 클수록 중요도가 높은 단어이다.
1. TF — 문서 내 빈도 → 2. DF — 문서 빈도 → 3. IDF — 역수 → 4. TF·IDF
