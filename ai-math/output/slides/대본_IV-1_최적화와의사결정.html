S04
손실함수 L(w)=(w-3)²
8분
"손실함수, Loss Function이라고 합니다. 영어로 기억해두세요."
"교과서 104쪽 정의를 봐요. '추세선에 따른 오차의 제곱의 평균'이 손실함수입니다. 오차를 직접 더하면 양수·음수가 상쇄되니까, 제곱해서 모두 양수로 만든 뒤 평균을 냅니다."
L(a) = [(y₁−ax₁)² + (y₂−ax₂)² + ⋯ + (yₙ−axₙ)²] / n
"오늘은 개념 이해를 위해 더 단순한 형태 L(w) = (w−3)²로 시작합니다. 오른쪽 그래프를 봐요."
"그래프에서 L이 가장 작아지는 w는 얼마인가요?"
학생 답변 유도: "w = 3" → "맞습니다. 초록 점이 최솟값 L=0이에요."
"w = 0이면 오차가 9, w = 2이면 오차가 1, w = 3이면 오차가 0. AI는 이 손실함수를 가장 작게 만드는 w를 찾는 것이 목표입니다."
강조: L(w)가 이차함수이기 때문에 미분으로 정확한 최솟값을 구할 수 있다. → 다음 단계에서 경사하강법으로 수치적으로도 접근한다.
S05
경사하강법 1단계 애니메이션
5분
"경사하강법, Gradient Descent. 이름 그대로 '경사를 따라 내려가는 방법'입니다. 산 위에서 눈을 감고 발이 닿는 땅이 가장 낮은 방향으로 한 발씩 내딛는 거예요."
갱신식: w ← w − η × (∂L/∂w)
"N키를 눌러서 단계별로 진행해봐요. 또는 '다음' 버튼을 클릭합니다."
[Step 1 등장] "현재 위치 w₀=0, L(0) = 9입니다. 오차가 9라고 해봐요."
[Step 2 등장] "기울기를 계산합니다. ∂L/∂w = 2(w−3), w=0 대입하면 −6입니다. 기울기가 마이너스라는 건, 이 방향으로 가면 L이 올라간다는 뜻이에요. 반대로 가야 내려갑니다."
[Step 3 등장] "갱신식 적용: w₁ = 0 − 0.1×(−6) = 0 + 0.6 = 0.6"
[Step 4 등장] "L(0.6) = (0.6−3)² = 5.76. 9보다 줄었죠. 한 발 내딛었습니다!"
오개념 주의: "η×(∂L/∂w)에서 η는 보폭 크기, ∂L/∂w는 방향입니다. 빼는 이유: 기울기가 양수면 함수가 올라가는 방향이므로 반대로 이동."

S09
손실함수 최솟값 — 미분 활용 (교과서 핵심)
5분
"이제 교과서의 핵심 방법입니다. 손실함수가 이차함수면, 미분해서 L'(a) = 0 을 풀면 됩니다."
교과서 105쪽: L(a) = (880a² − 1672a + 830) / 5
L'(a) = (1760a − 1672) / 5 = 0
→ a = 1672/1760 = 19/20 = 0.95
"이 a = 0.95가 가장 오차가 작은 추세선의 기울기입니다. 그래프에서 포물선의 꼭짓점이죠. 접선의 기울기가 0인 지점."
"경사하강법은 이 0.95를 수치적·반복적으로 찾아가는 방법이고, 미분 = 0은 해석적으로 한 번에 구하는 방법입니다. 둘 다 같은 답을 찾는 방법이에요."
"경사하강법과 미분=0 방법 중 어느 것이 더 유용할까요? 왜요?"
"미분=0은 간단한 함수에서 정확합니다. 딥러닝처럼 수백만 개의 변수가 있으면 L'=0 연립방정식을 풀 수 없어서 경사하강법을 사용합니다."
S10~11
엔트로피 + 정보이득
7분
"이번엔 다른 유형의 최적화입니다. 의사결정 트리에서 쓰는 엔트로피예요."
"엔트로피는 불확실성의 양입니다. 동전을 던질 때 앞:뒤=50:50이면 결과를 전혀 모르니까 불확실성이 최대. H = 1 bit입니다."
H = −Σ pᵢ·log₂(pᵢ)
50:50 → H = −(0.5·log₂0.5 + 0.5·log₂0.5) = −(−0.5 + −0.5) = 1.0
80:20 → H = −(0.8·log₂0.8 + 0.2·log₂0.2) ≈ 0.72
100:0 → H = 0 (완전히 예측 가능)
막대 그래프 보면서: "어느 경우가 가장 불확실한가요?" → 학생 답변
"의사결정 트리는 데이터를 분류할 때, 분류 후 엔트로피가 가장 많이 줄어드는 특징을 선택합니다. 이것이 정보이득입니다."
정보이득 = 분기 전 H − 분기 후 평균 H
예: 전체 H=1.0 → 분기 후 평균 H=0.72 → 정보이득=0.28

S13
2변수 경사하강법 종합 예제
5분
"이제 실제 딥러닝에 더 가까운 2변수 버전을 봐요. L(w₁, w₂) = w₁² + w₂². 이건 원점이 최솟값인 그릇 모양 함수입니다."
초기: w₁=2, w₂=3 → L=4+9=13
편미분: ∂L/∂w₁=2w₁=4, ∂L/∂w₂=2w₂=6
갱신: w₁=2−0.1×4=1.6, w₂=3−0.1×6=2.4
→ L=1.6²+2.4²=2.56+5.76=8.32
"N키로 단계별로 보면서 따라가봐요. 각 변수가 독립적으로 업데이트됩니다. 반복할수록 (0,0)으로 수렴해요."
