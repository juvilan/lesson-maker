감성 사전

4분
[핵심 설명] "감성 사전은 AI의 단어장입니다. 각 단어에 미리 긍정, 부정, 중립 레이블을 붙여놓은 목록이에요." "표를 보겠습니다. 훌륭하다, 감동적이다 같은 단어는 긍정. 실망스럽다, 지루하다는 부정. 영화, 배우처럼 감정을 담지 않은 단어는 중립입니다." [질문 포인트] Q: "사전에 없는 단어는 어떻게 처리할까요? 예를 들어 신조어 '킹받다'는?" [학생 응답 대기: 20초] A: "사전에 없으면 보통 무시하거나 중립으로 처리합니다. 이게 한계 중 하나예요 — 나중에 다시 다룰 겁니다." [오개념 예방] "여기서 주의할 점이 있어요. '작다'라는 단어 — 음식 양이 작다면 부정이지만 가격이 작다면 긍정이 될 수 있죠. 같은 단어도 문맥에 따라 달라집니다. 지금 방식은 이 문맥을 무시한다는 걸 기억해두세요."

벡터 표현

4분
[핵심 설명] "자, 이제 텍스트를 벡터로 만들어봅니다. 벡터는 숫자를 나열한 것이죠. 여기서는 세 숫자입니다." "수식을 읽어볼게요: 벡터 v는 긍정 단어 수, 부정 단어 수, 중립 단어 수의 순서쌍입니다." "오른쪽 예시 텍스트를 보겠습니다: '연기는 훌륭했지만 스토리가 지루하고 음악이 시끄러웠다' → 훌륭했지만은 긍정 1개 → 지루하고, 시끄러웠다는 부정 2개 → 연기, 스토리, 음악은 중립 3개" → [클릭: fragment] "그래서 벡터 = (1, 2, 3)입니다." [질문 포인트] Q: "벡터 (1, 2, 3)만 보고 어떤 단어가 쓰였는지 알 수 있나요?" [학생 응답 대기: 15초] A: "알 수 없습니다. 이게 벡터 변환의 한계예요 — 단어 정보가 손실됩니다."
📋 판서
벡터 v = (긍정 수, 부정 수, 중립 수) 예: (1, 2, 3)
07

감성 점수 계산

5분
[핵심 설명] "드디어 핵심 공식입니다. 감성 점수 = 긍정 단어 수 빼기 부정 단어 수. 읽어볼게요: '감성 점수는 긍정 단어 수에서 부정 단어 수를 뺀 값입니다.' 양수면 긍정, 0이면 중립, 음수면 부정." → [클릭] "실제 텍스트로 해봅시다. '정말 재미있고 연기가 훌륭했다. 음악도 아름다웠다. 결말이 실망스러웠다.' 긍정 단어를 세어봐요: 재미있고, 훌륭했다, 아름다웠다 — 3개." → [클릭] "부정 단어: 실망스러웠다 — 1개." → [클릭] "감성 점수 = 3 빼기 1 = 2. 양수니까 긍정 텍스트입니다." [질문 포인트] Q: "같은 텍스트인데 감성 사전이 다르면 결과가 달라질 수 있나요?" [학생 계산 시간: 30초] A: "맞아요. 감성 사전 구성이 달라지면 같은 텍스트도 다르게 분류될 수 있습니다. 그래서 좋은 감성 사전을 만드는 것이 중요합니다."
📋 판서
감성 점수 = 긍정 수 − 부정 수 = 3 − 1 = 2 → 긍정

다양한 리뷰 비교

3분
[핵심 설명] "표에서 세 가지 리뷰를 비교합니다. 리뷰 A는 긍정 3, 부정 1 → 점수 +2 → 긍정. 리뷰 B는 긍정 0, 부정 2 → 점수 −2 → 부정. 리뷰 C는 긍정 1, 부정 1 → 점수 0 → 중립." "차트를 보면 감성 점수가 양수, 0, 음수로 나뉘는 게 한눈에 보이죠?" [질문 포인트] Q: "중립 점수가 나온 리뷰 C를 보면 '좋았지만, 실망스러웠다'처럼 긍정과 부정이 상쇄된 경우인데, 이게 정말 '중립'일까요?" [학생 응답 대기: 20초]

벡터 변환 실습

4분
[핵심 설명] "이제 여러분이 직접 해봅니다. 텍스트: '공연이 감동적이었다. 하지만 음향이 불쾌하고 좌석이 불편했다.'" → [클릭] "Step 1: 텍스트를 단어로 쪼갭니다. 공연, 감동적이었다, 음향, 불쾌하고, 좌석, 불편했다." → [클릭] "Step 2: 감성 사전과 대조합니다. 옆 친구와 30초 동안 각 단어를 분류해보세요. [학생 계산 시간: 30초] 확인해봅시다: 감동적이었다는 긍정(1), 불쾌하고와 불편했다는 부정(2), 공연·음향·좌석은 중립(3)." → [클릭] "Step 3: 벡터 = (1, 2, 3), 감성 점수 = 1 − 2 = −1. 음수니까 부정입니다."
📋 판서
벡터 = (1, 2, 3) 감성 점수 = 1 − 2 = −1 → 부정
