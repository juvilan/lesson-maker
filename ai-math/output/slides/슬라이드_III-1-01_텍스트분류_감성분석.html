텍스트 분류의 두 가지 방법

① 감성 분석

텍스트에 담긴 긍정/부정/중립 감정을 분석하여 분류

예: 리뷰가 '좋음'인지 '나쁨'인지 판별

② 유사도 분석

텍스트 간의 유사한 정도를 수치화하여 그룹으로 묶음

예: 비슷한 주제의 글끼리 묶기

이번 차시: 감성 분석의 원리와 계산 방법

감성 분석(Sentiment Analysis)이란?

텍스트에 들어 있는 의견·감정·평가·태도 등 주관적인 감성 정보를 골라내어 텍스트를 긍정·부정·중립으로 분류하는 방법

감성 사전(Sentiment Dictionary)

긍정 또는 부정과 같은 감성을 포함한 단어들을 구분하여 모아 놓은 것

긍정 단어

감동, 따뜻하다, 밀다, 사랑, 웃다, 좋다, 재미있다, 추천하다, 최고, 행복

부정 단어

눈물, 슬프다, 싫어하다, 아쉽다, 아프다, 어설프다, 억지, 울다, 유치하다, 재미없다, 지루하다

텍스트를 벡터로 표현하기

텍스트 자료의 단어를 감성 사전으로 분류하면 세 범주로 구분됨

텍스트 벡터 \(= (\text{긍정 단어 수},\ \text{부정 단어 수},\ \text{중립 단어 수})\)

예시 — 공연 감상평

"슬픈 역사의 한 장면을 감동적인 이야기로 구성한 최고의 공연이었다."

긍정
감동, 최고
→ 2
부정
슬프다
→ 1
중립
역사, 한, 장면, 이야기, 구성하다, 공연
→ 6
벡터 표현: \((2,\ 1,\ 6)\)

감성 점수로 분류하기

\((\text{감성 점수}) = (\text{긍정 단어 수}) - (\text{부정 단어 수})\)

긍정

감성 점수 > 0

중립

감성 점수 = 0

부정

감성 점수 < 0

앞의 감상평 예시:

벡터 \((2, 1, 6)\) → 감성 점수 \(= 2 - 1 = 1 > 0\)

∴ 긍정 텍스트로 분류

활동 — 공연 감상평 감성 분류

아래 감성 사전을 이용하여 각 텍스트의 벡터, 감성 점수, 분류를 구하시오.

기호텍스트벡터감성 점수분류
P 배우 구성은 좋았으나, 연기가 어설퍼 아쉬웠다. (1, 2, 3) 1−2 = −1 부정
Q 다소 유치하고 억지 감동을 유발시킨다. (1, 2, 2) 1−2 = −1 부정
R 가슴이 너무 아프지만 따뜻하게 느껴진다. (1, 1, 3) 1−1 = 0 중립
S 스토리 전개가 어설프고 지루했던 공연 (0, 2, 3) 0−2 = −2 부정
T 세상이 사랑과 행복으로 가득 차 있다고 믿게 되었다. (3, 0, 5) 3−0 = 3 긍정

확인 문제

문제. 다음 감성 사전과 텍스트를 이용하여 감성 점수를 구하고 분류하시오.

긍정 단어

좋다, 재미있다, 감동, 추천, 행복, 따뜻하다

부정 단어

슬프다, 아쉽다, 지루하다, 싫다, 실망

텍스트: "감동적이고 따뜻한 이야기지만 결말이 너무 아쉽고 지루하여 실망했다."

긍정: 감동, 따뜻한 → 2개   부정: 아쉽, 지루하여, 실망 → 3개   중립: 나머지 → 다수

벡터 \(= (2, 3, \ldots)\),  감성 점수 \(= 2 - 3 = -1 < 0\)

∴ 부정 텍스트로 분류

핵심 정리

감성 분석: 텍스트의 긍정/부정/중립 감성 정보를 수치화하여 분류하는 방법

감성 사전: 긍정/부정 단어를 모아 놓은 사전; 중립 단어는 포함되지 않음

벡터 \(= (\text{긍정 수},\ \text{부정 수},\ \text{중립 수})\)
\((\text{감성 점수}) = (\text{긍정 수}) - (\text{부정 수})\)
점수 > 0
→ 긍정
점수 = 0
→ 중립
점수 < 0
→ 부정
