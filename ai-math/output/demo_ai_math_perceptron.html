퍼셉트론 구조

가중합
\[ z = \sum_{i=1}^{n} w_i x_i + b \]
활성화 함수 (계단 함수)
\[ y = \begin{cases} 1 & z \geq 0 \\ 0 & z < 0 \end{cases} \]
핵심 파라미터

w (가중치): 각 입력의 중요도
b (편향): 기준선 이동
f(z): 활성화 함수 (0/1 결정)

"퍼셉트론 구조입니다. 왼쪽에 입력, 가운데 합산, 오른쪽 출력. 가중치는 각 입력이 얼마나 중요한지를 나타내요. 편향은 기준선을 조정하는 역할을 합니다."

Step 3 — 활성화 함수 적용
\[ z = 0.3 \geq 0 \implies y = 1 \]

활성화 함수 — 왜 시그모이드를 쓸까?

계단 함수 (퍼셉트론)
미분 불가 → 학습 불가
시그모이드 σ(z)
\[ \sigma(z) = \frac{1}{1+e^{-z}} \] 미분 가능, 출력 0~1 → 학습 가능
ReLU (현대 신경망 주류)
\[ \text{ReLU}(z) = \max(0, z) \] 계산 빠름, 기울기 소실 적음 → 학습 효율↑
2.0
"왜 계단 함수 대신 시그모이드를 쓰냐면 — 학습을 위해서입니다. 학습은 미분이 필요한데 계단 함수는 미분이 안 돼요. 슬라이더로 z값을 바꿔보면 각 함수의 출력이 어떻게 다른지 볼 수 있어요."

순전파 계산 — 숫자로 직접 (XOR: x₁=0, x₂=1)

2-2-1 구조 | 시그모이드 활성화 | 아래 가중치 사용

Step 1 — 입력 설정
x₁ = 0, x₂ = 1
Step 2 — 은닉층 h₁ 계산
z₁ = 1×0 + 1×1 + (−0.5) = 0.5
h₁ = σ(0.5) ≈ 0.622
Step 3 — 은닉층 h₂ 계산
z₂ = 1×0 + 1×1 + (−1.5) = −0.5
h₂ = σ(−0.5) ≈ 0.378
Step 4 — 출력층 y 계산
z₃ = 1×0.622 + (−2)×0.378 + (−0.5)
= 0.622 − 0.756 − 0.5 = −0.634
y = σ(−0.634) ≈ 0.347 → 반올림 → 0 ✗ (XOR(0,1)=1이 맞는데...)

손실함수 — 얼마나 틀렸는지 측정

평균 제곱 오차 (MSE)
\[ \text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 \]
숫자 대입 예시
실제: y = 1  |  예측: ŷ = 0.347
오차: 1 − 0.347 = 0.653
손실 = 0.653² = 0.426
학습의 목표
손실을 최소화하는 가중치 w 찾기
→ 경사하강법 (다음 시간)

가중치 w가 최적값(w=1)으로 수렴할수록 손실이 0에 가까워짐

"손실함수는 '우리가 얼마나 틀렸는지'를 숫자로 나타냅니다. 실제 1, 예측 0.347 → 오차 0.653 → 제곱하면 0.426. 이 값을 줄이는 방향으로 가중치를 조금씩 바꾸는 것이 학습입니다."

확인 문제

Q1. 퍼셉트론에서 w₁=1, w₂=−1, b=0.5일 때,
입력 (x₁=1, x₂=1)에 대한 출력 y를 계산하시오.

풀이:

z = 1×1 + (−1)×1 + 0.5 = 1 − 1 + 0.5 = 0.5
0.5 ≥ 0 이므로 y = 1

Q2. 단층 퍼셉트론으로 XOR 게이트를 구현할 수 없는 이유는?

XOR의 데이터 점들이 선형 분리 불가능한 배치이기 때문.
단층 퍼셉트론은 직선(초평면) 하나로만 분리할 수 있어 XOR를 표현할 수 없다.
