② 함수 Function

최솟값은 미분으로: $f'(x)=0$ 인 곳을 찾음.

예) $f(x)=x^2-4x+5$ → $x=2$ 에서 최소.

Ⅱ-1. 텍스트 자료 — 글을 수(벡터)로

원-핫 벡터 One-hot

단어 사전에서 해당 단어 자리만 1, 나머지는 0.

사전 {영화, 긴장감, 감동} → "긴장감" = (0, 1, 0)

BoW Bag of Words

사전 각 단어의 등장 빈도로 만든 벡터.

단어 순서를 무시

— "나는 학교가 좋다" = "학교가 나는 좋다"

불용어 Stopword

의미가 적어 분석 전에 제거하는 단어.

예) 은/는/이/가, 그리고, ~하다 …

TF · IDF — 핵심어 찾기

$TF=\dfrac{\text{단어 등장 횟수}}{\text{문서 전체 단어 수}}$
$IDF=\log\dfrac{n}{DF}$   ($n$=총 문서 수, $DF$=단어가 나온 문서 수)

TF·IDF = TF × IDF → 값이 클수록 그 문서의 핵심어. 흔한 단어는 IDF가 작아 걸러짐.

Ⅱ-1(보충). 텍스트 자료의 시각화

워드 클라우드

글자 크기 = 단어 빈도. 어떤 단어가 자주 쓰였는지 한눈에.

막대 · 원그래프

막대: 빈도 비교. 원: 상대도수와 중심각($=\text{상대도수}\times360^\circ$)으로 비율 표현.

Ⅱ-2. 이미지 자료 — 사진을 행렬로

픽셀 → 행렬

이미지는 픽셀의 격자 = 행렬. 성분 표기 $a_{ij}$ ($i$행 $j$열).

흑백(이진)그레이스케일컬러
0 또는 10=검정 ~ 255=흰색RGB 3채널

이미지 처리 = 행렬 연산

스칼라배 $kA$: $k<1$ 어둡게, $k>1$ 밝게.

밝게 할 때 255를 넘으면 255로 처리(클리핑).

덧셈·뺄셈 $A\pm B$: 같은 자리 성분끼리 계산 → 합성·차이 검출.
