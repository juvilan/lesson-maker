## 각 애니메이션 상세 패턴

### `log_property` — 로그 성질 단계별 계산

**교수법 포인트**: log(MN) = logM + logN 성질을 숫자로 직접 확인.

**단계 구성**:
```
Step 1: 로그 성질 공식 제시
  log_a(MN) = log_a(M) + log_a(N)
  → "곱의 로그는 로그의 합"

Step 2: 숫자 대입 (예: a=10, M=2, N=50)
  log₁₀(2 × 50) = log₁₀(2) + log₁₀(50)
  log₁₀(100) = log₁₀(2) + log₁₀(50)

Step 3: 결과 확인
  2 = 0.301 + 1.699
  2 = 2  ✓
  (log₁₀2 ≈ 0.3010, log₁₀50 ≈ 1.699)
```

**계산 추적 표 구조**:
```
| 단계 | 식 | 값 |
|------|----|----|
| 원래 식 | log(2 × 50) | ? |
| 성질 적용 | log 2 + log 50 | ? |
| 각각 계산 | 0.3010 + 1.699 | ? |
| 결과 | 합산 | 2.000 |
```

**강의 원고 키포인트**:
```
Step 1 narration:
  "로그의 핵심 성질입니다. 곱의 로그는 로그의 합이에요.
  곱셈을 덧셈으로 바꿔준다는 게 로그가 강력한 이유예요."

Step 3 narration:
  "0.301 더하기 1.699가 딱 2가 되죠.
  log100=2이고, log2+log50도 2.
  같은 값입니다. 성질이 성립하는 거예요."
```

### `trig_special_value` — 삼각함수 특수각 계산

**교수법 포인트**: 단위원에서 좌표를 읽는 방법으로 특수각 값을 암기하지 않고 도출.

**단계 구성**:
```
Step 1: 단위원과 각도 제시
  반지름=1인 원 위의 점 P
  각도 θ = {{angle}} (예: 60° = π/3)
  → x축 양의 방향과 이루는 각

Step 2: 좌표 읽기 (직각삼각형 이용)
  특수각 삼각형 (30-60-90 또는 45-45-90)
  60° 기준:
    빗변=1, 밑변=1/2, 높이=√3/2
  → 단위원 위 점 P의 좌표: (cos 60°, sin 60°) = (1/2, √3/2)

Step 3: sin/cos/tan 값 확정
  sin 60° = y좌표 = √3/2 ≈ 0.866
  cos 60° = x좌표 = 1/2 = 0.5
  tan 60° = sin/cos = (√3/2)/(1/2) = √3 ≈ 1.732
  → 표에 채우기
```

**계산 추적 표 구조**:
```
| 각도 | sin | cos | tan |
|------|-----|-----|-----|
| 0° | ? | ? | ? |
| 30° | ? | ? | ? |
| 45° | ? | ? | ? |
| 60° | ? | ? | ? |
| 90° | ? | ? | ? |
```
→ 버튼 클릭으로 한 행씩 채우기

**강의 원고 키포인트**:
```
Step 2 narration:
  "단위원에서 각도 θ의 점 P를 잡으면,
  그 x좌표가 cos θ, y좌표가 sin θ예요.
  외울 필요 없이 단위원 그림 하나만 기억하면 됩니다."

Step 3 narration:
  "tan은 sin 나누기 cos이에요.
  60도일 때 루트3 나누기 2, 나누기 2분의 1이니까
  루트3이 나오네요."
```

### `arithmetic_sequence` — 등차수열 일반항 전개

**교수법 포인트**: 공식을 암기하기 전에 규칙을 직접 발견하는 과정.

**단계 구성**:
```
Step 1: 수열 나열 (규칙 발견)
  a₁, a₁+d, a₁+2d, a₁+3d, ...
  n=1: a₁        → d가 0번 더해짐
  n=2: a₁+d      → d가 1번 더해짐
  n=3: a₁+2d     → d가 2번 더해짐
  n번째: d가 (n-1)번 더해짐

Step 2: 일반항 공식 도출
  a_n = a₁ + (n-1)d
  "n번째 항 = 첫째항 + 공차×(n-1)"

Step 3: 숫자 대입 (예: a₁=2, d=3, 구하는 것 a₁₀)
  a₁₀ = 2 + (10-1)×3
       = 2 + 27
       = 29
```

**계산 추적 표 구조**:
```
| n | 수식 전개 | 계산 | aₙ |
|---|-----------|------|-----|
| 1 | 2 + (1-1)×3 | 2 + 0 | 2 |
| 2 | 2 + (2-1)×3 | 2 + 3 | 5 |
| 3 | 2 + (3-1)×3 | 2 + 6 | 8 |
| n | 2 + (n-1)×3 | ? | ? |
```

**강의 원고 키포인트**:
```
Step 1 narration:
  "n번째 항을 쓰려면 a₁에서 d를 몇 번 더해야 할까요?
  n=1이면 0번, n=2이면 1번, n=3이면 2번.
  n번째이면 (n-1)번이에요."

Step 3 narration:
  "공식에 숫자를 대입하면 됩니다.
  a₁₀이니까 n에 10을 넣고,
  a₁=2, d=3을 대입하면 29가 나옵니다."
```

### `geometric_sequence` — 등비수열 일반항 전개

**교수법 포인트**: 등차수열과 대응시켜 구조를 비교하며 이해.

**단계 구성**:
```
Step 1: 수열 나열 (곱하기 규칙)
  a₁, a₁·r, a₁·r², a₁·r³, ...
  n=1: a₁      → r을 0번 곱함
  n=2: a₁·r    → r을 1번 곱함
  n=3: a₁·r²   → r을 2번 곱함
  n번째: r을 (n-1)번 곱함

Step 2: 일반항 공식 도출
  aₙ = a₁ × r^(n-1)
  "등차: +d×(n-1)"  vs  "등비: ×r^(n-1)"

Step 3: 숫자 대입 (예: a₁=3, r=2, 구하는 것 a₆)
  a₆ = 3 × 2^(6-1)
     = 3 × 2⁵
     = 3 × 32
     = 96
```

**계산 추적 표 구조**:
```
| n | 수식 전개 | 2^(n-1) | aₙ = 3×2^(n-1) |
|---|-----------|---------|----------------|
| 1 | 3×2^0     | 1       | 3              |
| 2 | 3×2^1     | 2       | 6              |
| 3 | 3×2^2     | 4       | 12             |
| 4 | 3×2^3     | 8       | 24             |
| 5 | 3×2^4     | 16      | 48             |
| 6 | 3×2^5     | 32      | 96             |
```

**강의 원고 키포인트**:
```
Step 2 narration:
  "등차수열은 덧셈이고 등비수열은 곱셈이에요.
  구조가 완전히 대응됩니다.
  등차는 +d×(n-1), 등비는 ×r^(n-1)."

Step 3 narration:
  "a₆이니까 n=6을 넣으면,
  3 곱하기 2의 5제곱 = 3×32 = 96.
  지수에 (n-1)이 들어간다는 것만 기억하세요."
```

### `series_sum_arithmetic` — 등차수열의 합 계산

**교수법 포인트**: 가우스의 역순 더하기 아이디어로 공식을 유도.

**단계 구성**:
```
Step 1: 합을 두 가지 방향으로 쓰기 (가우스 아이디어)
  S_n = a₁       + (a₁+d)   + ... + aₙ
  S_n = aₙ       + (aₙ-d)   + ... + a₁
  (위 아래 대응항끼리 더하면 모두 a₁+aₙ)

Step 2: 양변 더하기
  2S_n = n×(a₁+aₙ)
  S_n = n/2 × (a₁ + aₙ)

Step 3: aₙ를 a₁, d로 바꾸면
  aₙ = a₁ + (n-1)d 대입
  S_n = n/2 × {2a₁ + (n-1)d}

Step 4: 숫자 대입 (예: a₁=2, d=3, n=10)
  S₁₀ = 10/2 × (2×2 + 9×3)
       = 5 × (4 + 27)
       = 5 × 31
       = 155
  검산: a₁₀ = 2+27 = 29, S₁₀ = 10/2×(2+29) = 155 ✓
```

**계산 추적 표 구조**:
```
| 항 | 정방향 | 역방향 | 합 |
|----|--------|--------|-----|
| 1번째 | a₁=2 | aₙ=29 | 31 |
| 2번째 | a₂=5 | a₉=26 | 31 |
| ... | ... | ... | 31 |
| n번째 | aₙ=29 | a₁=2  | 31 |
| 합계 | 2S₁₀ = 10×31 | = 310 | S₁₀=155 |
```

**강의 원고 키포인트**:
```
Step 1 narration:
  "가우스가 초등학생 때 1부터 100까지 더하는 방법을 발견한 거예요.
  앞에서 더하는 것과 뒤에서 더하는 것을 써놓고,
  대응되는 항끼리 더하면 모두 같은 값이 나옵니다."

Step 4 narration:
  "공식에 수를 대입할 때,
  S_n = n/2 × (a₁ + aₙ) 형태로 먼저 aₙ를 구한 다음 쓰는 게 편해요.
  a₁₀=29를 먼저 구하고, 10/2×(2+29)=155."
```

### `series_sum_geometric` — 등비수열의 합 계산

**교수법 포인트**: S_n - r·S_n 트릭으로 공식 유도.

**단계 구성**:
```
Step 1: S_n와 r·S_n 나란히 쓰기
  S_n   = a₁ + a₁r + a₁r² + ... + a₁r^(n-1)
  r·S_n =       a₁r + a₁r² + ... + a₁r^(n-1) + a₁rⁿ

Step 2: 빼기 → 대부분 소거
  S_n - r·S_n = a₁ - a₁rⁿ
  S_n(1 - r) = a₁(1 - rⁿ)

Step 3: 공식 확정
  r ≠ 1: S_n = a₁(1 - rⁿ) / (1 - r) = a₁(rⁿ - 1) / (r - 1)
  r = 1: S_n = n·a₁

Step 4: 숫자 대입 (예: a₁=3, r=2, n=6)
  S₆ = 3×(2⁶ - 1) / (2 - 1)
     = 3×(64 - 1) / 1
     = 3×63
     = 189
  검산: 3+6+12+24+48+96 = 189 ✓
```

**계산 추적 표 구조**:
```
| 단계 | 식 | 값 |
|------|----|----|
| 2^n 계산 | 2^6 | 64 |
| r^n - 1 | 64 - 1 | 63 |
| r - 1 | 2 - 1 | 1 |
| a₁ × 몫 | 3 × 63 / 1 | 189 |
```

**강의 원고 키포인트**:
```
Step 2 narration:
  "S_n에서 r 곱한 것을 빼면,
  중간 항들이 죄다 소거되고 앞 끝이랑 뒤 끝만 남아요.
  이게 등비수열 합 공식 유도의 핵심입니다."

Step 4 narration:
  "공식에 대입할 때 r^n 계산을 먼저 하세요.
  2^6 = 64, 여기서 1을 빼면 63,
  분모 r-1=1이니까 63×3=189."
```

### `limit_compute` — 극한 계산 (인수분해→약분→대입)

**교수법 포인트**: 직접 대입하면 0/0이 되는 불정형 극한을 인수분해로 해결.

**단계 구성**:
```
Step 1: 직접 대입 시도 → 불정형 확인
  예: lim_{x→2} (x²-4)/(x-2)
  x=2 대입: (4-4)/(2-2) = 0/0  ← 불정형! 직접 계산 불가

Step 2: 분자 인수분해
  x² - 4 = (x+2)(x-2)
  → lim_{x→2} (x+2)(x-2)/(x-2)

Step 3: 약분 (x≠2 조건에서)
  = lim_{x→2} (x+2)    ← x-2가 약분됨
  x→2이지 x=2가 아님 → 약분 가능

Step 4: 대입하여 극한값 계산
  = 2 + 2 = 4
  ∴ lim_{x→2} (x²-4)/(x-2) = 4
```

**계산 추적 표 구조**:
```
| 단계 | 식 변환 | 결과 |
|------|---------|------|
| 직접 대입 | (4-4)/(2-2) | 0/0 (불정형) |
| 분자 인수분해 | (x+2)(x-2)/(x-2) | — |
| 약분 (x≠2) | x+2 | — |
| x→2 대입 | 2+2 | 4 |
```

**강의 원고 키포인트**:
```
Step 1 narration:
  "x=2를 직접 대입하면 분자도 0, 분모도 0.
  0 나누기 0은 정의가 안 돼요.
  이 상황을 '0/0 불정형'이라고 합니다.
  극한은 x→2로 가까이 가는 것이지 x=2는 아니에요."

Step 3 narration:
  "x→2이지 x=2가 아니니까, (x-2)≠0.
  분모에 있는 (x-2)를 약분할 수 있어요.
  약분하고 나면 깔끔한 식이 남습니다."
```

### `derivative_definition` — 미분계수 정의 전개

**교수법 포인트**: 평균변화율 → 순간변화율의 극한이라는 개념 흐름.

**단계 구성**:
```
Step 1: 평균변화율 상기
  [a, a+h] 구간의 평균변화율
  = (f(a+h) - f(a)) / (a+h - a)
  = (f(a+h) - f(a)) / h
  → 직선(할선)의 기울기

Step 2: h → 0으로 보내기 (극한)
  f'(a) = lim_{h→0} (f(a+h) - f(a)) / h
  h가 작아질수록 할선이 접선에 가까워짐

Step 3: 숫자 대입 (예: f(x)=x², a=3)
  f'(3) = lim_{h→0} ((3+h)² - 9) / h
        = lim_{h→0} (9 + 6h + h² - 9) / h
        = lim_{h→0} (6h + h²) / h

Step 4: 약분 후 극한 계산
  = lim_{h→0} (6 + h)
  = 6
  ∴ f'(3) = 6  (x=3에서의 접선 기울기)
```

**계산 추적 표 구조**:
```
| 단계 | 식 | 변환 |
|------|----|----- |
| f(3+h) 전개 | (3+h)² | 9 + 6h + h² |
| f(3+h) - f(3) | 9+6h+h² - 9 | 6h + h² |
| h로 나누기 | (6h+h²)/h | 6 + h |
| h→0 대입 | 6 + 0 | 6 |
```

**강의 원고 키포인트**:
```
Step 2 narration:
  "h를 점점 줄이면 구간이 좁아지고,
  할선이 접선에 가까워져요.
  h→0 극한이 바로 그 접선의 기울기, 미분계수입니다."

Step 4 narration:
  "h로 약분하고 나니까 h→0을 대입할 수 있게 됐죠.
  f'(3)=6이에요. x=3에서 이 함수의 순간 변화율이 6이라는 뜻입니다."
```

### `power_rule_derivative` — 거듭제곱 미분법 숫자 대입

**교수법 포인트**: 정의를 매번 계산하지 않고 쓸 수 있는 공식을 소개.

**단계 구성**:
```
Step 1: 거듭제곱 미분 공식 제시
  d/dx [xⁿ] = n·xⁿ⁻¹
  → "지수를 앞으로 꺼내고, 지수에서 1을 뺀다"

Step 2: 구체적 예시로 적용 (예: f(x) = 4x³)
  f'(x) = 4 × d/dx[x³]
        = 4 × 3·x^(3-1)
        = 12x²
  (상수 4는 그대로 앞에 남는다)

Step 3: 합성 예시 (예: f(x) = 3x⁴ - 2x² + 5)
  f'(x) = 3×4x³ - 2×2x + 0
        = 12x³ - 4x
  → 항마다 공식 적용, 상수항 미분=0
```

**계산 추적 표 구조**:
```
| 항 | 원래 식 | 지수 앞으로 | 지수-1 | 미분 결과 |
|----|---------|------------|--------|-----------|
| 첫째 | 3x⁴ | 3×4×x⁴ | → x³ | 12x³ |
| 둘째 | -2x² | -2×2×x² | → x¹ | -4x |
| 셋째 | 5 | 상수 | — | 0 |
| 합계 | 3x⁴-2x²+5 | — | — | 12x³-4x |
```

**강의 원고 키포인트**:
```
Step 1 narration:
  "거듭제곱 미분법이에요. 지수를 앞으로 꺼내고, 지수에서 1을 빼면 됩니다.
  x⁵이면 5x⁴, x⁷이면 7x⁶.
  정의로 매번 계산하지 않아도 되는 강력한 공식입니다."

Step 3 narration:

  상수항은 미분하면 0이에요. 상수는 변화가 없으니까요."
```

### `binomial_compute` — 이항분포 P(X=k) 계산

**교수법 포인트**: nCk × p^k × (1-p)^(n-k)의 세 부분이 각각 무슨 의미인지 분리 설명.

**단계 구성**:
```
Step 1: 공식 제시 + 구조 설명
  P(X=k) = nCk × p^k × (1-p)^(n-k)
  ↑ 조합  ↑ 성공 k번  ↑ 실패 (n-k)번
  "성공이 k번 일어나는 경우의 수 × 그 확률"

Step 2: 조합 nCk 계산 (예: n=5, k=2)
  5C2 = 5! / (2! × 3!)
       = (5×4) / (2×1)
       = 10

Step 3: 확률 부분 계산 (예: p=0.4)
  p^k = 0.4² = 0.16
  (1-p)^(n-k) = 0.6³ = 0.216

Step 4: 세 부분 곱하기
  P(X=2) = 10 × 0.16 × 0.216
          = 10 × 0.03456
          = 0.3456
  → P(X=2) ≈ 0.346 (34.6%)
```

**계산 추적 표 구조**:
```
| 구성 요소 | 의미 | 계산 | 값 |
|----------|------|------|-----|
| nCk = 5C2 | 성공 위치 경우의 수 | 5×4/2×1 | 10 |
| p^k = 0.4² | 성공 k번 확률 | 0.4×0.4 | 0.16 |
| (1-p)^(n-k) = 0.6³ | 실패 (n-k)번 확률 | 0.6×0.6×0.6 | 0.216 |
| P(X=2) 최종 | 10 × 0.16 × 0.216 | — | 0.3456 |
```

**강의 원고 키포인트**:
```
Step 1 narration:
  "이항분포 공식을 세 덩어리로 나눠서 보세요.
  nCk는 성공이 k번 일어나는 순서 배열의 수,
  p^k는 성공 k번의 확률,
  (1-p)^(n-k)는 실패 (n-k)번의 확률.
  이 세 개를 곱하는 거예요."

Step 4 narration:
  "10 곱하기 0.16 곱하기 0.216이에요.
  0.3456, 약 34.6%.
  5번 시행 중 정확히 2번 성공할 확률이 35% 정도 된다는 뜻입니다."
```

### `normal_standardize` — 정규분포 표준화 계산

**교수법 포인트**: 모든 정규분포를 N(0,1)로 바꾸는 이유와 Z표 활용법.

**단계 구성**:
```
Step 1: 표준화 공식 제시
  Z = (X - μ) / σ
  → X의 값이 μ에서 σ 단위로 몇 칸 떨어져 있는지
  → 표준정규분포 N(0,1)로 변환

Step 2: 숫자 대입 (예: μ=70, σ=10, X=85)
  Z = (85 - 70) / 10
    = 15 / 10
    = 1.5
  → X=85는 평균보다 1.5 표준편차 위

Step 3: Z표에서 확률 읽기
  P(Z ≤ 1.5) = 0.9332
  ∴ P(X ≤ 85) = 0.9332
  → 점수가 85점 이하인 학생이 약 93.3%
```

**계산 추적 표 구조**:
```
| 단계 | 계산식 | 값 | 의미 |
|------|--------|-----|------|
| X - μ | 85 - 70 | 15 | 평균과의 차 |
| ÷ σ | 15 ÷ 10 | 1.5 | 표준편차 단위 |
| Z값 확정 | Z = 1.5 | 1.5 | 표준정규분포 변환 |
| Z표 참조 | P(Z≤1.5) | 0.9332 | 누적확률 |
```

**강의 원고 키포인트**:
```
Step 1 narration:
  "정규분포는 μ와 σ에 따라 모양이 달라서,
  μ=70짜리 표랑 μ=100짜리 표를 따로 만들면 표가 무한히 많아져요.
  그래서 모두 N(0,1)로 바꾸는 겁니다.
  Z = (X-μ)/σ, 이게 표준화예요."

Step 3 narration:
  "Z=1.5라는 건 평균에서 표준편차 1.5개만큼 위라는 뜻이에요.
  표준정규분포표에서 1.5를 찾으면 0.9332,
  즉 93.32%의 학생이 이 점수 이하예요."
```

```javascript
function showStep(stepId, delay = 0) {
```

```javascript
  gsap.to(el, {

    onComplete: () => {
      el.textContent = val;
      el.style.color = color;
      el.classList.add('filled');
      gsap.to(el, { backgroundColor: 'transparent', duration: 0.5 });

  });
```

### 단계 진행 컨트롤러
```javascript
function makeStepController(steps) {
  // steps: [{ show: ['id1', 'id2'], delay: 0.3 }, ...]
  let current = 0;
  return {
    next() {
      if (current >= steps.length) return;
      const s = steps[current];
      s.show.forEach((id, i) => showStep(id, (s.delay || 0) + i * 0.15));
      current++;
    },
    reset() {
      current = 0;
      steps.forEach(s => s.show.forEach(id => {
        const el = document.getElementById(id);
        if (el) gsap.set(el, { opacity: 0 });
      }));
    }
  };
}
```
