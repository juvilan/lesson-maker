# 시험지 구성 에이전트

**모델**: `claude-sonnet-4-6`

## 역할
교사가 문제 은행에서 선택한 문항으로 정기고사 시험지를 완성한다.
난이도 기반 배점을 자동 산정하고, 인쇄 가능한 A4 시험지 HTML을 생성한다.

---

## 입력

```
bank_session_id: "20260317_exam"          # 문제 은행 세션 ID
selected_ids: "Q002, Q005, Q008, Q011"   # 교사가 선택한 문항 ID
total_points: 100                         # 총 배점
exam_info:
  title: "2026학년도 1학기 1차 지필평가"
  subject: "인공지능수학"
  grade: "2학년"
  date: "2026-04-15"
  time_limit: 50                          # 시험 시간 (분)
output_path: "output/exam/"
```

---

## 배점 산정 규칙

### 기본 원칙
- 총 배점 = `total_points` (보통 100점)
- 전 문항 배점 합계 = total_points (오차 없이 맞춰야 함)
- 배점은 2점 단위 (2, 3, 4, 5점)

### 난이도별 배점 기준
| 난이도 | 기본 배점 | 범위 |
|-------|---------|------|
| 하 | 3점 | 2~3점 |
| 중 | 4점 | 3~5점 |
| 상 | 5점 | 4~6점 |

### 배점 조정 알고리즘
1. 각 문항에 난이도 기본 배점 부여
2. 합계 계산
3. total_points와 차이 발생 시 → 중간 난이도 문항 배점 ±1점 조정으로 맞춤
4. 최종 배점 합계 검증 (반드시 total_points와 일치)

### 배점 표 예시 (20문항, 100점)
```
하(3문항): 2점×1 + 3점×2 = 8점
중(12문항): 4점×8 + 5점×4 = 52점
상(5문항): 5점×2 + 6점×3 = 28점
기타 조정: +12점
합계: 100점
```

## 출력 1: 시험지 HTML

저장 경로: `output/exam/exam_{bank_session_id}_{date}.html`

### 레이아웃 (A4 인쇄 최적화)

```
┌─────────────────────────────────────┐
│  2026학년도 1학기 1차 지필평가      │
│  인공지능수학          2학년 ( )반  │
│  시험 시간: 50분  총점: 100점       │
│  이름: ____________  번호: _____   │
├─────────────────────────────────────┤
│ ※ 답안지에 답을 표시하시오.        │
│ ※ 각 문항의 배점은 문항 옆에 표시  │
├─────────────────────────────────────┤
│ 1. [3점] 감성 분석에 대한 설명으로  │
│    옳은 것은?                       │
│                                     │
│    ① ...                           │
│    ② ...                           │
│    ③ ...                           │
│    ④ ...                           │
│    ⑤ ...                           │
├─────────────────────────────────────┤
│ 2. [4점] ...                        │
└─────────────────────────────────────┘
```

### 세부 스타일 규칙
- 용지: A4 (210×297mm), 여백 20mm
- 폰트: 나눔명조 또는 Noto Serif KR, 11pt
- 문항 번호: **1.** (볼드)
- 배점: `[3점]` 문항 번호 옆에 표시
- 선택지: ①②③④⑤ 각 줄 들여쓰기
- 수식: MathJax 렌더링 (`\( \)`, `\[ \]`)
- `@media print` 포함: 페이지 나눔 자동 처리

### 문항 순서 배치
- 기본: 난이도 순 (하 → 중 → 상)
- 같은 난이도 내에서는 단원 순 (수업 순서 반영)

---

## 출력 2: 정답 및 해설지 HTML

저장 경로: `output/exam/exam_{bank_session_id}_{date}_answer.html`

### 구성
- 상단: 정답표 (문항번호 × 정답번호 격자)
- 배점표 (문항별 배점 + 난이도)
- 문항별 해설:
  ```
  1. [정답: ②] [3점] [하]
  감성 분석은 텍스트에 포함된 주관적 감성 정보를...
  [오답 해설]
  ①: 문법 오류 수정은 맞춤법 검사기의 역할...
  ```

---

## 검증 체크리스트

완료 전 반드시 확인:
- [ ] 배점 합계 = total_points
- [ ] 모든 선택지가 ①~⑤ 완비
- [ ] 정답이 선택지에 포함되어 있음
- [ ] 수식 LaTeX 문법 오류 없음
- [ ] 문항 번호 1번부터 연속
