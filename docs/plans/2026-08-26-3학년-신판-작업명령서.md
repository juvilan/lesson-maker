## 3. 집필 규약 (2학년 17개 + 3학년 9개에서 굳은 것)

### 3.1 뼈대

```html
<body class="lm-narrow" data-subject="ai_math">
```

- `data-subject`는 **`ai_math`** — 밑줄입니다. 하이픈은 아무 규칙에도 안 걸립니다.
- `lm-narrow`는 본문 폭 제한(1280px). **모든 신판이 켜져 있습니다.**
- CSS 경로는 `../../../_shared/templates/` — 산출물이 3단계 아래이기 때문입니다.
- `<head>`의 MathJax 설정, 맨 아래 `Reveal.initialize` + `safeTypeset` 블록은
  **본보기 덱에서 그대로 복사**하세요. 손으로 다시 쓰지 마세요.

### 3.2 세로 상한 994px — 절대 규칙

1920×1080, `margin: 0.04` 이므로 실제 쓸 수 있는 높이가 994px입니다.

> **넘치면 폰트를 줄이지 말고 슬라이드를 쪼갤 것.** 폰트 하한 0.7em.

여유가 필요하면 순서대로:
1. `<section class="tight">` — 상하 여백 72 → 48px (48px 확보)
2. `<section class="wide-measure">` — 그 장만 본문 폭 1440px (글이 한 줄 줄어듦)
3. 그래도 안 되면 **장을 쪼갠다**

### 3.3 표기 — 실물이면 정체, 수학이면 조판

| 정체(그대로 둘 것) | 조판할 것 |
|---|---|
| 댓글 A, 학생 B, 상품 A, 감상평 P (실물 지칭) | 점·벡터·집합 `\(P\)` `\(Q\)` |
| 약어 이름 (수식 안에서는 `\mathrm{TF}`) | 좌표축 `\(x\)` `\(y\)`, 원점 `\(O\)` |
| 단위 `m`, `m/s`, `°C` | `\(45^\circ\)`, `\(P(5,\ 1)\)`, 유니코드 첨자 금지 → `\(T_1\)` |

**유니코드 첨자(`T₁`, `P₁`)를 쓰지 마세요.** 반드시 `\(T_1\)`.
한 화면 안에서 같은 기호가 두 서체로 갈리는 것이 교사 지적의 핵심이었습니다.

### 3.4 ⚠️ 2015 표기와 2022 표기를 섞지 말 것

| | 2015 (ai-math, 3학년) | 2022 (ai-math-2022, 2학년) |
|---|---|---|
| 임곗값 | **θ** | h |
| 활성화함수 | **σ(x)** | — |
| 유클리드 유사도 | **L(P, Q)** | D(P, Q) |

**이번 작업은 전부 2015입니다.** 2022 덱을 참고하다가 표기가 딸려 오기 쉽습니다.
다 쓰고 나서 `grep -c 'h\b'` 같은 걸로는 못 잡으니, **쓸 때 조심**하는 수밖에 없습니다.

### 3.5 SVG 도식 안의 수식

**SVG `<text>` 안에서는 MathJax가 조판되지 않습니다.** `mjx-container`가 삽입은
되는데 그려지지 않습니다. 반드시:

```html
<foreignObject class="m-pt a-start" x="446" y="262" width="150" height="40">
  <div xmlns="http://www.w3.org/1999/xhtml">\(P(5,\ 1)\)</div>
</foreignObject>
```

**`foreignObject`에는 `text-anchor`가 없습니다.** `<text text-anchor="end" x="70">`을
같은 x로 옮기면 라벨이 상자 폭만큼 통째로 밀립니다 — 오류도 경고도 안 납니다.

- `end` → `x - width`, `middle` → `x - width/2`, 정렬은 flex로
- `y`는 baseline이 아니라 **상자 위쪽**. 시각 중심 ≈ `baseline − 0.35×글자크기`
- 예시는 `슬라이드_2-3-3차시_유클리드와코사인유사도.html`의 `.m-ax/.m-pt/.a-end`

축 눈금 숫자나 국문 라벨(`풍속 (m/s)`)은 `<text>` 평문이 맞습니다. 변수만 조판합니다.

### 3.6 확인 활동

답 자리를 **미리 확보**합니다. `display:none`이 아니라:

```css
.qlist li .ans { visibility: hidden; border-top: 1px solid transparent; }
.qlist li.revealed .ans { visibility: visible; border-top-color: var(--lm-rule); }
```

`display:none`이면 답을 열 때 아래가 밀리고, 닫힌 상태에서는 화면 아래가 텅 빕니다.
투명 테두리는 빈 칸에 가로줄만 뜨는 새 결함을 막기 위한 것입니다.

### 3.7 발표자 노트는 **장마다 하나씩**

`aside class="notes"` 개수 = `<section>` 개수. 구판에 없던 것이라 새로 써야 합니다.
내용은 **무엇을 강조할지, 학생이 어디서 틀리는지, 어떤 질문을 던질지**.
"이 장은 …를 설명한다" 같은 요약은 쓰지 마세요 — 화면에 이미 있습니다.

### 3.8 차시 쪼개기

**방법이 바뀌는 자리에서 끊습니다.** 예(Ⅲ-2): 86|87은 직접 세기 → 곱하기,
89|90은 확률 → 경향, 92|93은 직선 구하기 → 직선 쓰기.
쪽수를 균등 분배하지 마세요.

한 차시는 **10~16장**. 각 차시가 다음 차시의 질문을 남기도록 잇습니다.

## 5. 함정 모음 (전부 실제로 밟은 것들)

### 측정

| 함정 | 증상 | 대처 |
|---|---|---|
| **CSS 전이 대기** | `.visible` 붙인 직후 재면 전이 전 값. 1-2-4를 977로 오독(실제 1022) | 클래스 붙이고 **2초 대기**, 500ms 간격 3회 연속 일치 확인 |
| **MathJax 조판 대기** | 조판 전 원시 TeX가 더 길어 높이가 부풀려짐 | `await MathJax.startup.promise` → `typesetPromise()` 후 측정 |
| **브라우저 캐시** | `python -m http.server`는 `Cache-Control`을 안 보냄. CSS를 고쳐도 반영 안 됨 | `fetch(url,{cache:'reload'})` + 덱 URL에 `?cb=` |
| **CSS 특이도** | 주입 스타일이 커밋된 규칙에 져서 조용히 무시됨 | 주입할 때 같은 접두사(`.lm-narrow …`) 사용 |
| **교차 출처** | 다른 포트 iframe은 `contentDocument`가 null | 같은 출처 탭에서 측정 |

### 환경 (윈도우)

| 함정 | 대처 |
|---|---|
| Git Bash `python3` 실패(0x80070002) | **파이썬은 설치돼 있습니다.** `powershell.exe -NoProfile -Command "python ..."` |
| Git Bash 히어독(heredoc)이 **백슬래시를 먹음** (`\\\(` → `\\(`) | 정규식·TeX가 든 스크립트는 **Write 도구로 파일 작성** 후 실행 |
| Git Bash 네트워크 차단 | PowerShell `Invoke-WebRequest` |
| 파이썬 urllib SSL 검증 실패 | 검증을 끄지 말고 PowerShell에 위임 |
| `grep -P` 가 에러만 내고 조용히 끝남 | ANSI-C 인용(`$'...'`) 사용 |

### 협업

  실제로 한 번 남의 파일을 쓸어 담았습니다. **항상 경로를 명시**하세요.
