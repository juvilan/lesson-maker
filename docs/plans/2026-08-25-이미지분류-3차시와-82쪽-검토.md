## 1. 배경

유사도 덱(Ⅲ-1-03) 수업 후, 이어지는 교과서 73~82쪽을 3차시로 만들었다.
사용자가 함께 던진 질문 — **"82쪽에서 가중치와 퍼셉트론으로 유사도 비교를 마무리 짓는데,
이렇게까지 설명할 필요가 있었나 싶다"** — 에 대한 검토가 6차시 후반부 설계의 뼈대가 되었다.

## 2. 교과서 82쪽 검토 결과

교과서는 78쪽에서 두 방법을 이렇게 가른다.

> "**유사한 정도**에 따라 분류하는 경우에는 해밍 거리를,
> **가능성의 정도**에 따라 분류하는 경우에는 퍼셉트론을 이용한다."

퍼셉트론이 실제로 계산하는 값은 (활성화함수가 \(\sigma(x)=x\)이므로 그냥 내적)

\[ \text{P의 출력} = \frac{1}{19}\langle C, A\rangle = \frac{|C \cap A|}{|A|} \]

즉 **"A에서 켜진 픽셀 중 몇 %가 C에도 켜져 있나"**이다. 교과서 값은 전부 재현된다
(합 19·17, 해밍 5·3, 출력 0.74·0.82, 문제 3의 17/19와 1).

### 문제점 세 가지

| | 내용 |
|---|---|
| ① 잘못 켜진 칸을 벌하지 않는다 | 전광판을 **전부 켜서** 넣으면 0일 가능성 1.00, 8일 가능성 1.00. 해밍은 16·18로 제대로 "안 닮았다"고 한다 |
| ② 교과서 자신의 문제 3이 그 구멍을 밟는다 | 이미지 D에 대해 \(P'\) 출력이 **정확히 1.00**("완벽한 8")인데 해밍으로는 **4칸이 다르다** |
| ③ 가중치를 학습하지 않는다 | 73쪽은 "학습이란 가중치를 찾아 가는 과정"이라 해 놓고 여기선 \(W=\frac{1}{19}A\)로 손으로 정한다. 활성화함수도 계단함수 → 항등함수로 바뀐다 |

### 이 예제에서 더 결정적인 것

\(\langle C,A\rangle = \langle C,B\rangle = \mathbf{14}\) — **분자가 같다.**
C에서 켜진 14칸이 A에도 B에도 통째로 들어 있기 때문이다.
즉 답을 가른 것은 **분모뿐**이고, 퍼셉트론은 모양을 비교한 것이 아니라
**어느 정답 이미지가 덜 켜져 있는가**만 본 셈이다.

### 결론 — 절을 없앨 필요는 없다

- 퍼셉트론(Ⅲ-1-02)이 이미지 분류에서 값을 하는 **유일한 자리**다.
- **"분류 = 후보마다 점수를 매겨 큰 쪽을 고른다"**는 해밍 거리가 못 가르치는 진짜 아이디어이고,
  실제 분류기가 그렇게 동작한다.
- 교과서 78쪽 주안점도 "실제로 이미지를 분류하는 알고리즘을 정확하게 이해하는 것은 쉽지 않으므로
  여기서는 **단계를 간단히 하여 제시**하였다"고 밝히고 있다.

다만 교과서는 두 방법이 **둘 다 8로 일치**해서 차이가 드러나지 않는다.
그래서 유사도 덱의 유클리드 반례와 **같은 구조**로 설계했다 —
교과서 문제 3을 반례로 써서 "퍼셉트론은 1.00이라는데 해밍은 4칸 다르다"로 끈다.

**프레이밍**: "퍼셉트론이 틀렸다"가 아니라 **"재는 것이 다르다"**.
전구가 나가 일부가 빠진 이미지에는 오히려 퍼셉트론이 어울리고,
낙서가 더해진 이미지에는 해밍이 낫다.
