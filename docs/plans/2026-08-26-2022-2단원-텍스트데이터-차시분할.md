## 4. 차시별 설계 메모

### 2-1-1 정형과 비정형, 그리고 벡터 (50~52쪽)

핵심 한 줄: **정해진 칸에 든 말은 수로 바꾸면 끝난다.**

- 생각 열기: 급식 '선호하는 메뉴'(정형) vs '의견'(비정형) — 이 대비로 연다
- 정형의 장단: 처리·검색이 쉽다 / 형식 밖 정보는 못 담는다. 비정형은 그 반대
- 혈액형 0·1·2·3, 성별 3·4 → **수로 바꾸기**
- 벡터 정의: 성분, 차원. \(\vec{X}=(x_1,\ x_2,\ \dots,\ x_n)\)
- **원-핫 벡터** — 남성 (1, 0), 여성 (0, 1). 범주 개수가 곧 차원
- 확인 활동: 문제 1(정형/비정형 구분), 문제 2(성분 찾기), 문제 3(혈액형 원-핫 표 완성)

### 2-1-2 문장을 집합으로 (52~54쪽)

핵심 한 줄: **자유로운 문장은 부수고 걸러서 집합으로 만든다.**

- 교복 댓글 3개(A·B·C) 말뭉치로 전 과정을 관통한다
- 5단계를 순서대로: 문장 → 문장 부호 제외·낱말 분리 → 기본 사전형 → **불용어 제거** → 단어집합
  - A={학교, 교복, 주변, 디자인, 예쁘다}
  - B={디자인, 신축성, 좋다, 교복}, C={소재, 좋다, 교복, 생각}
- **단어 사전** \(U=A\cup B\cup C\) (9개)
- 표(9열 × 3행) → \(\vec{A}=(1,1,1,1,1,0,0,0,0)\) 등 → **임베딩**
- 불용어는 목적에 따라 달라진다 — '학교'·'교복'을 불용어로 넣을 수도 있다(교과서 참고)
- 확인 활동: 문제 4·5(영화 후기 3개), 확인하기 OX 3개

### 2-2-1 빈도수 벡터와 주제어 (55~58쪽)

핵심 한 줄: **있다/없다(0·1) 대신 몇 번인가를 세면 강조점이 보인다.**

- 생각 열기 표어 A·B로 0/1 벡터의 한계를 보인다 — 출현 여부만으로는 빈도가 안 보인다
- **빈도수 벡터** 정의, 단어가방(Bag of Words)
- 음식점 후기 4개(A~D) + 말뭉치 \(\vec{U}=(5,1,2,2,4,2,3,4,1)\) → 주제어 '추천'
- 예제 1(자율주행 기사 3개), 문제 1(윤동주 「산울림」), 문제 2(스포츠 기사 → 축구·야구·농구 연결)

### 2-2-2 TF-IDF (58~62쪽)

핵심 한 줄: **모두가 쓰는 말은 깎고, 여기서만 잦은 말을 올린다.**

- 문제 제기: 말뭉치 주제어가 '추천'인 건 알겠는데 **추천하는 이유**는 안 보인다
- 4단계로 끊어서: TF → DF → IDF\(=\dfrac{n}{DF}\) → TF-IDF\(=TF\times IDF\)
- 후기 A에서 TF는 '추천'(2)이 '위생적'(1)보다 크지만,
  TF-IDF는 '위생적'(4)이 '추천'(2)보다 크다 → **이것이 이 절의 전부**
- 결과 읽기: A 위생적 / B 맛·좋다 / C 저렴 / D 맛 → 추천 이유 네 가지
- 예제 2, 문제 3(미세 먼지 문서 3개)
- (심화·『대수』 이수자) \(IDF=\log\dfrac{n}{DF}\) — 왜 로그를 쓰는지. **선택 자료로 표시**
- 탐구&융합 워드 클라우드는 시간이 되면 마지막 1장

### 2-3-1 감성 사전과 감성 점수 (63~66쪽)

핵심 한 줄: **긍정 단어 수에서 부정 단어 수를 뺀다.**

- 생각 열기: 사과 후기 3개(별점 ★5/★2/★1). **B가 어려운 이유**로 연다 —
  별점은 부정인데 후기에는 긍정·부정이 섞여 있다
- 감성 사전(긍정 19개·부정 18개 표), 사전에 없으면 중립
- 감성 벡터 (긍정 수, 부정 수, 중립 수) → A (3,0,2), B (2,2,2), C (1,4,1)
- **감성 점수 = 첫째 − 둘째**, 양수 긍정 / 0 중립 / 음수 부정
- B는 0 → **중립**. 사람이 애매하다고 한 것을 기계는 기준대로 판정한다
- ⚠️ '작다·높다·많다'처럼 상황에 따라 뒤집히는 단어 — 교과서 참고를 꼭 짚는다
- 확인 활동: 문제 1(소비자 D·E)

### 2-3-2 벡터의 덧셈과 전체 감성 (66~68쪽)

핵심 한 줄: **후기 하나가 아니라 전체를 보려면 벡터를 더한다.**

- 벡터의 덧셈 정의(차원이 같을 때만), 세 개 이상도 가능·결합법칙
- \(\vec{A}+\vec{B}+\vec{C}=(6,6,5)\) → 감성 점수 0 → 전체는 **중립**
- 개별로는 긍정 하나·중립 하나·부정 하나였는데 합치면 중립이라는 점을 짚는다
- 확인 활동: 문제 2(벡터 덧셈 계산), 문제 3(5명 전체 감성 분석)
- 감성 분석의 쓸모(기업의 품질 개선·홍보, 개인의 구매 참고)로 닫고 유사도로 넘어간다

### 2-3-3 유클리드 유사도와 코사인 유사도 (68~70쪽)

핵심 한 줄: **거리로 재면 작을수록 닮았고, 각도로 재면 클수록 닮았다.**

- 생각 열기 T1·T2·T3(딸기·바나나 좋아함/싫어함)으로 "사람마다 기준이 다르다" →
  **정량화가 필요하다**는 문제의식
- 유클리드 \(D(P,Q)\) — 두 점 사이의 거리. **0에 가까울수록 유사**
- 코사인 \(C(P,Q)\) — 내적/크기곱. **1에 가까울수록 유사**, \(C=\cos\theta\), \(0\le C\le 1\)
- 부등호 방향이 반대라는 점이 학생들이 가장 많이 틀리는 자리 → 한 장을 할애해 대비
- 예제 1·2, 문제 4~7

### 2-3-4 자카드 유사도와 세 유사도 비교 (71~75쪽)

핵심 한 줄: **잣대가 다르면 답도 갈린다.**

- 자카드 \(J(P,Q)=\dfrac{n(P\cap Q)}{n(P\cup Q)}\) — 벡터가 아니라 **집합**으로 잰다. 1에 가까울수록 유사
- 함께하기(영화 장르 3명), 문제 8(일기 예보 기사)
- **환경 문서 A·B·C 비교**가 이 차시의 클라이맥스 —
  유클리드는 C가 A와, 코사인·자카드는 C가 B와 더 유사하다고 답한다
- 결론: 목적과 특성에 맞는 유사도를 골라야 한다
- 공학 도구(AskMath AI 웹 실험실)는 마지막 1장으로 소개
- 확인하기 OX 2개

## 6. 열린 문제

- **차시 수 8개가 맞나** — 1단원이 절당 2~4차시였으니 균형은 맞지만,
  2-3절이 13쪽으로 커서 4차시로 잡았다. 수업해 보고 조정이 필요할 수 있다.
- **TF-IDF의 로그 버전**(61쪽)은 『대수』 이수자 대상 심화다.
  덱에는 선택 자료로 표시해 넣되, 이수 여부는 교사가 판단한다.
- **대단원 평가 문제(79~81쪽)**는 차시에 넣지 않았다. 단원 마무리 차시가 필요하면 별도 설계.
